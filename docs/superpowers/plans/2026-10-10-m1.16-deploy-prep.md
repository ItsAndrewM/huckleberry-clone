## Decisions this plan makes (veto in review)

- **P1: The log vocabulary.** One JSON object per line, from `logs.ts`:
  - `{event: "refused", reason, route}`, with `origin` added for `foreign-origin`
  - `{event: "keys-unavailable", route, cause}`
  - `{event: "household-unavailable", route, cause}`
  - `{event: "defect", route, caregiverId, actionId}`

  A defect's error and stack stay on their own line, from the `ErrorReporter` that's already there. The household adds the context line at its edge, from a clone of the request. So a 500 logs two lines that Workers Logs groups under one invocation.
- **P2: Refusal reasons.** They come from `jose`'s error codes and failing claim, and are listed in the runbook:
  - `no-token`, `access-unconfigured`, `malformed`, `wrong-algorithm`, `unknown-key`, `bad-signature`, `expired`, `wrong-issuer`, `wrong-audience`, `invalid-claims`, `no-identity`
  - the routing refusals `not-admin`, `service-token` and `not-a-caregiver`

  A key-set outage keeps its own `keys-unavailable` with the cause's message.
- **P3: Only the socket checks `Origin`.**
  - **What's refused:** a `/api/ws` upgrade whose `Origin` isn't exactly the request URL's origin gets 403 with no body. That includes a missing `Origin` and `"null"`.
  - **Why exact:** `jude-bedtime`, `house-compare` and the `andamonium.dev` root are the same site, so `SameSite=Lax` alone wouldn't stop them.
  - **Writes (changed by the final review):** this plan first said writes were already safe, since they need `application/json`, which forces a CORS preflight the Worker never answers. That's false in effect 4.0.1: it decodes a body with no `Content-Type` as JSON, and a no-cors POST of an untyped Blob or ArrayBuffer needs no preflight. So the Worker now answers 415 (`refused`, `not-json`) to any write that isn't `application/json`. A cross-site read still can't see its answer.
- **P4: `set-email` keeps the caregiver.**
  - **What it changes:** it moves the row's email and keeps its id, so entries and receipts stay that parent's.
  - **Refusals:** 404 when no caregiver has the current email. 400 on `newEmail` when any caregiver already has it, the same one included.
  - **Sockets:** it closes that parent's sockets with `CAREGIVER_DISABLED` (4401), which the app reads as "signed out".
- **P5: One admin call restores.**
  - **The call:** `POST /api/admin/pitr/restore` schedules the restore, then restarts the household. The restart counts as done only if it rejects with `RESTART_REASON`. Anything else answers 503 and logs that the restore waits for the next restart. Running the same command again fixes it.
  - **The target:** a bookmark, or a time within the last 30 days and not in the future.
  - **The CLI:** `--at` needs an explicit zone (`Z` or `±hh:mm`).
- **P6: No start-up sweep of disabled caregivers' sockets.**
  - **Why not:** the spike's note asked for one after a restore. But a restart drops every socket (1006, seen locally), and each reconnect goes through the `active` check, which refuses a caregiver the restore disabled.
  - **The test:** `pitr.test.ts` pins that, in place of a sweep.
- **P7: `pnpm release`.**
  - **Refuses unless:** the checkout is a clean `main` that matches `origin/main`, and CI passed on that commit (`gh run list --commit`).
  - **The build:** it builds with `CLOUDFLARE_ENV` removed, and refuses if the built config fails `deployProblems`.
  - **The bookmark:** it takes one, unless `--first`.
  - **The deploy:** `wrangler deploy` with the built config, then a line appended to `deploys.log`, which git ignores.
  - **The name:** it's `release` because `pnpm deploy` is a pnpm built-in.
- **P8: The config.**
  - **Entry point:** `routes: [{pattern: "baby.andamonium.dev", custom_domain: true}]`, `workers_dev: false`, `preview_urls: false`.
  - **Logs:** `observability: {enabled: true, logs: {invocation_logs: false}}`.
  - **Access values:** `ACCESS_AUD` and `ADMIN_SERVICE_TOKEN_CN` filled in.
  - **`env.local`:** gets `routes: []`, because routes are inherited, and wrangler warns that a deploy of `local` would take the Custom Domain.
- **P9: The Access app differs from the spike's.**
  - **What changed:** it allows Google only, with instant redirect. The spike had a choice screen with one-time PIN, and S1 passed that way.
  - **Fallback:** if sign-in fails inside the installed app on deploy day, the runbook gives the fallback: add one-time PIN and turn off instant redirect.
  - **The token:** `baby-tracker-admin` lasts a year, like the spike's, and Refresh renews it.
- **P10: M1.16 grows from S to M** in the plan's table, as the grill said it would.

```ts
export type AccessKeysFor = (teamDomain: string) => JWTVerifyGetKey

const refused = (reason: Refusal): Caller => ({ kind: "unauthenticated", reason })

const HttpsOrigin = Schema.String.check(
  Schema.makeFilter(
    (value: string) => {
      const parsed = URL.parse(value)
      return parsed?.protocol === "https:" && parsed.origin === value
    },
    { expected: "an https origin like https://team.cloudflareaccess.com" },
  ),
)

const JwtSettings = Schema.Struct({ ACCESS_TEAM_DOMAIN: HttpsOrigin, ACCESS_AUD: Schema.NonEmptyString })
const jwtSettingsOf = Schema.decodeUnknownOption(JwtSettings)

const Claims = Schema.Struct({ email: Schema.optional(Schema.String), common_name: Schema.optional(Schema.String) })
const claimsOf = Schema.decodeUnknownOption(Claims)

const callerFrom = ({ email, common_name }: typeof Claims.Type): Caller => {
  if (email !== undefined && email !== "") return { kind: "user", email: email.toLowerCase() }
  if (common_name !== undefined && common_name !== "") return { kind: "service", clientId: common_name }
  return refused("no-identity")
}

const callerFromClaims = (claims: JWTPayload | CloudflareAccessIdentity): Caller =>
  Option.match(claimsOf(claims), { onNone: () => refused("no-identity"), onSome: callerFrom })

const REFUSALS = new Map<string, Refusal>([
  ["ERR_JOSE_ALG_NOT_ALLOWED", "wrong-algorithm"],
  ["ERR_JWKS_NO_MATCHING_KEY", "unknown-key"],
  ["ERR_JWKS_MULTIPLE_MATCHING_KEYS", "unknown-key"],
  ["ERR_JWS_SIGNATURE_VERIFICATION_FAILED", "bad-signature"],
  ["ERR_JWT_EXPIRED", "expired"],
])

const CLAIM_REFUSALS = new Map<string, Refusal>([
  ["iss", "wrong-issuer"],
  ["aud", "wrong-audience"],
])

const refusalOf = (error: errors.JOSEError): Refusal =>
  error instanceof errors.JWTClaimValidationFailed
    ? (CLAIM_REFUSALS.get(error.claim) ?? "invalid-claims")
    : (REFUSALS.get(error.code) ?? "malformed")

class AccessKeysUnavailable extends Error {}

const reportingOutages =
  (keys: JWTVerifyGetKey): JWTVerifyGetKey =>
  async (header, token) => {
    try {
      return await keys(header, token)
    } catch (error) {
      if (error instanceof errors.JWKSNoMatchingKey || error instanceof errors.JWKSMultipleMatchingKeys) throw error
      throw new AccessKeysUnavailable(error instanceof Error ? error.message : "the key set couldn't be read")
    }
  }

const verifiedCaller = async (
  token: string,
  settings: typeof JwtSettings.Type,
  keys: JWTVerifyGetKey,
): Promise<Caller> => {
  try {
    const { payload } = await jwtVerify(token, reportingOutages(keys), {
      issuer: settings.ACCESS_TEAM_DOMAIN,
      audience: settings.ACCESS_AUD,
      algorithms: ["RS256"],
    })
    return callerFromClaims(payload)
  } catch (error) {
    if (error instanceof AccessKeysUnavailable) return { kind: "keys-unavailable", cause: error.message }
    return refused(error instanceof errors.JOSEError ? refusalOf(error) : "malformed")
  }
}

export const callerOf = async (
  request: Request,
  access: CloudflareAccessContext | undefined,
  settings: AccessSettings,
  keysFor: AccessKeysFor,
): Promise<Caller> => {
  const identity = await access?.getIdentity()
  if (identity !== undefined) return callerFromClaims(identity)
  const token = request.headers.get("cf-access-jwt-assertion")
  if (token === null) return refused("no-token")
  const jwt = jwtSettingsOf(settings)
  if (Option.isNone(jwt)) return refused("access-unconfigured")
  return verifiedCaller(token, jwt.value, keysFor(jwt.value.ACCESS_TEAM_DOMAIN))
}

const remoteKeys = new Map<string, JWTVerifyGetKey>()

export const remoteAccessKeys: AccessKeysFor = (teamDomain) => {
  const cached = remoteKeys.get(teamDomain)
  if (cached !== undefined) return cached
  const keys = createRemoteJWKSet(new URL("/cdn-cgi/access/certs", teamDomain))
  remoteKeys.set(teamDomain, keys)
  return keys
}
```

```ts
export interface CaregiverJson {

const emailOf = (value: string) => value.trim().toLowerCase()

export const caregiverFromArgs = (args: ReadonlyArray<string>): CaregiverJson => {
  const { positionals } = parseArgs({ args: [...args], allowPositionals: true, strict: true })
  const [email, ...rest] = positionals
  if (email === undefined || email.trim() === "" || rest.length > 0) throw new Error("Give one caregiver email")
  return { email: emailOf(email) }
}

export const emailChangeFromArgs = (args: ReadonlyArray<string>): EmailChangeJson => {
  const { positionals } = parseArgs({ args: [...args], allowPositionals: true, strict: true })
  const [email, newEmail, ...rest] = positionals
  if (
    email === undefined ||
    newEmail === undefined ||
    rest.length > 0 ||
    [email, newEmail].some((value) => value.trim() === "")
  ) {
    throw new Error("Give the caregiver's current email, then the new one")
  }
  return { email: emailOf(email), newEmail: emailOf(newEmail) }
}
```

```ts
  if (runs.some((run) => run.status !== "completed")) return ["CI has finished on this commit"]
  return runs.some((run) => run.conclusion === "success") ? [] : ["CI passed on this commit"]
}

export const withoutCloudflareEnv = (env: NodeJS.ProcessEnv): NodeJS.ProcessEnv =>
  Object.fromEntries(Object.entries(env).filter(([name]) => name !== "CLOUDFLARE_ENV"))

const bookmarkIn = (body: string): string | undefined => {
  try {
    const parsed: { readonly bookmark?: string } = JSON.parse(body)
    return parsed.bookmark
  } catch {
    return undefined
  }
}

export const bookmarkFrom = (status: number, body: string): string => {
  const bookmark = status === 200 ? bookmarkIn(body) : undefined
  if (bookmark === undefined || !BOOKMARK_FORMAT.test(bookmark)) {
    throw new Error(`Couldn't take a bookmark before deploying: ${status} ${body}`)
  }
  return bookmark
}

export const deployLogLine = (at: Date, commit: string, bookmark: string | null): string =>
  `${at.toISOString()} ${commit} ${bookmark ?? "first-deploy-no-bookmark"}\n`
```

```ts
import { appendFileSync, readFileSync } from "node:fs"
import { fileURLToPath } from "node:url"

import { adminRequest } from "./admin-seed.ts"

const webDir = fileURLToPath(new URL("../apps/web/", import.meta.url))
const env = withoutCloudflareEnv(process.env)

const output = (command: string, args: string[]): string => {
  const run = spawnSync(command, args, { cwd: rootDir, env, encoding: "utf8" })
  if (run.error !== undefined) throw run.error
  if (run.status !== 0) throw new Error(`${command} ${args.join(" ")} failed:\n${run.stdout}${run.stderr}`)
  return run.stdout.trim()
}

const step = (command: string, args: string[], cwd = rootDir): void => {
  const run = spawnSync(command, args, { cwd, env, stdio: "inherit" })
  if (run.error !== undefined) throw run.error
  if (run.status !== 0) process.exit(run.status ?? 1)
}

const stopUnless = (problems: string[]): void => {
  if (problems.length === 0) return
  console.error(
    `Not releasing. Each of these must hold first:\n${problems.map((problem) => `- ${problem}`).join("\n")}`,
  )
  process.exit(1)
}

const { values } = parseArgs({ options: { first: { type: "boolean", default: false } }, strict: true })

output("git", ["fetch", "--quiet", "origin", "main"])
const head = output("git", ["rev-parse", "HEAD"])
stopUnless(
  checkoutProblems({
    branch: output("git", ["branch", "--show-current"]),
    clean: output("git", ["status", "--porcelain"]) === "",
    head,
    originMain: output("git", ["rev-parse", "origin/main"]),
  }),
)
stopUnless(
  ciProblems(
    JSON.parse(output("gh", ["run", "list", "--commit", head, "--workflow", "CI", "--json", "status,conclusion"])),
  ),
)

step("pnpm", ["build"])
const config = builtWorkerConfig(webDir)
stopUnless(deployProblems(JSON.parse(readFileSync(config, "utf8"))))

const bookmarkResponse = values.first ? null : await fetch(adminRequest(process.env, "/api/admin/pitr/bookmark"))
const bookmark = bookmarkResponse === null ? null : bookmarkFrom(bookmarkResponse.status, await bookmarkResponse.text())
if (bookmark !== null) console.log(`Bookmark before this deploy: ${bookmark}`)

step("pnpm", ["exec", "wrangler", "deploy", "--config", config], webDir)
appendFileSync(new URL("../deploys.log", import.meta.url), deployLogLine(new Date(), head, bookmark))
console.log(`Released ${head.slice(0, 7)} to https://${PRODUCTION_HOSTNAME}. Logged in deploys.log.`)
```
