# M1.13 Conflict Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, as Andrew chose on 11 Oct 2026) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** when a save meets the other phone's change, or comes back "already saved", the sheet offers the next sensible step:
- **Redo:** do it again on the feed as it is now, if it still fits.
- **Edit:** save the parent's changes as an edit.
- **Join:** carry on with the feed the other phone started.

**Architecture:**
- **`apps/web/src/sheets/recovery.ts` (new, pure):** decides what a failed action's note offers. Its answer is a label, plus the `Sending` to make when that button is tapped.
- **`FailureNote`:** renders that button and an OK. OK settles the conflict and keeps the sheet showing the household's copy.
- **New actions:** two edits, `editDiaper` and `editPortion`, join `Action` as on-record kinds.
- **Held failures:** M1.12's held-failure model learns that two conflicts mean the entry can't be saved as it is. Those close on OK, with no "Discard this entry?".

## Decisions this plan makes (veto in review)

- **P1, what "still fits" means.** The feed must be active and not deleted, and:
  - **Switch and Pause:** it's running, and its open side started at or before the parent's tap. If it started later, the other phone switched or resumed after the tap, and redoing would undo their change.
  - **Resume:** it's paused.
  - **Finish:**
    - a plain finish (not the "Delete this feed?" delete) fits when the feed is paused
    - while it's running, it fits only if the corrected stop is still at or after the open side's start
  - **Add a bottle:** the bottle's time is at or after the feed's start.
- **P2, a redo reuses the failed request's `actionId`, with the feed's current version.** A 409 writes no receipt, so the household has never seen that `actionId` succeed. A lost answer to the redo then replays as usual.
- **P3, an edit and a join each make a fresh `actionId`.** They go to another route, where a reused `actionId` gets 400.
- **P4, "Save my changes" covers a diaper, and a bottle that is its own feed.**
  - A diaper's 409 carries the saved diaper, and a bottle-only feed's 409 carries a feed with exactly one portion. Both targets are exact.
  - A bottle added to a running feed is left out. The household gives portions random ids, so the portion the first attempt added can't be told apart from the feed's others. It says "This was already saved as you first entered it." with OK, as nursing and past feeds do.
- **P5, two conflicts mean the entry can't be saved as it is:** `ACTION_REPLAY_MISMATCH` (it's saved already) and `FEED_ALREADY_ACTIVE` (another feed is running).
  - A held entry with either of these closes on OK, or on dismissal, with no "Discard this entry?". It leaves the queue as it closes.
  - The check is by code, so M4.4's measurement conflicts follow it with no change (agreed with 7b).
- **P6, OK shows only on a conflict a parent settles by accepting the household's copy:** `STALE_VERSION`, `FEED_ALREADY_ACTIVE` and `ACTION_REPLAY_MISMATCH`.
  - OK discards the held failure. The sheet stays open, showing the feed or entry as it is now.
  - An overlap or a field error gets no OK. The parent fixes the form, or dismisses the sheet and is asked "Discard this entry?".
- **P7, a shared sides module.** `recovery.ts` names a side ("Switch to Left"), and the shared sheets layer mustn't import a feature.
  - `SIDES`, `SIDE_NAMES` and `OTHER_SIDE` move to `apps/web/src/sides.ts`, beside `clock-time.ts`.
  - This also removes M1.12's duplicated `SIDES` (`first-side.tsx`, `side-picker.tsx`).
- **P8, the Nursing running and paused views show the note above their controls,** as D3's preview does.
- **P9, Back from the finish step drops a held finish,** as "Keep it" does. This is M1.12's parked minor 1. Otherwise the running view shows a stale failed finish with a working Try again.
- **P10, a bottle picked in the running feed's start minute tops that feed up, at the start's instant.**
  - This is M1.12's parked minor 2, and it mirrors M1.12's P11 for a stop.
  - Picked times are whole minutes, so "3:00" for a 3:00:27 start would otherwise log a separate feed. That would add to "Feeds started".
- **P11, the edits are controls that close their sheet.**
  - `editDiaper` and `editPortion` join `CLOSES_ON_SEND`, since saving the changes finishes the entry. They stay out of `NEW_ENTRIES`, matching M4.4's `editMeasurement`.
  - A failed edit shows its note while the sheet is open, and goes on close.
- **P12, the copy.** `ACTION_REPLAY_MISMATCH` now reads "This was already saved as you first entered it." for feeds and diapers. That is true with or without "Save my changes". The other messages are M1.12's.

## Review Focus

1. **A redo must never undo the other phone's change.** Take a Switch when they already switched, or a Pause when they paused and resumed. The open side started after the tap, so no redo is offered. Pinned by `recovery.test.ts` ("doesn't redo a switch after theirs").
2. **"Save my changes" must edit the record that was saved, never create a second one.** It sends the parent's values on that record's id and current version, under a fresh `actionId`. Pinned by `recovery.test.ts`, `diaper.spec.ts` and `bottle.spec.ts`.
3. **A start that loses to the other phone must never start a second feed.** It only offers to switch or resume on theirs, with their id and version. Pinned by `nursing.spec.ts` ("offers your side on theirs").
4. **OK must never silently drop an entry that could still be saved.**
   - OK appears only on P6's conflicts.
   - P5's no-prompt close applies only to "saved already" and "another feed is running".
   - An offline entry and an overlap still ask "Discard this entry?".
   - Pinned by `sheets-state.test.ts`.
5. **A redone finish keeps the corrected stop only while it's still at or after the running side's start.** Pinned by `recovery.test.ts`.

```ts
import { type Diaper, DiaperConflict, type Feed, FeedConflict } from "@bt/contracts"
import type { Action } from "../api/actions.ts"
import { SIDE_NAMES } from "../sides.ts"
import type { Failed, Sending } from "./sending.ts"

export interface Tap {
  readonly at: number
  readonly actionId: string
}

export interface Recovery {
  readonly label: string
  readonly sendingAt: (tap: Tap) => Sending
}

const SAVE_CHANGES = "Save my changes"

const REDO_LABELS = new Map<Action["kind"], string>([
  ["switchSide", "Switch anyway"],
  ["pauseFeed", "Pause anyway"],
  ["resumeFeed", "Resume anyway"],
  ["finishFeed", "Finish anyway"],
  ["addBottle", "Add it anyway"],
])

const SETTLED_BY_OK = new Set(["STALE_VERSION", "FEED_ALREADY_ACTIVE", "ACTION_REPLAY_MISMATCH"])

const CANT_SAVE_AS_IS = new Set(["ACTION_REPLAY_MISMATCH", "FEED_ALREADY_ACTIVE"])

const openSideOf = (feed: Feed) => feed.segments.find(({ endedAt }) => endedAt === null) ?? null

const runningSince = (feed: Feed, at: number) => {
  const open = openSideOf(feed)
  return open !== null && open.startedAt <= at
}

const fits = (action: Action, feed: Feed) => {
  switch (action.kind) {
    case "switchSide":
    case "pauseFeed":
      return runningSince(feed, action.payload.occurredAt)
    case "resumeFeed":
      return openSideOf(feed) === null
    case "finishFeed":
      return !action.payload.deleteIfEmpty && (openSideOf(feed) === null || runningSince(feed, action.payload.occurredAt))
    case "addBottle":
      return action.payload.occurredAt >= feed.startedAt
    default:
      return false
  }
}

const withVersion = <Sent extends Action>(action: Sent, version: number): Sent => ({
  ...action,
  payload: { ...action.payload, version },
})

const redone = ({ sheet, action }: Sending, feed: Feed): Recovery | null => {
  const label = REDO_LABELS.get(action.kind)
  const live = feed.status === "active" && feed.deletedAt === null
  if (label === undefined || !live || !fits(action, feed)) return null
  return { label, sendingAt: () => ({ sheet, action: withVersion(action, feed.version) }) }
}

const joined = ({ action }: Sending, feed: Feed): Recovery | null => {
  if (action.kind !== "startFeed") return null
  const { side } = action.payload
  const open = openSideOf(feed)
  if (open?.side === side) return null
  const id = feed.id
  const version = feed.version
  if (open === null) {
    return {
      label: `Resume on ${SIDE_NAMES[side]}`,
      sendingAt: ({ at, actionId }) => ({
        sheet: "nursing",
        action: { kind: "resumeFeed", id, payload: { actionId, version, side, occurredAt: at } },
      }),
    }
  }
  return {
    label: `Switch to ${SIDE_NAMES[side]}`,
    sendingAt: ({ at, actionId }) => ({
      sheet: "nursing",
      action: { kind: "switchSide", id, payload: { actionId, version, occurredAt: at } },
    }),
  }
}

const diaperEdit = ({ sheet, action }: Sending, saved: Diaper): Recovery | null => {
  if (action.kind !== "logDiaper") return null
  const { occurredAt, wet, dirty } = action.payload
  return {
    label: SAVE_CHANGES,
    sendingAt: ({ actionId }) => ({
      sheet,
      action: { kind: "editDiaper", id: saved.id, payload: { actionId, version: saved.version, occurredAt, wet, dirty } },
    }),
  }
}

const bottleEdit = ({ sheet, action }: Sending, saved: Feed): Recovery | null => {
  if (action.kind !== "logFeed" || action.payload.segments.length > 0) return null
  const [mine] = action.payload.portions
  const [portion] = saved.portions
  if (mine === undefined || portion === undefined || saved.portions.length > 1 || saved.segments.length > 0) return null
  return {
    label: SAVE_CHANGES,
    sendingAt: ({ actionId }) => ({
      sheet,
      action: { kind: "editPortion", id: portion.id, payload: { actionId, version: saved.version, ...mine } },
    }),
  }
}

const feedRecovery = (sending: Sending, error: FeedConflict): Recovery | null => {
  switch (error.code) {
    case "STALE_VERSION":
      return redone(sending, error.current)
    case "FEED_ALREADY_ACTIVE":
      return joined(sending, error.current)
    case "ACTION_REPLAY_MISMATCH":
      return bottleEdit(sending, error.current)
    default:
      return null
  }
}

export const recoveryOf = ({ sending, error }: Failed): Recovery | null => {
  if (error instanceof FeedConflict) return feedRecovery(sending, error)
  if (error instanceof DiaperConflict && error.code === "ACTION_REPLAY_MISMATCH") return diaperEdit(sending, error.current)
  return null
}

export const offersOk = (error: Error) =>
  (error instanceof FeedConflict || error instanceof DiaperConflict) && SETTLED_BY_OK.has(error.code)

export const settlesWithoutAsking = (error: Error) => "code" in error && CANT_SAVE_AS_IS.has(String(error.code))
```

  If lint refuses `String(error.code)`, check the two conflict classes by `instanceof` instead, and tell 7b that measurement conflicts then need adding to the check.

export const dismissedState = (state: SheetsState): SheetsState => {
  if (state.open === null) return state
  const shown = heldFor(state.held, state.open)
  if (shown === null) return closing(state)
  if (settlesWithoutAsking(shown.error)) {
    return closing({ ...state, held: withoutAction(state.held, actionIdOf(shown.sending)) })
  }
  return isEntry(shown.sending) ? { ...state, asking: true } : closing(state)
}

```tsx
import { Button } from "../components/ui/button.tsx"
import { offersOk, recoveryOf } from "./recovery.ts"
import type { Failed } from "./sending.ts"
import { useSheets } from "./sheets-context.ts"
import { tapTime } from "./tap-time.ts"

export const RecoveryButtons = ({ failed }: { readonly failed: Failed }) => {
  const sheets = useSheets()
  const recovery = recoveryOf(failed)
  const ok = offersOk(failed.error)
  if (recovery === null && !ok) return null
  return (
    <div className="flex gap-2">
      {recovery === null ? null : (
        <Button
          variant="outline"
          size="lg"
          className="flex-1"
          onClick={() => {
            sheets.discard(failed)
            sheets.send(recovery.sendingAt({ at: tapTime(), actionId: crypto.randomUUID() }))
          }}
        >
          {recovery.label}
        </Button>
      )}
      {ok ? (
        <Button variant="ghost" size="lg" className="flex-1" onClick={() => sheets.discard(failed)}>
          OK
        </Button>
      ) : null}
    </div>
  )
}
```
