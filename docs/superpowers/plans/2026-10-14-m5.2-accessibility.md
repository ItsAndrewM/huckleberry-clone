# M5.2 Accessibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 14 Oct 2026) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **The code listings below come from the prototype replay and predate the final review's fixes (16 Oct 2026), so the branch's code is the record.** The decisions, P1 to P15, are brought up to date.

**Goal:** Every screen and sheet passes axe's WCAG 2.2 A and AA rules in both themes, and CI keeps it that way. Every hand-off note that's a real defect is fixed with a test: contrast, tap targets, the Day grid's reading order, focus, announcements and names. Each screen names itself in the page title, focus is never hidden under a bar, Reduce Motion is respected, and text follows iOS's text size (issue #47).

**Architecture:**
- **The gate** (`e2e/accessibility.spec.ts`, its helpers `e2e/axe-gate.ts` and `e2e/opened-sheets.ts`, `e2e/played-screens.ts`): `playEveryScreen(page)` plays every read the app makes from one busy day, with the household's supplements and the child's sex fixed, so axe sees real content without writing to the shared local household. Each check stops transitions first, runs axe's `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22a` and `wcag22aa` rules, and leaves out Base UI's focus guards, which Base UI makes unnamed buttons in Safari on purpose.
- **Contrast** (`apps/web/src/index.css`, `apps/web/test/contrast.test.ts`): a test reads the theme's `light-dark()` tokens, works out each mark's contrast as drawn (its colour at its alpha over what's behind it), and checks that each class it names is really in its component. A new `--field` token draws fields' borders.
- **Order** (`features/history/grid-order.ts`, `grid-item.tsx`): `gridItems` lists a day's sleeps, feeds and markers in one sequence by the time each began, and `GridItemView` draws each in its own column's layer, so the DOM, and so VoiceOver and Tab, go in time order while nothing moves on screen.
- **Focus** (`sheets/focus-home.ts`, `sheets/use-last-pressed.ts`, `shell/page-heading.ts`): the sheets provider remembers what opened a sheet (the control just pressed, since Safari never focuses a tapped button) and its list row. Base UI's `finalFocus` asks `focusTarget` where focus goes when the sheet closes: the opener, else its row, the row after, the row before, or the page's heading. A failure note focuses itself; Go to, Trends' × and the install card move focus themselves. A control that waits keeps focus (`focusableWhenDisabled`), and one that gives way or leaves hands it on (`shell/focus-hand-off.ts`).
- **Announcements and names**: period headings are polite live regions; Trends reads out the bar the chart has focused through a hidden `<output>`; Export says it's preparing and when the file is ready; a field's message is tied to its field and spoken politely (`components/field-message.tsx`). Spoken names keep a control's visible words and add what's missing.
- **The shell** (`shell/use-page-title.ts`, `index.css`): page titles, `scroll-padding` for the fixed bars, the No connection banner and History's sticky switcher (the banner and the switcher publish their heights), and a Reduce Motion block.
- **Larger Text** (`index.css`): a registered `--text-unit`, 16 px by default. On an iPhone, `body { font: -apple-system-body }` sets it from iOS's text size, clamped to the standard sizes and never below 16 px, and Tailwind's `text-*` sizes multiply it. Spacing stays in `rem`.

**Tech Stack:** React 19.3.0, Base UI 1.8.0 (the Drawer popup's `finalFocus`), TanStack Charts 1.1.0 (`onFocusChange`), Tailwind CSS 4.3.3 (`@theme inline`, `@property`, `:has()`), Playwright 1.64.0 with `@axe-core/playwright` 4.13.0 (new, a dev dependency), Vitest 4.1.11, TypeScript 5.9.3, oxlint 1.87.0 and oxfmt 0.72.0, Node 24.21.0.

**Spec:** issue #47: its body (15 hand-off notes) and its comments: the hand-offs from M3.9, M3.2, #61 and M3.3, "Taken", "Grill decisions" and the axe sweep's "Progress". Also `docs/implementation-plan.md`, the M5.2 row, §3.4 and §6.

Andrew decided these on 14 Oct 2026, in the grill before this plan:
- **Execution:** by subagents, over native.
- **Done means:** an axe spec over every screen and every sheet and dialog open, in light and dark, on both engines, failing CI on any WCAG 2.2 A or AA violation; each hand-off defect fixed with a test; the VoiceOver checks as one `andrew` issue after the deploy (dropped on 16 Oct 2026, because neither parent uses VoiceOver or a physical keyboard; the PR's description asks Andrew, in one line, to look at a few screens at a bigger text size if either parent uses one). M5.2 closes with its PR.
- **Contrast:** every mark that carries meaning reaches 3:1 against what's next to it in both themes.
- **Tap targets:** at least 24 px; the Day grid's minimum block goes from 4 to 5 steps.
- **Day grid order:** by start time across kinds, then the hour rows.
- **Lost focus:** opener, else what replaced it, else the heading; a failure back in an open sheet puts focus on its note.
- **Announcements:** what a tap changes elsewhere is announced politely; failures stay alerts.
- **Names:** visible words stay; the spoken name starts with them and adds context.
- **Extras:** page titles, Reduce Motion, and iOS Larger Text: text only, through the standard sizes, unchanged at the usual size.
- **Delivery:** one plan, one PR.

- **P12: Larger Text.**

## Review Focus

The five ways this is most likely to fail a parent, each with the test that pins it:

1. **Focus jumping somewhere surprising after a tap**, on a phone where nobody sees a ring but the page scrolls to whatever takes focus.
   - Pinned by `focus.spec.ts`: the opener after Escape, the row while it saves, the next row after a delete, a measurement's card while it saves, and the page's heading after a delete from History's details (Tasks 4 and 9). The fix wave adds the hand-offs: a control that waits, gives way or leaves, a back-swipe, Escape in Go to and a failure note's Try again.
2. **A sheet that never finishes closing with Reduce Motion on**, since Base UI waits for its transitions before it unmounts the sheet.
   - Pinned by `shell-a11y.spec.ts`'s five Reduce Motion tests; one closes the sheet and expects no dialog (Task 8).
3. **Text at iOS's largest standard size spilling sideways or out of its box.**
   - Pinned by `larger-text.spec.ts`: every screen, and each of the 15 sheet states in `e2e/opened-sheets.ts`, with no sideways scroll and every date and time showing whole, a quick action still 48 px tall, and an hour label still 11 px (Task 10 and the fix wave).
4. **A desktop browser or a Mac's Safari changing its text size.**
   - Pinned by `larger-text.spec.ts`'s "at iOS's usual text size, text keeps the sizes it has today", which runs in Playwright's WebKit on a Mac (Task 10).
5. **A later feature quietly undoing this.**
   - Pinned by the gate itself and by `contrast.test.ts`'s "no focus ring or outline is faded", and by `CLAUDE.md`'s new rule (Tasks 1, 2 and 11).

import type { Page } from "@playwright/test"
import { BIRTH_DATE, busyDay, DAY, diaper, dose, emptyDay, feed, local, measurement, NOW, sleep } from "./played-day.ts"
import { datesFrom, periodOf, TRENDS_DAYS } from "./played-period.ts"
import { LAST_WEEK, THIS_WEEK, weekOf } from "./played-week.ts"

const MINUTE = 60_000

const deletedAt = <Entry extends object>(entry: Entry) => ({ ...entry, deletedAt: NOW - 30 * MINUTE })

const dayOf = (andrew: string, emily: string, vitaminD: string) => {
  const busy = busyDay(andrew, emily)
  return {
    ...busy,
    sleeps: [
      sleep("night", local("20:10", "2026-10-08"), local("06:05"), "night", emily),
      sleep("nap", local("07:00"), local("07:20"), "nap", andrew),
    ],
    doses: [dose("dose", vitaminD, local("08:00"), andrew)],
    measurements: [measurement("weighed", local("08:30"), 4300, 54.5, 36.8, emily)],
  }
}

type Day = ReturnType<typeof dayOf>

const todayOf = (day: Day) => {
  const running = day.feeds.find((one) => one.status === "active") ?? null
  const recent = [
    ...day.feeds.map((one) => ({ kind: "feed", feed: one, at: one.startedAt })),
    ...day.diapers.map((one) => ({ kind: "diaper", diaper: one, at: one.occurredAt })),
    ...day.sleeps.map((one) => ({ kind: "sleep", sleep: one, at: one.startedAt })),
    ...day.doses.map((one) => ({ kind: "dose", dose: one, at: one.occurredAt })),
  ]
  return {
    date: DAY,
    totals: TRENDS_DAYS[DAY],
    activeFeed: running,
    lastFeed: running,
    activeSleep: null,
    lastSleep: day.sleeps.at(-1) ?? null,
    prefill: { lastBottle: { breastMilkMl: 60, formulaMl: 0 }, lastSide: "left" },
    recent: recent.toSorted((a, b) => b.at - a.at).map(({ at: _at, ...entry }) => entry),
    doses: day.doses,
  }
}

const deletedOf = (andrew: string, vitaminD: string) => ({

const answering = (page: Page, pattern: RegExp, answers: ReadonlyMap<string, object>) =>
  page.route(pattern, (route) => {
    const key = new URL(route.request().url()).pathname.split("/").at(-1) ?? ""
    const answer = answers.get(key)
    return answer === undefined
      ? route.fulfill({ status: 404, json: { _tag: "NotFound" } })
      : route.fulfill({ json: answer })
  })

export const playEveryScreen = async (page: Page) => {
  const me = await (await page.request.get("/api/me")).json()
  const [andrew, emily] = me.household.caregivers
  const vitaminD = me.household.supplements[0].id
  const household = {
    ...me.household,
    timeZone: "America/Vancouver",
    units: { volume: "ml", weight: "kg", length: "cm" },
  }
  const day = dayOf(andrew.id, emily.id, vitaminD)
  const trendsWeek = periodOf(datesFrom("2026-10-05", 7), TRENDS_DAYS)
  const week = { ...weekOf(THIS_WEEK, [day]), days: trendsWeek.days, totals: trendsWeek.totals }
  await page.route("**/api/me", (route) =>
    route.fulfill({ json: { ...me, household, child: { ...me.child, birthDate: BIRTH_DATE } } }),
  )
  await page.route("**/api/today", (route) => route.fulfill({ json: todayOf(day) }))

  )
  await answering(

    /\/api\/days\/[^/]+$/u,
    new Map([

      ["2026-10-08", emptyDay("2026-10-08")],
    ]),
  )
  await answering(
    page,
    /\/api\/weeks\/[^/]+$/u,
    new Map([
      [THIS_WEEK, { ...week, week: THIS_WEEK }],
      [LAST_WEEK, { ...periodOf(datesFrom("2026-09-28", 7), TRENDS_DAYS), week: LAST_WEEK }],
    ]),
  )
  await answering(
    page,
    /\/api\/months\/[^/]+$/u,
    new Map([["2026-10", { ...periodOf(datesFrom("2026-10-01", 31), TRENDS_DAYS), month: "2026-10" }]]),
  )
  await page.route("**/api/growth", (route) => route.fulfill({ json: { measurements: growthOf(andrew.id) } }))
  await page.route("**/api/deleted", (route) => route.fulfill({ json: deletedOf(andrew.id, vitaminD) }))
  await page.clock.setFixedTime(NOW)
}

type Rgb = readonly [number, number, number]
export type Theme = 0 | 1

const encode = (linear: number) =>
  linear <= 0.003_130_8 ? 12.92 * linear : 1.055 * Math.max(linear, 0) ** (1 / 2.4) - 0.055

const decode = (channel: number) => (channel <= 0.040_45 ? channel / 12.92 : ((channel + 0.055) / 1.055) ** 2.4)

const clamp = (channel: number) => Math.min(Math.max(channel, 0), 1)

export const srgbOfOklch = (lightness: number, chroma: number, hue: number): Rgb => {
  const a = chroma * Math.cos((hue * Math.PI) / 180)
  const b = chroma * Math.sin((hue * Math.PI) / 180)
  const l = (lightness + 0.396_337_777_4 * a + 0.215_803_757_3 * b) ** 3
  const m = (lightness - 0.105_561_345_8 * a - 0.063_854_172_8 * b) ** 3
  const s = (lightness - 0.089_484_177_5 * a - 1.291_485_548 * b) ** 3
  return [
    clamp(encode(4.076_741_662_1 * l - 3.307_711_591_3 * m + 0.230_969_929_2 * s)),
    clamp(encode(-1.268_438_004_6 * l + 2.609_757_401_1 * m - 0.341_319_396_5 * s)),
    clamp(encode(-0.004_196_086_3 * l - 0.703_418_614_7 * m + 1.707_614_701 * s)),
  ]
}

const luminance = ([red, green, blue]: Rgb) => 0.2126 * decode(red) + 0.7152 * decode(green) + 0.0722 * decode(blue)

export const over = (top: Rgb, alpha: number, under: Rgb): Rgb => [
  alpha * top[0] + (1 - alpha) * under[0],
  alpha * top[1] + (1 - alpha) * under[1],
  alpha * top[2] + (1 - alpha) * under[2],
]

export const contrast = (one: Rgb, other: Rgb) => {
  const [lighter, darker] = [luminance(one), luminance(other)].toSorted((a, b) => b - a)
  return ((lighter ?? 0) + 0.05) / ((darker ?? 0) + 0.05)
}

const oklchOf = (values: string) => {
  const [lightness = 0, chroma = 0, hue = 0] = values.split(/\s+/u).map(Number)
  return srgbOfOklch(lightness, chroma, hue)
}

const COLOUR = /--([a-z-]+):\s*light-dark\(oklch\(([^)]+)\),\s*oklch\(([^)]+)\)\)/gu
const ALIAS = /--([a-z-]+):\s*var\(--([a-z-]+)\)/gu

export const themeTokens = (css: string) => {
  const colours = new Map(
    [...css.matchAll(COLOUR)].map(
      ([, name = "", light = "", dark = ""]) => [name, [oklchOf(light), oklchOf(dark)]] as const,
    ),
  )
  const aliases = new Map([...css.matchAll(ALIAS)].map(([, name = "", alias = ""]) => [name, alias]))
  return (name: string, theme: Theme): Rgb => {
    const colour = colours.get(aliases.get(name) ?? name)
    if (colour === undefined) throw new Error(`No colour token --${name}`)
    return colour[theme]
  }
}

import { CONTROL, pageHeading, readyForFocus } from "../shell/page-heading.ts"

export interface FocusHome {
  readonly opener: HTMLElement | null
  readonly row: HTMLElement | null
  readonly next: HTMLElement | null
  readonly previous: HTMLElement | null
}

export const NO_HOME: FocusHome = { opener: null, row: null, next: null, previous: null }

const asHtml = (element: Element | null | undefined) => (element instanceof HTMLElement ? element : null)

export const homeOf = (opener: Element | null): FocusHome => {
  const row = asHtml(opener?.closest("li"))
  return {
    opener: asHtml(opener),
    row,
    next: asHtml(row?.nextElementSibling),
    previous: asHtml(row?.previousElementSibling),
  }
}

const isUsable = (element: HTMLElement | null): element is HTMLElement =>
  element !== null && element.isConnected && element.matches(CONTROL)

const landingIn = (row: HTMLElement) => row.querySelector<HTMLElement>(CONTROL) ?? row

const homeTarget = ({ opener, row, next, previous }: FocusHome) => {
  if (isUsable(opener)) return opener
  const standIn = [row, next, previous].find((one) => one?.isConnected === true)
  return standIn === undefined || standIn === null ? pageHeading() : landingIn(standIn)
}

export const focusTarget = (home: FocusHome) => {
  const target = homeTarget(home)
  return target === null ? true : readyForFocus(target)
}

export const useLastPressed = () => {
  const pressed = useRef<Element | null>(null)
  useEffect(() => {
    const remember = (event: Event) => {
      pressed.current = event.target instanceof Element ? event.target.closest(CONTROL) : null
      setTimeout(() => {
        pressed.current = null
      }, 0)
    }
    document.addEventListener("click", remember, true)
    return () => document.removeEventListener("click", remember, true)
  }, [])
  return pressed
}
