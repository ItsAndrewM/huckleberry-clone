# M5.6 Held Entries Survive a Reload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, as Andrew chose on 11 Oct 2026) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an entry the household hasn't confirmed survives a reload or iOS closing the app. The next time the app opens, it asks before saving it. Also: M1.12's three parked held-entry items, and the startup wait.

**Architecture:**
- **`sheets/kept.ts` (new, pure):** the entries kept on the phone, in `localStorage` under `bt.kept`. Each is the `Sending`, when it was first kept, and whether its save failed. Reading skips what it can't decode.
- **`sheets/restored.ts` (new, pure):** at startup, `main.tsx` turns the sign-in draft and the kept entries into held failures. A kept entry's error is `Unsaved`, and its note asks "Save it now?".
- **`SheetsProvider`:**
  - `useKeptEntries` keeps an entry from its send until it's saved, discarded, or can't be saved as it is.
  - `useReopenWhenReady` opens the first held sheet once its data is there.
  - `useHeldDrafts` drops a sign-in draft whose action isn't held any more.
- **`Sheet`:** a sheet that opens on its own ignores taps for half a second (`arrival.ts`, a ref callback).
- **`api/optimistic.ts`:** a send cancels Today's or Growth's fetch only when that cache holds data.

**Tech Stack:** as M1.12 and M4.4: React 19.3, TypeScript 5.9.3, TanStack Query 5.104.1, `effect` 4.0.1, `@bt/contracts`, shadcn on Base UI 1.8.0, Tailwind 4.3.3, Vitest 4.1.11, Playwright 1.64.0, Node 24.21.0. M5.6 adds no package.

## Decisions this plan makes (veto in review)

- **P1, where:** `localStorage`, key `bt.kept`.
  - `sessionStorage` doesn't outlive iOS closing a Home Screen app. WebKit's seven-day storage cap exempts Home Screen apps.
  - Each record is `{ sending, keptAt, failed }`. A record from another version that doesn't decode is skipped, as `RecentEntries` skips kinds the app doesn't know.
- **P2, what's kept:** new entries only (`isEntry`): a diaper, a bottle or past feed, a started feed, a bottle added to a feed, and a new measurement.
  - An entry is kept from its send until one of three things: the household confirms it, it's discarded, or it fails in a way that settles without asking (already saved, or another feed is running).
  - Controls and edits are never kept. They go with their sheet, as M5.4's note says.
- **P3, `keptAt` is when the entry was first kept,** and retries keep it. On restore, 12 h from `keptAt` decides whether it keeps its `actionId`, the draft's rule (§3.3).
- **P4, `failed`:**
  - It's true once the app has seen the save fail, and false again while it's re-sent.
  - A reload with a save in flight counts as a failure, because the browser cancels the request while the page still runs. So "might not have been saved" means iOS closed the app.
- **P5, when it reopens:**
  - **Today's sheets** (diaper, bottle, nursing, past feed): once Today has loaded.
  - **A new measurement:** once `me` has loaded, since its sheet needs nothing more.
  - The provider fetches Today itself only while a kept Today entry waits, so Growth and Settings don't otherwise fetch it.
- **P6, a stale sign-in draft joins the same queue.**
  - Its sheet now opens once Today loads too, instead of at once with an empty form.
  - M1.12's `bottle.spec.ts` test "holds a draft's reopened Bottle sheet until Today loads" pinned the empty sheet. It becomes "opens a draft's Bottle sheet once Today loads".
- **P7, a fresh sign-in draft's entry stays kept while it's re-sent.** A stale draft takes the place of its kept copy, under the new `actionId`.
- **P8, when the phone won't keep it:** private browsing, or full storage.
  - Every write says whether it landed.
  - When one doesn't, the offline note keeps M5.4's "Keep the app open" wording.
- **P9, the arrival guard.**
  - A sheet that opens on its own ignores pointer taps for 500 ms: one from the queue, from a failure, or from the restore. The Drawer's slide-in takes 450 ms.
  - It's a module-level ref callback that sets `data-arriving`, styled `pointer-events-none`, so it adds no effect.
  - Keyboard and screen readers are unaffected, and Playwright waits it out.
  - It covers the online case, where the next held entry's sheet opens at once. On a phone that reads offline, the sheet stays open and its note already moves to the next held entry. That is M4.4's handoff to M3.4, and the double tap's resend there fails offline too.
- **P10, the sign-in draft follows the held list.**
  - One `useEffect` (`useHeldDrafts`) drops a stored draft whose action is no longer held. That covers a re-send, a discard and a let-go control in one place.
  - It replaces M1.12's explicit drops. It syncs `sessionStorage` with React state, which is what effects are for.
- **P11, not tied to who's signed in.**
  - One phone is one caregiver: Access lasts 730 h, and the app has no sign-out.
  - A kept entry is saved as whoever is signed in when it's sent.
- **P12, two tabs on one desktop share `bt.kept`,** and the last write wins. The phones run one app each.
- **P13, a restored started feed asks like any entry,** showing when it was kept. Saving it starts the feed from its original start, and Finish's stop correction ends it.
- **P14, the restored notes** (a stale draft, a kept entry) move to `restored-note.ts`, so `failure.ts` doesn't grow.

```ts
import { Data, Option, Schema } from "effect"
import { attempt, type BrowserStorage } from "../storage.ts"
import { actionIdOf } from "./held.ts"
import { Sending } from "./sending.ts"

export const KEPT_KEY = "bt.kept"

export const KeptEntry = Schema.Struct({ sending: Sending, keptAt: Schema.Int, failed: Schema.Boolean })
export type KeptEntry = typeof KeptEntry.Type

const isKeptEntry = Schema.is(KeptEntry)

const decodeStored = Schema.decodeUnknownOption(Schema.fromJsonString(Schema.Array(Schema.Json)))

export const keptStorage = () => localStorage

export const readKept = (openStorage: () => BrowserStorage): ReadonlyArray<KeptEntry> => {
  const stored = attempt(() => openStorage().getItem(KEPT_KEY), null)
  if (stored === null) return []
  return Option.getOrElse(decodeStored(stored), () => []).flatMap((entry) => (isKeptEntry(entry) ? [entry] : []))
}

export const writeKept = (openStorage: () => BrowserStorage, entries: ReadonlyArray<KeptEntry>) =>
  attempt(() => {
    if (entries.length === 0) openStorage().removeItem(KEPT_KEY)
    else openStorage().setItem(KEPT_KEY, JSON.stringify(entries))
    return true
  }, false)

const idOf = ({ sending }: KeptEntry) => actionIdOf(sending)

const upsert = (entries: ReadonlyArray<KeptEntry>, sending: Sending, failed: boolean, now: number) => {
  const actionId = actionIdOf(sending)
  const before = entries.find((entry) => idOf(entry) === actionId)
  const kept = { sending, keptAt: before?.keptAt ?? now, failed }
  return before === undefined ? [...entries, kept] : entries.map((entry) => (entry === before ? kept : entry))
}

export const keptSending = (entries: ReadonlyArray<KeptEntry>, sending: Sending, now: number) =>
  upsert(entries, sending, false, now)

export const keptFailed = (entries: ReadonlyArray<KeptEntry>, sending: Sending, now: number) =>
  upsert(entries, sending, true, now)

export const keptWithout = (entries: ReadonlyArray<KeptEntry>, actionId: string) =>
  entries.some((entry) => idOf(entry) === actionId) ? entries.filter((entry) => idOf(entry) !== actionId) : entries

export class Unsaved extends Data.TaggedError("Unsaved")<{ readonly keptAt: number; readonly failed: boolean }> {}
```

import { DRAFT_RETRY_MS, type Draft, isFresh, renewed, StaleDraft } from "./drafts.ts"
import { actionIdOf } from "./held.ts"
import { type KeptEntry, Unsaved } from "./kept.ts"
import type { Failed } from "./sending.ts"

export interface Restored {
  readonly held: ReadonlyArray<Failed>
  readonly kept: ReadonlyArray<KeptEntry>
}

interface Back {
  readonly held: Failed
  readonly kept: KeptEntry
}

const staleDraftBack = (draft: Draft, actionId: string): Back => {
  const sending = renewed(draft.sending, actionId)
  return {
    held: { sending, error: new StaleDraft({ createdAt: draft.createdAt }) },
    kept: { sending, keptAt: draft.createdAt, failed: true },
  }
}

const entryBack = (entry: KeptEntry, now: number, newId: () => string): Back => {
  const sending = now - entry.keptAt < DRAFT_RETRY_MS ? entry.sending : renewed(entry.sending, newId())
  return {
    held: { sending, error: new Unsaved({ keptAt: entry.keptAt, failed: entry.failed }) },
    kept: { ...entry, sending },
  }
}

export const restored = (
  draft: Draft | null,
  stored: ReadonlyArray<KeptEntry>,
  now: number,
  newId: () => string,
): Restored => {
  const draftId = draft === null ? null : actionIdOf(draft.sending)
  const resent = draft !== null && isFresh(draft, now)
  const stale = draft === null || resent ? [] : [staleDraftBack(draft, newId())]
  const back = [
    ...stale,
    ...stored.filter((entry) => actionIdOf(entry.sending) !== draftId).map((entry) => entryBack(entry, now, newId)),
  ]
  const resending = resent ? stored.filter((entry) => actionIdOf(entry.sending) === draftId) : []
  return { held: back.map(({ held }) => held), kept: [...back.map(({ kept }) => kept), ...resending] }
}

  const entries = useRef(restored)
  const [keeping, setKeeping] = useState(true)
  const store = (next: ReadonlyArray<KeptEntry>) => {
    if (next === entries.current) return
    entries.current = next

import { type ReactNode, useState } from "react"
import { useConnectivity } from "../api/hooks.ts"
import type { Draft } from "./drafts.ts"
import type { Restored } from "./restored.ts"
import type { Sending } from "./sending.ts"
import { type Sheets, SheetsContext } from "./sheets-context.ts"
import {
  discardedState,
  dismissedState,
  expiredState,
  failedState,
  keptState,
  reopenedState,
  restoredState,
  savedState,
  sendingState,
  shownState,
} from "./sheets-state.ts"
import { TOAST_MS } from "./undo.ts"
import { useHeldDrafts } from "./use-held-drafts.ts"
import { useKeptEntries } from "./use-kept-entries.ts"
import { useReopenWhenReady } from "./use-reopen.ts"
import { useResumedDraft } from "./use-resumed-draft.ts"
import { useSend } from "./use-send.ts"

interface SheetsProviderProps {
  readonly draft: Draft | null
  readonly restored: Restored
  readonly children: ReactNode
}

export const SheetsProvider = ({ draft, restored, children }: SheetsProviderProps) => {
  const [state, setState] = useState(() => restoredState(restored.held))
  const [editing, setEditing] = useState<string | null>(null)
  const kept = useKeptEntries(restored.kept)
  const online = useConnectivity() === "online"
  useHeldDrafts(state.held)
  useReopenWhenReady(state, () => setState(reopenedState))
  const sweepAfter = (shownAt: number) =>
    setTimeout(() => setState((current) => expiredState(current, shownAt + TOAST_MS)), TOAST_MS)
  const mutation = useSend({
    onFailed: (failed) => {
      kept.failed(failed)
      const now = Date.now()
      setState((current) => failedState(current, failed, now))
      sweepAfter(now)
    },
    onSaved: (sending, saved) => {
      kept.done(sending)
      const now = Date.now()
      setState((current) => savedState(current, sending, saved, now))
      sweepAfter(now)
    },
  })
  const send = (sending: Sending) => {
    kept.sending(sending)
    setState((current) => sendingState(current, sending, online))
    mutation.mutate(sending)
  }
  useResumedDraft(draft, send)
  const sheets: Sheets = {
    ...state,
    editing,
    keeping: kept.keeping,
    busy: mutation.isPending ? (mutation.variables ?? null) : null,
    show: (sheet, record) => {
      setEditing(record ?? null)
      setState((current) => shownState(current, sheet))
    },
    close: () => setState(dismissedState),
    keep: () => setState(keptState),
    discard: (failed) => {

    },

  }
