# M3.7 Calendar Day View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 12 Oct 2026) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** History shows one day by the hour, so a parent can see when she fed, on which side, and when each diaper came. Tapping an entry shows its details, and tapping an empty hour logs something there.

**Architecture:**
- **The layout** (`packages/domain/src/calendar/`, pure, held at 100 % coverage): `layoutDay` turns a day's bounds, its feed blocks and its points into hour rows, blocks in lanes with each side as a band, gathered markers and the now line, all in 5-minute steps. `slotIn` turns a tap into its quarter hour.
- **The sheets frame** (`apps/web/src/sheets/`, M1.12's): `showAt(sheet, at)` opens a create sheet at a given time, and `show()` goes back to Now.
- **The day** (`apps/web/src/api/day.ts`): `useDay(date)` reads M3.6's `GET /api/days/:date`, keyed `["day", date]`, so every save's `changed` keys and the socket refresh it.
- **The page** (`apps/web/src/features/history/`):
  - The model runs in Node tests: the address and day navigation, the totals line, blocks and markers from a day, their labels, an entry's details and the hour labels.
  - The components draw the switcher, the totals and growth strip, the grid, the details sheet and the Log-at menu.

**Tech Stack:** React 19.3.0, TypeScript 5.9.3, TanStack Router 1.170.41 (search params) and Query 5.104.1, `effect` 4.0.1 (Schema), `@bt/contracts` and `@bt/domain`, shadcn on Base UI 1.8.0 (M1.12's Drawer, `Button`), Tailwind CSS 4.3.3 (functional `@utility` classes and `@source inline`), `lucide-react` 1.51.0, Vitest 4.1.11 with fast-check 4.10.2, Playwright 1.64.0, oxlint 1.87.0 and oxfmt 0.72.0, Node 24.21.0. M3.7 adds no package.

## Decisions this plan makes (veto in review)

- **P1: Order.**
  - Tasks 1–2 build the layout and the sheets' opening time on `main` alone.
  - Task 3 waits for M3.6's merge (the gate below Task 2), and Tasks 3–6 build the screen on M3.6's day read.
  - Task 7 writes the docs. One PR.
- **P2: The grid's scale, without `style`.**
  - 60 px an hour, drawn in 5-minute steps of 5 px (`--cal-step: 5px` on the grid). A block is at least 4 steps tall (20 minutes, room for one line), and a marker 5 (25 minutes).
  - Positions come from Tailwind utilities, not `style` (react-code-standards): `cal-at` and `cal-tall` add up a step count from `cal-at-tens-*`/`cal-at-ones-*` and `cal-tall-tens-*`/`cal-tall-ones-*`. Lanes use `cal-lanes-*` and `cal-lane-*`. `@source inline` lists them (0–30 tens, 0–9 ones, up to 6 lanes), since the class names are built at run time.
  - Splitting into tens and ones keeps that list to 94 classes. A class per step (`cal-top-0…300`) added 4.6 kB gzip of CSS; this adds about 1 kB, all of M3.7's CSS included.
- **P3: A feed's block** (Andrew, 12 Oct 2026).
  - It runs from its first side's start to its last part's end, so a bottle given after the sides stays inside it (`sessionBounds`).
  - Each side is a band inside it, placed in proportion to the block. A short feed's band fills its taller block rather than leaving a false pause. The left side is darker (`bg-primary/40`) than the right (`bg-primary/20`); the rest of the block is hollow (`bg-card`).
  - Its label is "Nursing 14m L · 9m R · 60 mL", minutes floored; a side under a minute reads "<1m".
  - A feed that started yesterday or runs into tomorrow is cut at the day's edge, with that edge flat. A running feed reaches the phone's clock and grows each minute.
- **P4: Markers.**
  - A bottle on its own and each diaper is a marker, in a column on the right, so markers never cover blocks.
  - Markers whose chips would overlap gather into one, "2 entries", anchored on the first, so a gathered chip never runs into the next.
  - A diaper's chip uses the Diaper sheet's own words (Pee, Poo, Both); "Pee and poo" didn't fit at 360 px. A bottle's chip is its amount in the household's unit.
- **P5: Lanes.** Blocks that overlap on screen share the width side by side. They sort by start, then end, then id, and a block takes the first lane free at its top; half-open, so a block that ends as another starts shares its lane. The lane count is the most any overlapping group needs. Real days rarely need two lanes before sleep arrives (D9 keeps nursing sides apart); the grid styles up to 6.
- **P6: Hours.**
  - One row per real hour inside the household's day bounds, which come from the day read: 23 on the day the clocks go forward, 25 when they go back (AC 23).
  - Each row is labelled on the household's clock ("1 AM"), so the repeated hour shows twice. Its "Log at" name tells them apart as "(first)" and "(second)", as D11's picker does.
  - A day whose midnight never happened starts at its first moment (Santiago).
- **P7: Tapping an entry** (Andrew, 12 Oct 2026).
  - A block or a single marker opens the details sheet ("details", a new `SheetKind`): the time or range on the household's clock, its sides, any pause, any bottle (breast milk, formula or both), and "Logged by …".
  - A running or paused feed opens the Nursing sheet instead, as Today does.
  - A gathered marker opens the same sheet, listing its entries.
  - A measurement in the growth strip opens its edit sheet (`show("measurement", id)`).
- **P8: Tapping an empty slot** (Andrew, 12 Oct 2026).
  - Each hour row is a button, "Log at 2 AM". Where the tap lands in it picks the quarter hour, rounded down; from the keyboard, which gives no position, it's the hour's start.
  - On today, a tap after now does nothing, and later hours are disabled.
  - The menu ("logAt", a new `SheetKind`) is titled "Log at 2:15 AM", with Bottle, Nursing (the past-feed sheet), Diaper and Measurement. The chosen sheet opens through `showAt(sheet, at)`.
  - `showAt` sets a time each create form's session starts its When at; a held entry's own time still wins, and `show()` clears it, so Today's quick actions still start at Now.
- **P9: The page and its address.**
  - The page is titled "History", with her name below. The switcher reads "‹ Fri, Oct 9 ›" with "Today", or a "Back to today" link on another day.
  - The day lives in the address: `/history?date=2026-10-08`. With no date, History follows the household's today and turns over at its midnight, through the minute clock (M5.4's hand-off). A date after today, or one that isn't real, shows today.
  - "‹" stops at her birth date and "›" at today. There's no swiping.
- **P10: Above the grid.**
  - One or two lines of the day's totals, worded as on Today's card: "7 feeds started · 1 h 52 min nursing · 540 mL in bottles" and "8 diapers · 6 pee · 3 poo", leaving out what didn't happen, or "Nothing logged."
  - The growth strip: a button per measurement, "8:00 AM 4.21 kg · 55.0 cm · 37.5 cm".
- **P11: Where the grid opens.** Scrolled so now is in the middle on today, and the first entry on another day; at the top when the day is empty.
- **P12: No pending entries in the day's cache.** A save from History shows on the grid once the household confirms it, since its `changed` keys include the day. Today still shows it at once, through M1.12's optimistic writes.
- **P13: The layout's tests.** Fixtures for the AC 23 days, a fall-back day with two 1 AMs, a spring-forward day, a day whose midnight never happened, and properties over the repo's tricky zones:
  - hour rows tile every day
  - no two blocks that overlap on screen share a lane
  - every marker lands in exactly one cluster, with no two clusters overlapping
- **P14: The bundle.** Measured on the gate's merge (`9a3498b`) and on the final commit (`e1a4c86`):
  - the app's JS grows by 4.96 kB gzip, from 298.26 to 303.22 kB

## Review Focus

The five ways this is most likely to fail a parent, each with the test that pins it:

1. **A forgotten diaper logged from the calendar at the wrong time.**
   - The time sent must be the quarter hour tapped, on the household's clock, whatever the phone's zone.
   - Pinned by `history-log.spec.ts` ("logs a diaper at the quarter hour tapped, and draws it once the household has it", Task 6) and `slot.test.ts` (Task 1).
2. **A feed across midnight.**
   - It must show on both days, cut at midnight, its sides split where they fell.
   - Pinned by `blocks.test.ts` ("cuts a feed that crosses midnight into the part on each day", Task 1) and `history-grid.spec.ts` ("draws the part of yesterday's feed after midnight…", Task 5).
3. **The nights the clocks change.**
   - 25 rows with two 1 AMs, or 23 with no 2 AM, every row a real hour.
   - Pinned by `hours.test.ts` (AC 23 and the zone property, Task 1), `history-grid.spec.ts` (Task 5) and `history-log.spec.ts` ("asks for both 1 AMs by name…", Task 6).
4. **Today's quick actions after History opened a sheet at a slot.**
   - They must start at Now again, not at the slot.
   - Pinned by `history-log.spec.ts` ("starts the quick actions on Today at Now again…", Task 6) and the session tests (Task 2).
5. **History left open past midnight.**
   - It must move to the new day.
   - Pinned by `history.spec.ts` ("moves to the new day at the household's midnight while it shows today", Task 3).

```ts
import type { Instant, Interval } from "../time/instant.ts"
import { type LocalResolution, localDateTimeOf, resolveLocal } from "../time/wall-clock.ts"
import type { TimeZone } from "../time/zone.ts"
import { type Placing, stepAt } from "./steps.ts"

export interface HourRow extends Interval {
  readonly top: number
  readonly height: number
  readonly repeated: boolean
}

const HOURS = Array.from({ length: 24 }, (_, hour) => String(hour).padStart(2, "0"))

const instantsOf = (resolution: LocalResolution): ReadonlyArray<Instant> => {
  if (resolution.kind === "ok") return [resolution.instant]
  return resolution.kind === "ambiguous" ? [resolution.earlier, resolution.later] : []
}

const hourStarts = (date: LocalDate, zone: TimeZone, bounds: Interval): ReadonlyArray<Instant> => {
  const starts = HOURS.flatMap((hour) => instantsOf(resolveLocal(`${date}T${hour}:00`, zone)))
  const inside = starts.filter((at) => at > bounds.start && at < bounds.end)
  return [...new Set([bounds.start, ...inside])].toSorted((a, b) => a - b)
}

export const hourRows = (date: LocalDate, zone: TimeZone, placing: Placing): ReadonlyArray<HourRow> => {
  const { bounds, scale } = placing
  const starts = hourStarts(date, zone, bounds)
  return starts.map((start, index) => {
    const end = starts[index + 1] ?? bounds.end
    const top = stepAt(bounds, scale.stepMs, start)
    const previous = starts[index - 1]
    return {
      start,
      end,
      top,
      height: stepAt(bounds, scale.stepMs, end) - top,
      repeated: previous !== undefined && localDateTimeOf(previous, zone) === localDateTimeOf(start, zone),
    }
  })
}
```

```ts
export interface Extent {
  readonly top: number
  readonly height: number
}

export interface Laned {
  readonly lane: number
  readonly lanes: number
}

const freeLane = (ends: ReadonlyArray<number>, top: number) => {
  const free = ends.findIndex((end) => end <= top)
  return free === -1 ? ends.length : free
}

const overlapGroups = <T extends Extent>(items: ReadonlyArray<T>): ReadonlyArray<ReadonlyArray<T>> => {
  const groups: T[][] = []
  let group: T[] = []
  let reach = Number.NEGATIVE_INFINITY
  for (const item of items) {
    if (item.top >= reach) {
      group = []
      groups.push(group)
    }
    group.push(item)
    reach = Math.max(reach, item.top + item.height)
  }
  return groups
}

export const placeInLanes = <T extends Extent>(items: ReadonlyArray<T>): ReadonlyArray<T & Laned> => {
  const ends: number[] = []
  const laned = items.map((item) => {
    const lane = freeLane(ends, item.top)
    ends[lane] = item.top + item.height
    return { ...item, lane }
  })
  return overlapGroups(laned).flatMap((group) => {
    const lanes = Math.max(...group.map(({ lane }) => lane)) + 1
    return group.map((item) => ({ ...item, lanes }))
  })
}
```

```ts
  readonly kind: Kind
}

export interface CalendarBlock<Kind extends string> extends Span {
  readonly id: string
  readonly bands: ReadonlyArray<CalendarBand<Kind>>
}

  readonly kind: Kind
}

export interface PlacedBlock<Kind extends string> extends Extent {
  readonly id: string
  readonly lane: number
  readonly lanes: number
  readonly running: boolean
  readonly startsBefore: boolean
  readonly endsAfter: boolean
  readonly bands: ReadonlyArray<PlacedBand<Kind>>
}

const endOf = (span: Span, now: Instant) => span.endedAt ?? Math.max(now, span.startedAt)

const fragmentOf = (span: Span, { bounds, now }: Placing): Interval | null => {
  const start = Math.max(span.startedAt, bounds.start)
  const end = Math.min(endOf(span, now), bounds.end)
  const visible = span.startedAt === endOf(span, now) ? contains(bounds, span.startedAt) : start < end
  return visible ? { start, end } : null
}

const extentOf = (fragment: Interval, { bounds, scale, steps }: Placing): Extent => {
  const top = stepAt(bounds, scale.stepMs, fragment.start)
  const height = Math.min(Math.max(stepAt(bounds, scale.stepMs, fragment.end) - top, scale.minBlockSteps), steps)
  return { top: Math.min(top, steps - height), height }
}

const shareOf = (fragment: Interval, at: Instant, ifInstant: number) =>
  fragment.end === fragment.start ? ifInstant : (at - fragment.start) / (fragment.end - fragment.start)

const bandsOf = <Kind extends string>(
  block: CalendarBlock<Kind>,
  fragment: Interval,
  height: number,
  now: Instant,
): ReadonlyArray<PlacedBand<Kind>> =>
  block.bands.flatMap((band) => {
    const top = Math.round(shareOf(fragment, Math.max(band.startedAt, fragment.start), 0) * height)
    const bottom = Math.round(shareOf(fragment, Math.min(endOf(band, now), fragment.end), 1) * height)
    return bottom > top ? [{ kind: band.kind, top, height: bottom - top }] : []
  })

  a.top - b.top || a.top + a.height - (b.top + b.height) || (a.id < b.id ? -1 : 1)
```

```ts
import { contains } from "../interval/interval.ts"
import type { Instant } from "../time/instant.ts"
import { type Placing, stepAt } from "./steps.ts"

export interface CalendarPoint {
  readonly id: string
  readonly at: Instant
}

export interface PlacedCluster {
  readonly top: number
  readonly ids: ReadonlyArray<string>
}

const byTimeThenId = (a: CalendarPoint, b: CalendarPoint) => a.at - b.at || (a.id < b.id ? -1 : 1)

export const clusterPoints = (
  points: ReadonlyArray<CalendarPoint>,
  { bounds, scale, steps }: Placing,
): ReadonlyArray<PlacedCluster> => {
  const lowest = Math.max(0, steps - scale.pointSteps)
  const clusters: { readonly top: number; readonly ids: string[] }[] = []
  for (const point of points.filter(({ at }) => contains(bounds, at)).toSorted(byTimeThenId)) {
    const top = Math.min(stepAt(bounds, scale.stepMs, point.at), lowest)
    const last = clusters.at(-1)
    if (last !== undefined && top < last.top + scale.pointSteps) last.ids.push(point.id)
    else clusters.push({ top, ids: [point.id] })
  }
  return clusters
}
```

```ts
import { type Instant, type Interval, MINUTE_MS } from "../time/instant.ts"

export const QUARTER_HOUR_MS = 15 * MINUTE_MS

export const slotIn = (row: Interval, fraction: number, now: Instant): Instant | null => {
  const tapped = row.start + (row.end - row.start) * Math.min(Math.max(fraction, 0), 1)
  if (tapped > now) return null
  const quarters = Math.floor((Math.min(tapped, row.end - 1) - row.start) / QUARTER_HOUR_MS)
  return row.start + quarters * QUARTER_HOUR_MS
}
```

```ts
import { LocalDate } from "@bt/contracts"
import { addDaysToDate } from "@bt/domain"
import { flow, Option, Schema } from "effect"

export interface HistorySearch {
  readonly date?: LocalDate | undefined
}

export interface DayNavigation {
  readonly date: LocalDate
  readonly isToday: boolean
  readonly previous: HistorySearch | null
  readonly next: HistorySearch | null
}

const decodeDate = Schema.decodeUnknownOption(LocalDate)

export const dateInSearch = flow(decodeDate, Option.getOrUndefined)

export const shownDate = (asked: LocalDate | undefined, today: LocalDate): LocalDate =>
  asked !== undefined && asked < today ? asked : today

const searchFor = (date: LocalDate, today: LocalDate): HistorySearch => (date === today ? {} : { date })

export const navigationOf = (date: LocalDate, today: LocalDate, birthDate: LocalDate): DayNavigation => ({
  date,
  isToday: date === today,
  previous: date > birthDate ? searchFor(addDaysToDate(date, -1), today) : null,
  next: date < today ? searchFor(addDaysToDate(date, 1), today) : null,
})

export const dayTitle = (date: LocalDate, locale?: string) =>
  new Intl.DateTimeFormat(locale, { weekday: "short", month: "short", day: "numeric", timeZone: "UTC" }).format(
    Date.parse(`${date}T12:00:00Z`),
  )
```

```ts
import type { Measurement, Totals, Units, VolumeUnit } from "@bt/contracts"

export interface GrowthItem {
  readonly id: string
  readonly time: string
  readonly values: ReadonlyArray<string>
  readonly name: string
}

const counted = (count: number, one: string, many: string) => `${count} ${count === 1 ? one : many}`

export const totalsLines = (totals: Totals, volume: VolumeUnit): ReadonlyArray<ReadonlyArray<string>> =>
  [
    presentParts([
      [totals.feedsStarted, counted(totals.feedsStarted, "feed started", "feeds started")],
      [totals.nursingSeconds, `${formatMinutes(totals.nursingSeconds)} nursing`],
      [totals.bottleMl, `${formatVolume(totals.bottleMl, volume)} in bottles`],
    ]),
    presentParts([
      [totals.diapers, counted(totals.diapers, "diaper", "diapers")],
      [totals.wetDiapers, `${totals.wetDiapers} pee`],
      [totals.dirtyDiapers, `${totals.dirtyDiapers} poo`],
    ]),
  ].filter((parts) => parts.length > 0)

export const growthItems = (
  measurements: ReadonlyArray<Measurement>,
  units: Units,
  timeZone: string,
  locale?: string,
): ReadonlyArray<GrowthItem> =>
  measurements.map((measurement) => {
    const time = clockTime(measurement.measuredAt, timeZone, locale)
    return {
      id: measurement.id,
      time,
      values: GROWTH_METRICS.flatMap(({ metric, recorded }) => {
        const value = recorded(measurement)
        return value === null ? [] : [formatMeasurement(metric, value, units)]
      }),
      name: `Edit the measurement from ${time}`,
    }
```

```ts
import type { DayPeriod, Diaper, Feed } from "@bt/contracts"
import {
  type CalendarBlock,
  type CalendarPoint,
  type DayGrid,
  type GridScale,
  layoutDay,
  sessionBounds,
  type Side,
} from "@bt/domain"

export const SCALE: GridScale = { stepMs: 5 * 60_000, minBlockSteps: 4, pointSteps: 5 }

export type Entry =
  | { readonly kind: "feed"; readonly feed: Feed }
  | { readonly kind: "diaper"; readonly diaper: Diaper }

export interface DayModel {
  readonly grid: DayGrid<Side>
  readonly entries: ReadonlyMap<string, Entry>
}

const isNursing = (feed: Feed) => feed.segments.length > 0

const blockOf = (feed: Feed): ReadonlyArray<CalendarBlock<Side>> => {
  const span = sessionBounds(feed)
  if (span === null) return []
  const bands = feed.segments.map(({ side, startedAt, endedAt }) => ({ kind: side, startedAt, endedAt }))
  return [{ id: feed.id, ...span, bands }]
}

const pointsOf = (day: DayPeriod): ReadonlyArray<CalendarPoint> => [
  ...day.feeds.filter((feed) => !isNursing(feed)).map(({ id, startedAt }) => ({ id, at: startedAt })),
  ...day.diapers.map(({ id, occurredAt }) => ({ id, at: occurredAt })),
]

const entriesOf = (day: DayPeriod): ReadonlyMap<string, Entry> =>
  new Map<string, Entry>([
    ...day.feeds.map((feed) => [feed.id, { kind: "feed", feed }] as const),
    ...day.diapers.map((diaper) => [diaper.id, { kind: "diaper", diaper }] as const),
  ])

export const dayModel = (day: DayPeriod, zone: string, now: number): DayModel => ({
  grid: layoutDay(
    {
      date: day.date,
      zone,
      bounds: day.bounds,
      now,
      blocks: day.feeds.filter(isNursing).flatMap(blockOf),
      points: pointsOf(day),
    },
    SCALE,
  ),
  entries: entriesOf(day),
})

export const entriesIn = (model: DayModel, ids: ReadonlyArray<string>): ReadonlyArray<Entry> =>
  ids.flatMap((id) => {
    const entry = model.entries.get(id)
    return entry === undefined ? [] : [entry]
  })

export const isLiveFeed = (entries: ReadonlyArray<Entry>) => {
  const [only] = entries
  return entries.length === 1 && only?.kind === "feed" && only.feed.status === "active"
}

export const anchorOf = (model: DayModel): number => {
  if (model.grid.now !== null) return model.grid.now
  const tops = [...model.grid.blocks, ...model.grid.clusters].map(({ top }) => top)
  return tops.length === 0 ? 0 : Math.min(...tops)
}
```

```ts
import type { Diaper, Feed, VolumeUnit } from "@bt/contracts"
import { feedSummary } from "@bt/domain"
import { clockTime } from "../../clock-time.ts"
import type { Display } from "../today/display.ts"
import { feedParts, feedTitle } from "../today/feed-parts.ts"
import { formatVolume, presentParts } from "../today/format.ts"
import type { Entry } from "./day-model.ts"

const MINUTE_S = 60
const HOUR_MIN = 60

export const shortMinutes = (seconds: number) => {
  if (seconds > 0 && seconds < MINUTE_S) return "<1m"
  const minutes = Math.floor(seconds / MINUTE_S)
  const hours = Math.floor(minutes / HOUR_MIN)
  const rest = minutes % HOUR_MIN
  if (hours === 0) return `${minutes}m`
  return rest === 0 ? `${hours}h` : `${hours}h ${rest}m`
}

export const diaperText = ({ wet, dirty }: Diaper) => {
  if (wet && dirty) return "Pee and poo"
  return wet ? "Pee" : "Poo"
}

export const blockText = (feed: Feed, volume: VolumeUnit, now: number) => {
  const { leftSeconds, rightSeconds, bottleMl } = feedSummary(feed, now)
  const parts = presentParts([
    [leftSeconds, `${shortMinutes(leftSeconds)} L`],
    [rightSeconds, `${shortMinutes(rightSeconds)} R`],
    [bottleMl, formatVolume(bottleMl, volume)],
  ])
  return parts.length === 0 ? "Nursing" : `Nursing ${parts.join(" · ")}`
}

const diaperChip = ({ wet, dirty }: Diaper) => {
  if (wet && dirty) return "Both"
  return wet ? "Pee" : "Poo"
}

export const markerText = (entry: Entry, volume: VolumeUnit, now: number) =>
  entry.kind === "diaper" ? diaperChip(entry.diaper) : formatVolume(feedSummary(entry.feed, now).bottleMl, volume)

const progressOf = (feed: Feed) => {
  if (feed.status === "completed") return []
  return [feed.segments.some(({ endedAt }) => endedAt === null) ? "in progress" : "paused"]
}

export const entryName = (entry: Entry, display: Display, now: number) => {
  const time = (at: number) => clockTime(at, display.timeZone, display.locale)
  if (entry.kind === "diaper") return `Diaper at ${time(entry.diaper.occurredAt)}: ${diaperText(entry.diaper)}`
  const { feed } = entry
  const details = [...progressOf(feed), ...feedParts(feed, display.volume, now)]
  return `${feedTitle(feed)} at ${time(feed.startedAt)}: ${details.join(", ")}`
}

export const clusterName = (count: number, first: number, display: Display) =>
  `${count} entries from ${clockTime(first, display.timeZone, display.locale)}`
```

```ts
import type { Feed } from "@bt/contracts"
import { feedSummary, sessionBounds } from "@bt/domain"
import type { Display } from "../today/display.ts"
import { feedTitle } from "../today/feed-parts.ts"
import { formatMinutes, formatVolume, presentParts } from "../today/format.ts"
import type { Entry } from "./day-model.ts"
import { diaperText } from "./entry-labels.ts"

export interface EntryDetails {
  readonly id: string
  readonly title: string
  readonly when: string
  readonly lines: ReadonlyArray<string>
  readonly by: string
}

const MS_PER_SECOND = 1000

const whenOf = (start: number, end: number, display: Display) => {
  const format = new Intl.DateTimeFormat(display.locale, {
    weekday: "short",
    month: "short",
    day: "numeric",
    hour: "numeric",
    minute: "2-digit",
    timeZone: display.timeZone,
  })
  return end > start ? format.formatRange(start, end) : format.format(start)
}

const byOf = ({ caregivers }: Display, id: string) => {
  const name = caregivers.find((caregiver) => caregiver.id === id)?.displayName
  return name === undefined ? "" : `Logged by ${name}`
}

const pausedSeconds = (feed: Feed, now: number) => {
  const span = sessionBounds(feed)
  if (span === null || feed.segments.length === 0) return 0
  const nursed = feedSummary(feed, now).nursingSeconds
  const lastSide = Math.max(...feed.segments.map(({ endedAt }) => endedAt ?? now))
  return Math.max(0, Math.floor((lastSide - span.startedAt) / MS_PER_SECOND) - nursed)
}

const statusOf = (feed: Feed) => {
  if (feed.status === "completed") return []
  return [feed.segments.some(({ endedAt }) => endedAt === null) ? "In progress" : "Paused"]
}

const bottleLines = (bottleMl: number, breastMilkMl: number, formulaMl: number, { volume }: Display) => {
  if (bottleMl === 0) return []
  const bottle = `Bottle ${formatVolume(bottleMl, volume)}`
  if (formulaMl === 0) return [`${bottle} breast milk`]
  if (breastMilkMl === 0) return [`${bottle} formula`]
  return [`${bottle}: breast milk ${formatVolume(breastMilkMl, volume)} · formula ${formatVolume(formulaMl, volume)}`]
}

const feedLines = (feed: Feed, display: Display, now: number) => {
  const { leftSeconds, rightSeconds, bottleMl, breastMilkMl, formulaMl } = feedSummary(feed, now)
  const paused = pausedSeconds(feed, now)
  const sides = presentParts([
    [leftSeconds, `Left ${formatMinutes(leftSeconds)}`],
    [rightSeconds, `Right ${formatMinutes(rightSeconds)}`],
  ])
  return [
    ...statusOf(feed),
    ...(sides.length === 0 ? [] : [sides.join(" · ")]),
    ...(paused === 0 ? [] : [`Paused ${formatMinutes(paused)}`]),
    ...bottleLines(bottleMl, breastMilkMl, formulaMl, display),
  ]
}

const feedDetails = (feed: Feed, display: Display, now: number): EntryDetails => {
  const span = sessionBounds(feed)
  const end = span?.endedAt ?? now
  return {
    id: feed.id,
    title: feedTitle(feed),
    when: whenOf(feed.startedAt, end, display),
    lines: feedLines(feed, display, now),
    by: byOf(display, feed.createdBy),
  }
}

export const entryDetails = (entry: Entry, display: Display, now: number): EntryDetails => {
  if (entry.kind === "feed") return feedDetails(entry.feed, display, now)
  const { diaper } = entry
  return {
    id: diaper.id,
    title: "Diaper",
    when: whenOf(diaper.occurredAt, diaper.occurredAt, display),
    lines: [diaperText(diaper)],
    by: byOf(display, diaper.createdBy),
  }
}
```

```ts
import type { Display } from "../today/display.ts"
import { type DayModel, type Entry, entriesIn } from "./day-model.ts"
import { clusterName, entryName, markerText } from "./entry-labels.ts"

export type MarkerKind = "bottle" | "diaper" | "several"

export interface Marker {
  readonly key: string
  readonly top: number
  readonly ids: ReadonlyArray<string>
  readonly kind: MarkerKind
  readonly text: string
  readonly name: string
}

const timeOf = (entry: Entry) => (entry.kind === "diaper" ? entry.diaper.occurredAt : entry.feed.startedAt)

const markerOf = (cluster: PlacedCluster, model: DayModel, display: Display, now: number): Marker => {
  const entries = entriesIn(model, cluster.ids)
  const [first] = entries
  const placed = { key: cluster.ids.join(), top: cluster.top, ids: cluster.ids }
  if (entries.length === 1 && first !== undefined) {

    return { ...placed, kind, text: markerText(first, display.volume, now), name: entryName(first, display, now) }

  const from = first === undefined ? 0 : timeOf(first)
  return {
    ...placed,
    kind: "several",
    text: `${entries.length} entries`,
    name: clusterName(entries.length, from, display),
  }
}
```
