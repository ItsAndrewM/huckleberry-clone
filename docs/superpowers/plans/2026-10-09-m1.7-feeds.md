# M1.7 Feeds Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 9 Oct 2026) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parents can log a feed after the fact and run a nursing feed live: start it, switch sides, pause, resume, add a bottle, and finish. They can also fix any segment or bottle in it, and move, delete or restore a whole feed, all through the household's API. Every change keeps one version for the whole feed (D3), never lets two nursing segments overlap (D9), and answers the query keys it changed.

**Architecture:** `packages/contracts` gains the feed record, its payloads, `FeedConflict`, and three groups in `Api`: `feeds`, `segments` and `portions`. In the Worker, migration `0004` adds `feeds`, `nursing_segments` and `bottle_portions`. `src/core/feeds/` holds the synchronous core:
- `store.ts` reads and writes rows, and recomputes a feed's session bounds from its live segments and bottles.
- `rules.ts` holds what every feed mutation shares: field checks, M1.6's order of refusals, the D9 overlap check, `FEED_EMPTY`, and the changed keys.
- `log.ts`, `lifecycle.ts`, `components.ts` and `feed-edits.ts` hold the fourteen operations.

`src/feed-handlers.ts` runs each endpoint through M1.6's `mutations`. Before any of that, the diapers core's time checks and its `changedKeys` move to a shared `core/calendar.ts`, as the M1.6 handoff asked.

**Tech Stack:** TypeScript 5.9.3, `effect` 4.0.1 (Schema, `effect/http`, `effect/http-api`), `@bt/contracts`, `@bt/domain`, Workers and Durable Objects (`@cloudflare/workers-types` 5.20261006.1, wrangler 4.148.0), `@cloudflare/vitest-plugin` 1.3.7, Vitest 4.1.11, Playwright 1.64.0, oxlint 1.87.0 + oxfmt 0.72.0, Node 24.21.0. ## Decisions this plan makes (veto in review)

- **P1: A feed is its nursing segments and its bottles, and nothing else** (the spec's §8 isn't in the repo; this mirrors Andrew's diaper decision of 9 Oct 2026).
  - A segment is a side (`left` or `right`), a start, and an end that's `null` while it runs. A bottle (a "portion") is a time, breast milk mL and formula mL, so a mixed bottle is one portion (M1.2's P6, AC 3).
  - A feed is `active` or `completed`. Paused isn't stored: it's an active feed with no running segment.
  - The record the API answers carries the feed's `id`, `status`, its session `startedAt` and `endedAt`, its live `segments` and `portions` in time order, and the audit fields M1.6's `Diaper` carries. Segments and portions carry only their `id` and their own fields: who changed a part shows on the feed.
- **P2: Migration `0004-feeds` adds three `STRICT` tables.**
  - Each has D4's `source` and `source_ref`, with the partial unique index, and the audit columns.
  - `CHECK`s keep the event times inside `Instant`'s years (2000 up to, not including, 2100). This closes, for these tables, the M1.6 deferred minor about a stored time outside `Instant`'s range. They also keep sides and statuses to their values, require a segment's end to come after its start, keep both amounts at zero or more with some milk, and require a completed feed to have an end.
  - `feeds_one_active`, a partial unique index on live active feeds, keeps the table to one at most.
  - Indexes: `(started_at, ended_at)` on `feeds` and `nursing_segments` (§3.3), `feed_id` on both component tables, and `occurred_at` on `bottle_portions`.
- **P3: Segments and portions are deleted softly, and keep their `source_ref`.** A re-import then skips a row the parent deleted (AC 24). There's no endpoint to restore one part: M1.7's row has none. A feed's restore brings back the parts that were live when it was deleted.
- **P4: A live feed always has a segment or a portion.** Any request that would leave one empty answers 409 `FEED_EMPTY` with the feed as it is, unless it carries `deleteIfEmpty: true`.
  - With `deleteIfEmpty`, it deletes the feed as it stands and keeps that last part live, so a restore brings it all back.
  - Two requests can do it:
    - Finishing a feed whose running side is corrected back to its own start. The stop-time correction says "I didn't feed on this side". A running side corrected that way is dropped.
    - Deleting the last segment or bottle. The row's note says "of a completed feed"; this applies the same offer to active feeds, so the rule holds for every live feed.
  - Switch and pause refuse a time at or before the running side's start (400 `end_not_after_start`), so neither can empty a feed.
- **P5: A feed stores its session bounds, recomputed from its live parts on every change** with M1.2's `sessionBounds`. A paused feed's session ends at its last part, so the active feed is found by `status`, never by a missing end (the M1.2 handoff). Segments are ordered by their start, and there's no `sequence` column: D9 makes the start a strict order. §5 mentions `sequence + 1`.
- **P6: The endpoints.** Each answers `{ feed, changed }`.
  - `POST /api/feeds` with `{ actionId, segments: [{ side, startedAt, endedAt }], portions: [{ occurredAt, breastMilkMl, formulaMl }] }` → 201. It logs a completed feed: manual entry, backdating, and the Bottle sheet's one-tap save.
  - `POST /api/feeds/start` with `{ actionId, side, startedAt }` → 201.
  - `POST /api/feeds/:id/switch` and `…/pause` with `{ actionId, version, occurredAt }`; `…/resume` with `{ actionId, version, side, occurredAt }`; `…/bottle` with `{ actionId, version, occurredAt, breastMilkMl, formulaMl }`; `…/finish` with `{ actionId, version, occurredAt, deleteIfEmpty }`. Each answers 200.
  - `PATCH /api/feeds/:id` with `{ actionId, version, startedAt }` moves the whole feed (P12). `DELETE /api/feeds/:id` and `POST /api/feeds/:id/restore` take M1.6's `VersionedAction`.
  - `PATCH /api/segments/:id` with `{ actionId, version, side, startedAt, endedAt }` and `PATCH /api/portions/:id` with `{ actionId, version, occurredAt, breastMilkMl, formulaMl }`. Both `DELETE`s take `{ actionId, version, deleteIfEmpty }`. Each `version` is the feed's (D3).
  - Every request sends every field (M1.6's P6). `deleteIfEmpty` is required where it appears, so a request has one canonical body for its hash.
- **P7: Every time a request sends is required, and it's the tap time** (M1.6's P7; §5 shows `occurredAt?`). A retry then keeps the moment the switch or bottle happened.
- **P8: The order of refusals is M1.6's P8, applied to feeds.**
  - An unknown id gets 404.
  - A stale version gets 409 `STALE_VERSION` with the feed as it is now, deleted or not.
  - The right version in the wrong state gets 404:
    - switching or pausing a feed with no running side
    - resuming one that's running
    - adding a bottle to, or finishing, a feed that isn't active
    - moving or deleting a deleted feed, or restoring a live one
    - editing or deleting a deleted part
  - §5 answers a switch while paused with "409 `InvalidInput`". Here it's 404, since the request's version was current.
  - Then the request's times are checked (400). Last come the rules that involve other records: `FEED_ALREADY_ACTIVE`, `SEGMENT_OVERLAP` and `FEED_EMPTY` (409). A 409 then always offers a choice about input that was otherwise valid.
- **P9: D9 covers the live segments of live feeds.**
  - A segment runs up to its end, not through it, so two segments may meet.
  - A running segment, stored or newly opened, counts as reaching 5 minutes past now (the M1.2 handoff's open question). Otherwise a manual segment saved in that window would collide with the running side once it grew.
  - Bottles never take part.
  - The 409's `current` is the feed holding the overlapped segment, which can be the feed being edited.
- **P10: The time rules.**
  - Every time a request uses is at most 5 minutes ahead of the server's clock (`in_future`, AC 21). Finishing a paused feed uses no time, so its `occurredAt` isn't checked.
  - Every start is on or after the first moment of the birth date in the household's time zone (`before_birth`).
  - A segment whose ends both come from the request (`POST /api/feeds`, `PATCH /api/segments/:id`) must end after it starts (`end_not_after_start`) and last at most 4 hours (`out_of_range`).
  - A segment closed by switch, pause or finish has no cap. Its length came from the clock, and finish's stop-time correction is how a parent fixes a forgotten timer.
  - The amounts and list caps are schema checks (400 `invalid`), the M1.3 handoff:
    - each amount from 0 to 500 mL, with at most one decimal, and some milk in every bottle
    - at most 20 segments and 20 bottles in one logged feed
    - at least one of either
  - `MAX_BOTTLE_ML`, `MAX_SEGMENT_MS` and `MAX_FEED_COMPONENTS` are exported for the client's forms.
- **P11: `changed` is `today`, `last24h`, and the day, week and month keys of the feed's session before and after the change** (D7). A running feed's session runs to now. Every part lies inside the session, so this covers every part's day.
  - A delete or restore of a feed adds `deleted`, as does a `deleteIfEmpty`.
  - Deleting a part doesn't add it, since parts don't appear in Recently deleted.
- **P12: Moving a feed shifts every live part by the same amount,** so the feed starts at `startedAt`.
  - It works on any live feed, running ones included.
  - The moved feed is checked as a whole: its start (`in_future`, `before_birth`), its latest part (`in_future`), and D9 against other feeds' segments.
  - It's how M3.4's "move whole feed" reaches the API.
- **P13: Restore re-runs D10's invariants:** `FEED_ALREADY_ACTIVE` for an active feed while another is active, then D9.
  - `feeds_one_active` stands behind the first check. A violation means a check was missed, so it's a defect (a logged 500 with nothing written), not a mapped 409.
  - D10's last sentence maps such violations to 409. The check always runs first, so that mapping would be dead code. Task 9 updates D10's text.
- **P14: The diapers core's time checks and `changedKeys` move to `core/calendar.ts`** (the M1.6 handoff). `calendarOf` reads the zone and the birth date in one query, once per mutation. That also fixes the M1.6 deferred minor about reading the zone twice.
- **P15: Each conflict class names its schema.** `Conflict<Self>()` takes an identifier first: `DiaperConflict` and `FeedConflict`. `docs/api.json` then shows `DiaperConflictEncoded` and `FeedConflictEncoded`, instead of the `ConflictEncoded_1` the M1.6 handoff predicted. Every conflict still says `_tag: "Conflict"` on the wire.
- **P16: One `FeedConflict` serves every feed endpoint.** Its codes are `FEED_ALREADY_ACTIVE`, `SEGMENT_OVERLAP`, `FEED_EMPTY`, `STALE_VERSION` and `ACTION_REPLAY_MISMATCH`, and `current` is always a `Feed` (the M1.6 handoff). `current` is:
  - for `FEED_ALREADY_ACTIVE`, the active feed
  - for `SEGMENT_OVERLAP`, the feed holding the overlapped segment
  - for `FEED_EMPTY`, the feed as it is
  - for `STALE_VERSION`, the feed as it is now
  - for `ACTION_REPLAY_MISMATCH`, the saved feed
- **P17: The handlers live in `src/feed-handlers.ts`,** in three groups (`feeds`, `segments`, `portions`), each running through M1.6's `mutations`. `http.ts` only merges them in.
- **P18: The Worker bundle grows from 244.85 to 250.13 KiB gzip,** well under the 400 KiB budget.

## Review Focus

1. **Two parents tap Switch at the same moment** (AC 13). Expect one switch saved and the other answered 409 `STALE_VERSION` with the switched feed, and never two running sides. Tested in Tasks 5 and 8.
2. **A Start retried after its answer was lost** (AC 14). Expect the stored 201 again and still one feed, never `FEED_ALREADY_ACTIVE` against itself. Tested in Task 8.
3. **A phone whose clock runs a few minutes fast** (AC 21). Expect times up to 5 minutes ahead to save. While a feed runs, expect a segment logged in the next 5 minutes to get `SEGMENT_OVERLAP`, because the running side will reach it. Tested in Tasks 4 and 5.
4. **A finish corrected back to the start of the only running side.** Expect 409 `FEED_EMPTY` with the feed. With `deleteIfEmpty`, the feed is deleted as it stood, and a restore brings it back still running. Tested in Tasks 5, 7 and 8.
5. **A feed moved from the last day of a month to the first of the next** (AC 17), or a segment moved across midnight (AC 7, AC 18). Expect `changed` to name both days, and both months, so both phones refresh both. Tested in Tasks 6 and 7.

Every operation that takes an id also carries M1.6's guard for its order of refusals. An edit to a feed the other parent just finished or deleted answers `STALE_VERSION` showing that, not 404. Tested in Tasks 5, 6 and 7.

import { runInDurableObject } from "cloudflare:test"
import { describe, expect, it } from "vitest"
import { calendarOf, changedKeys, timeIssue } from "../src/core/calendar.ts"
import { seededHousehold } from "./fixtures.ts"

const NOW = Date.UTC(2026, 9, 8, 19)
const MINUTE_MS = 60_000
const CALENDAR = { zone: "America/Vancouver", birthDate: "2026-09-01" }
const BIRTH_DATE_BEGINS = Date.UTC(2026, 8, 1, 7)
const SEP_30_AT_23_30 = Date.UTC(2026, 9, 1, 6, 30)
const OCT_1_AT_00_30 = Date.UTC(2026, 9, 1, 7, 30)

describe("the household's calendar", () => {
  it("is the household's time zone and the child's birth date, read in one query", async () => {
    const household = await seededHousehold()
    const calendar = await runInDurableObject(household, (_instance, state) => calendarOf(state.storage.sql))
    expect(calendar).toEqual(CALENDAR)
  })
})

describe("timeIssue", () => {
  it.each([
    ["5 minutes ahead of the server's clock, for a phone whose clock runs fast", NOW + 5 * MINUTE_MS, null],
    ["more than 5 minutes ahead of the server's clock", NOW + 5 * MINUTE_MS + 1, "in_future"],
    ["the first moment of the birth date in the household's time zone", BIRTH_DATE_BEGINS, null],
    ["before the birth date began in the household's time zone", BIRTH_DATE_BEGINS - 1, "before_birth"],
  ])("judges a time %s", (_label, at, issue) => {
    expect(timeIssue(CALENDAR, at, NOW)).toBe(issue)
  })
})

describe("changedKeys", () => {
  it("names today, last24h, and every day, week and month either interval touches", () => {
    const before = { start: SEP_30_AT_23_30, end: SEP_30_AT_23_30 }
    const after = { start: OCT_1_AT_00_30, end: OCT_1_AT_00_30 }
    expect(changedKeys(CALENDAR, before, after)).toEqual([
      ["today"],
      ["last24h"],
      ["day", "2026-09-30"],
      ["day", "2026-10-01"],
      ["week", "2026-W40"],
      ["month", "2026-09"],
      ["month", "2026-10"],
    ])
  })

  it("names only today and last24h when neither side has a time", () => {
    expect(changedKeys(CALENDAR, null, null)).toEqual([["today"], ["last24h"]])
  })

import type { BottlePortion, Feed, FeedStatus, NursingSegment, PortionEntry, Side } from "@bt/contracts"
import { sessionBounds } from "@bt/domain"
import type { Stamp } from "../receipts.ts"

type FeedRow = {
  id: string
  status: FeedStatus
  started_at: number
  ended_at: number | null
  version: number
  created_by: string
  created_at: number
  updated_by: string
  updated_at: number
  deleted_at: number | null
}

type SegmentRow = { id: string; side: Side; started_at: number; ended_at: number | null }

type PortionRow = { id: string; occurred_at: number; breast_milk_ml: number; formula_ml: number }

export type SegmentTimes = Omit<NursingSegment, "id">

type FeedHeader = Pick<Feed, "id" | "status" | "deletedAt">

const FEED_COLUMNS =
  "id, status, started_at, ended_at, version, created_by, created_at, updated_by, updated_at, deleted_at"

const segmentsOf = (sql: SqlStorage, feedId: string): NursingSegment[] =>
  sql
    .exec<SegmentRow>(
      `SELECT id, side, started_at, ended_at FROM nursing_segments
       WHERE feed_id = ? AND deleted_at IS NULL ORDER BY started_at`,
      feedId,
    )
    .toArray()
    .map((row) => ({ id: row.id, side: row.side, startedAt: row.started_at, endedAt: row.ended_at }))

const portionsOf = (sql: SqlStorage, feedId: string): BottlePortion[] =>
  sql
    .exec<PortionRow>(
      `SELECT id, occurred_at, breast_milk_ml, formula_ml FROM bottle_portions
       WHERE feed_id = ? AND deleted_at IS NULL ORDER BY occurred_at, rowid`,
      feedId,
    )
    .toArray()
    .map((row) => ({
      id: row.id,
      occurredAt: row.occurred_at,
      breastMilkMl: row.breast_milk_ml,
      formulaMl: row.formula_ml,
    }))

const feedFrom = (row: FeedRow, segments: NursingSegment[], portions: BottlePortion[]): Feed => ({
  id: row.id,
  status: row.status,
  startedAt: row.started_at,
  endedAt: row.ended_at,
  segments,
  portions,
  version: row.version,
  createdBy: row.created_by,
  createdAt: row.created_at,
  updatedBy: row.updated_by,
  updatedAt: row.updated_at,
  deletedAt: row.deleted_at,
})

export const loadFeed = (sql: SqlStorage, id: string): Feed | undefined => {
  const [row] = sql.exec<FeedRow>(`SELECT ${FEED_COLUMNS} FROM feeds WHERE id = ?`, id).toArray()
  return row === undefined ? undefined : feedFrom(row, segmentsOf(sql, id), portionsOf(sql, id))
}

export const insertSegment = (sql: SqlStorage, stamp: Stamp, feedId: string, segment: SegmentTimes): void => {
  sql.exec(
    `INSERT INTO nursing_segments (id, feed_id, side, started_at, ended_at, source, created_by, created_at, updated_by, updated_at)
     VALUES (?, ?, ?, ?, ?, 'app', ?, ?, ?, ?)`,
    crypto.randomUUID(),
    feedId,
    segment.side,
    segment.startedAt,
    segment.endedAt,
    stamp.caregiverId,
    stamp.now,
    stamp.caregiverId,
    stamp.now,
  )
}

export const insertPortion = (sql: SqlStorage, stamp: Stamp, feedId: string, portion: PortionEntry): void => {
  sql.exec(
    `INSERT INTO bottle_portions (id, feed_id, occurred_at, breast_milk_ml, formula_ml, source, created_by, created_at, updated_by, updated_at)
     VALUES (?, ?, ?, ?, ?, 'app', ?, ?, ?, ?)`,
    crypto.randomUUID(),
    feedId,
    portion.occurredAt,
    portion.breastMilkMl,
    portion.formulaMl,
    stamp.caregiverId,
    stamp.now,
    stamp.caregiverId,
    stamp.now,
  )
}

export const createFeed = (
  sql: SqlStorage,
  stamp: Stamp,
  status: FeedStatus,
  segments: ReadonlyArray<SegmentTimes>,
  portions: ReadonlyArray<PortionEntry>,
): Feed => {
  const bounds = sessionBounds({ segments, portions })
  if (bounds === null) throw new Error("A feed needs a nursing segment or a bottle")
  const row = sql
    .exec<FeedRow>(
      `INSERT INTO feeds (id, status, started_at, ended_at, version, source, created_by, created_at, updated_by, updated_at)
       VALUES (?, ?, ?, ?, 1, 'app', ?, ?, ?, ?) RETURNING ${FEED_COLUMNS}`,
      crypto.randomUUID(),
      status,
      bounds.startedAt,
      bounds.endedAt,
      stamp.caregiverId,
      stamp.now,
      stamp.caregiverId,
      stamp.now,
    )
    .one()
  for (const segment of segments) insertSegment(sql, stamp, row.id, segment)
  for (const portion of portions) insertPortion(sql, stamp, row.id, portion)
  return feedFrom(row, segmentsOf(sql, row.id), portionsOf(sql, row.id))
}

export const saveFeed = (sql: SqlStorage, stamp: Stamp, header: FeedHeader): Feed => {
  const segments = segmentsOf(sql, header.id)
  const portions = portionsOf(sql, header.id)
  const bounds = sessionBounds({ segments, portions })
  if (bounds === null) throw new Error(`Feed ${header.id} would be left with no nursing segment or bottle`)
  const row = sql
    .exec<FeedRow>(
      `UPDATE feeds SET status = ?, started_at = ?, ended_at = ?, deleted_at = ?, version = version + 1, updated_by = ?, updated_at = ?
       WHERE id = ? RETURNING ${FEED_COLUMNS}`,
      header.status,
      bounds.startedAt,
      bounds.endedAt,
      header.deletedAt,
      stamp.caregiverId,
      stamp.now,
      header.id,
    )
    .one()
  return feedFrom(row, segments, portions)
}

import {
  type Changed,
  type Feed,
  FeedConflict,
  type FieldError,
  InvalidInput,
  MAX_SEGMENT_MS,
  type PortionEntry,
} from "@bt/contracts"
import {
  FUTURE_TOLERANCE_MS,
  type Instant,
  type Interval,
  type Span,
  type ValidationIssue,
  validateEndAfterStart,
  validateNotInFuture,
} from "@bt/domain"
import { type Calendar, changedKeys, timeIssue } from "../calendar.ts"
import { loadFeed } from "./store.ts"

interface Exclusion {
  readonly feedId: string | null
  readonly segmentId: string | null
}

export const NO_EXCLUSION: Exclusion = { feedId: null, segmentId: null }

export const errorAt = (path: string, issue: ValidationIssue | null): FieldError[] =>
  issue === null ? [] : [{ path, issue }]

export const invalidUnless = (errors: ReadonlyArray<FieldError>): InvalidInput | null =>
  errors.length === 0 ? null : new InvalidInput({ fieldErrors: errors })

const endIssue = (startedAt: Instant, endedAt: Instant, now: Instant): ValidationIssue | null =>
  validateEndAfterStart(startedAt, endedAt) ??
  validateNotInFuture(endedAt, now) ??
  (endedAt - startedAt > MAX_SEGMENT_MS ? "out_of_range" : null)

export const segmentErrors = (calendar: Calendar, segment: Span, now: Instant, prefix: string): FieldError[] => [
  ...errorAt(`${prefix}startedAt`, timeIssue(calendar, segment.startedAt, now)),
  ...errorAt(`${prefix}endedAt`, segment.endedAt === null ? null : endIssue(segment.startedAt, segment.endedAt, now)),
]

export const portionErrors = (calendar: Calendar, portion: PortionEntry, now: Instant, prefix: string): FieldError[] =>
  errorAt(`${prefix}occurredAt`, timeIssue(calendar, portion.occurredAt, now))

export const overlappedFeed = (
  sql: SqlStorage,
  segments: ReadonlyArray<Span>,
  now: Instant,
  except: Exclusion,
): Feed | undefined => {
  const runningUntil = now + FUTURE_TOLERANCE_MS
  for (const segment of segments) {
    const [hit] = sql
      .exec<{ feed_id: string }>(
        `SELECT s.feed_id FROM nursing_segments s JOIN feeds f ON f.id = s.feed_id
         WHERE s.deleted_at IS NULL AND f.deleted_at IS NULL AND f.id IS NOT ? AND s.id IS NOT ?
           AND s.started_at < ? AND COALESCE(s.ended_at, ?) > ?
         ORDER BY s.started_at LIMIT 1`,
        except.feedId,
        except.segmentId,
        segment.endedAt ?? runningUntil,
        runningUntil,
        segment.startedAt,
      )
      .toArray()
    if (hit !== undefined) return loadFeed(sql, hit.feed_id)
  }
  return undefined
}

export const overlapConflict = (feed: Feed) => new FeedConflict({ code: "SEGMENT_OVERLAP", current: feed })

const spanOf = (feed: Feed, now: Instant): Interval => ({ start: feed.startedAt, end: feed.endedAt ?? now })

export const feedChanges = (calendar: Calendar, before: Feed | null, after: Feed | null, now: Instant): Changed =>
  changedKeys(calendar, before === null ? null : spanOf(before, now), after === null ? null : spanOf(after, now))

import { type Feed, type FeedConflict, InvalidInput, type NewFeed, type SegmentEntry } from "@bt/contracts"
import { type Instant, overlaps } from "@bt/domain"
import { type Calendar, calendarOf } from "../calendar.ts"
import type { CoreResult, Stamp } from "../receipts.ts"
import {
  feedChanges,
  invalidUnless,
  NO_EXCLUSION,
  overlapConflict,
  overlappedFeed,
  portionErrors,
  segmentErrors,
} from "./rules.ts"
import { createFeed } from "./store.ts"

const intervalOf = (segment: SegmentEntry) => ({ start: segment.startedAt, end: segment.endedAt })

const overlapEachOther = (segments: ReadonlyArray<SegmentEntry>) =>
  segments.some((first, index) =>
    segments.slice(index + 1).some((second) => overlaps(intervalOf(first), intervalOf(second))),
  )

const invalidEntry = (calendar: Calendar, entry: NewFeed, now: Instant): InvalidInput | null => {
  const invalid = invalidUnless([
    ...entry.segments.flatMap((segment, index) => segmentErrors(calendar, segment, now, `segments.${index}.`)),
    ...entry.portions.flatMap((portion, index) => portionErrors(calendar, portion, now, `portions.${index}.`)),
  ])
  if (invalid !== null || !overlapEachOther(entry.segments)) return invalid
  return new InvalidInput({ fieldErrors: [{ path: "segments", issue: "invalid" }] })
}

export const logFeed =
  (stamp: Stamp, entry: NewFeed) =>
  (sql: SqlStorage): CoreResult<Feed, InvalidInput | FeedConflict> => {
    const calendar = calendarOf(sql)
    const invalid = invalidEntry(calendar, entry, stamp.now)
    if (invalid !== null) return { ok: false, error: invalid }
    const overlapped = overlappedFeed(sql, entry.segments, stamp.now, NO_EXCLUSION)
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    const feed = createFeed(sql, stamp, "completed", entry.segments, entry.portions)
    return { ok: true, response: feed, changed: feedChanges(calendar, null, feed, stamp.now) }
  }

type FeedState = "live" | "active" | "paused" | "deleted"

type Found =
  | { readonly ok: true; readonly feed: Feed }
  | { readonly ok: false; readonly error: NotFound | FeedConflict }

type Running =
  | { readonly ok: true; readonly feed: Feed; readonly open: NursingSegment }
  | { readonly ok: false; readonly error: NotFound | FeedConflict }

interface Exclusion {
  readonly feedId: string | null
  readonly segmentId: string | null
}

export const NO_EXCLUSION: Exclusion = { feedId: null, segmentId: null }

export const errorAt = (path: string, issue: ValidationIssue | null): FieldError[] =>
  issue === null ? [] : [{ path, issue }]

export const invalidUnless = (errors: ReadonlyArray<FieldError>): InvalidInput | null =>
  errors.length === 0 ? null : new InvalidInput({ fieldErrors: errors })

const endIssue = (startedAt: Instant, endedAt: Instant, now: Instant): ValidationIssue | null =>
  validateEndAfterStart(startedAt, endedAt) ??
  validateNotInFuture(endedAt, now) ??
  (endedAt - startedAt > MAX_SEGMENT_MS ? "out_of_range" : null)

export const segmentErrors = (calendar: Calendar, segment: Span, now: Instant, prefix: string): FieldError[] => [
  ...errorAt(`${prefix}startedAt`, timeIssue(calendar, segment.startedAt, now)),
  ...errorAt(`${prefix}endedAt`, segment.endedAt === null ? null : endIssue(segment.startedAt, segment.endedAt, now)),
]

export const portionErrors = (calendar: Calendar, portion: PortionEntry, now: Instant, prefix: string): FieldError[] =>
  errorAt(`${prefix}occurredAt`, timeIssue(calendar, portion.occurredAt, now))

export const runningSegment = (feed: Feed) => feed.segments.find((segment) => segment.endedAt === null)

const isIn = (feed: Feed, wanted: FeedState): boolean => {
  if (wanted === "deleted") return feed.deletedAt !== null
  if (feed.deletedAt !== null) return false
  if (wanted === "live") return true
  if (feed.status !== "active") return false
  return wanted === "active" || runningSegment(feed) === undefined
}

export const feedFor = (sql: SqlStorage, id: string, version: number, wanted: FeedState): Found => {
  const feed = loadFeed(sql, id)
  if (feed === undefined) return { ok: false, error: new NotFound() }
  if (feed.version !== version) return { ok: false, error: new FeedConflict({ code: "STALE_VERSION", current: feed }) }
  return isIn(feed, wanted) ? { ok: true, feed } : { ok: false, error: new NotFound() }
}

export const runningFeedFor = (sql: SqlStorage, id: string, version: number): Running => {
  const found = feedFor(sql, id, version, "active")
  if (!found.ok) return found
  const open = runningSegment(found.feed)
  return open === undefined ? { ok: false, error: new NotFound() } : { ok: true, feed: found.feed, open }
}

export const activeFeed = (sql: SqlStorage): Feed | undefined => {
  const [row] = sql
    .exec<{ id: string }>("SELECT id FROM feeds WHERE status = 'active' AND deleted_at IS NULL")
    .toArray()
  return row === undefined ? undefined : loadFeed(sql, row.id)
}

export const overlappedFeed = (
  sql: SqlStorage,
  segments: ReadonlyArray<Span>,
  now: Instant,
  except: Exclusion,
): Feed | undefined => {
  const runningUntil = now + FUTURE_TOLERANCE_MS
  for (const segment of segments) {
    const [hit] = sql
      .exec<{ feed_id: string }>(
        `SELECT s.feed_id FROM nursing_segments s JOIN feeds f ON f.id = s.feed_id
         WHERE s.deleted_at IS NULL AND f.deleted_at IS NULL AND f.id IS NOT ? AND s.id IS NOT ?
           AND s.started_at < ? AND COALESCE(s.ended_at, ?) > ?
         ORDER BY s.started_at LIMIT 1`,
        except.feedId,
        except.segmentId,
        segment.endedAt ?? runningUntil,
        runningUntil,
        segment.startedAt,
      )
      .toArray()
    if (hit !== undefined) return loadFeed(sql, hit.feed_id)
  }
  return undefined
}

export const overlapConflict = (feed: Feed) => new FeedConflict({ code: "SEGMENT_OVERLAP", current: feed })

const spanOf = (feed: Feed, now: Instant): Interval => ({ start: feed.startedAt, end: feed.endedAt ?? now })

export const feedChanges = (calendar: Calendar, before: Feed | null, after: Feed | null, now: Instant): Changed =>
  changedKeys(calendar, before === null ? null : spanOf(before, now), after === null ? null : spanOf(after, now))

export const savedFeed = (
  calendar: Calendar,
  before: Feed | null,
  after: Feed,
  now: Instant,
): CoreResult<Feed, never> => ({
  ok: true,
  response: after,
  changed: feedChanges(calendar, before, after, now),
})

export const onlyComponent = (feed: Feed) => feed.segments.length + feed.portions.length === 1

export const deletedAsItStands = (
  sql: SqlStorage,
  stamp: Stamp,
  calendar: Calendar,
  feed: Feed,
): CoreResult<Feed, never> => ({
  ok: true,
  response: saveFeed(sql, stamp, { ...feed, deletedAt: stamp.now }),
  changed: [...feedChanges(calendar, feed, null, stamp.now), queryKeys.deleted],
})

export const whenEmptied = (
  sql: SqlStorage,
  stamp: Stamp,
  calendar: Calendar,
  feed: Feed,
  deleteIfEmpty: boolean,
): CoreResult<Feed, FeedConflict> =>
  deleteIfEmpty
    ? deletedAsItStands(sql, stamp, calendar, feed)
    : { ok: false, error: new FeedConflict({ code: "FEED_EMPTY", current: feed }) }

  savedFeed,
  whenEmptied,
} from "./rules.ts"
import { closeSegment, createFeed, insertPortion, insertSegment, removeSegment, saveFeed } from "./store.ts"

type Failure = InvalidInput | NotFound | FeedConflict

const OTHER_SIDE = { left: "right", right: "left" } as const

const closeIssue = (open: NursingSegment, at: Instant, now: Instant): ValidationIssue | null =>
  validateEndAfterStart(open.startedAt, at) ?? validateNotInFuture(at, now)

const finishIssue = (open: NursingSegment, at: Instant, now: Instant): ValidationIssue | null =>
  at < open.startedAt ? "end_not_after_start" : validateNotInFuture(at, now)

export const startFeed =
  (stamp: Stamp, start: FeedStart) =>
  (sql: SqlStorage): CoreResult<Feed, InvalidInput | FeedConflict> => {
    const calendar = calendarOf(sql)
    const invalid = invalidUnless(errorAt("startedAt", timeIssue(calendar, start.startedAt, stamp.now)))
    if (invalid !== null) return { ok: false, error: invalid }
    const active = activeFeed(sql)
    if (active !== undefined) {
      return { ok: false, error: new FeedConflict({ code: "FEED_ALREADY_ACTIVE", current: active }) }
    }
    const opened = { side: start.side, startedAt: start.startedAt, endedAt: null }
    const overlapped = overlappedFeed(sql, [opened], stamp.now, NO_EXCLUSION)
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    return savedFeed(calendar, null, createFeed(sql, stamp, "active", [opened], []), stamp.now)
  }

export const switchSide =
  (stamp: Stamp, id: string, action: TimedAction) =>
  (sql: SqlStorage): CoreResult<Feed, Failure> => {
    const found = runningFeedFor(sql, id, action.version)
    if (!found.ok) return found
    const { feed, open } = found
    const invalid = invalidUnless(errorAt("occurredAt", closeIssue(open, action.occurredAt, stamp.now)))
    if (invalid !== null) return { ok: false, error: invalid }
    const opened = { side: OTHER_SIDE[open.side], startedAt: action.occurredAt, endedAt: null }
    const overlapped = overlappedFeed(sql, [opened], stamp.now, { feedId: null, segmentId: open.id })
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    closeSegment(sql, stamp, open.id, action.occurredAt)
    insertSegment(sql, stamp, feed.id, opened)
    return savedFeed(calendarOf(sql), feed, saveFeed(sql, stamp, feed), stamp.now)
  }

export const pauseFeed =
  (stamp: Stamp, id: string, action: TimedAction) =>
  (sql: SqlStorage): CoreResult<Feed, Failure> => {
    const found = runningFeedFor(sql, id, action.version)
    if (!found.ok) return found
    const invalid = invalidUnless(errorAt("occurredAt", closeIssue(found.open, action.occurredAt, stamp.now)))
    if (invalid !== null) return { ok: false, error: invalid }
    closeSegment(sql, stamp, found.open.id, action.occurredAt)
    return savedFeed(calendarOf(sql), found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

export const resumeFeed =
  (stamp: Stamp, id: string, action: FeedResume) =>
  (sql: SqlStorage): CoreResult<Feed, Failure> => {
    const found = feedFor(sql, id, action.version, "paused")
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    const invalid = invalidUnless(errorAt("occurredAt", timeIssue(calendar, action.occurredAt, stamp.now)))
    if (invalid !== null) return { ok: false, error: invalid }
    const opened = { side: action.side, startedAt: action.occurredAt, endedAt: null }
    const overlapped = overlappedFeed(sql, [opened], stamp.now, NO_EXCLUSION)
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    insertSegment(sql, stamp, found.feed.id, opened)
    return savedFeed(calendar, found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

export const addBottle =
  (stamp: Stamp, id: string, portion: VersionedPortion) =>
  (sql: SqlStorage): CoreResult<Feed, Failure> => {
    const found = feedFor(sql, id, portion.version, "active")
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    const invalid = invalidUnless(portionErrors(calendar, portion, stamp.now, ""))
    if (invalid !== null) return { ok: false, error: invalid }
    insertPortion(sql, stamp, found.feed.id, portion)
    return savedFeed(calendar, found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

const completed = (sql: SqlStorage, stamp: Stamp, calendar: Calendar, feed: Feed) =>
  savedFeed(calendar, feed, saveFeed(sql, stamp, { ...feed, status: "completed" }), stamp.now)

const finishRunning = (
  sql: SqlStorage,
  stamp: Stamp,
  calendar: Calendar,
  feed: Feed,
  open: NursingSegment,
  finish: FeedFinish,
): CoreResult<Feed, Failure> => {
  const invalid = invalidUnless(errorAt("occurredAt", finishIssue(open, finish.occurredAt, stamp.now)))
  if (invalid !== null) return { ok: false, error: invalid }
  if (finish.occurredAt > open.startedAt) closeSegment(sql, stamp, open.id, finish.occurredAt)
  else if (onlyComponent(feed)) return whenEmptied(sql, stamp, calendar, feed, finish.deleteIfEmpty)
  else removeSegment(sql, stamp, open.id)
  return completed(sql, stamp, calendar, feed)
}

export const finishFeed =
  (stamp: Stamp, id: string, finish: FeedFinish) =>
  (sql: SqlStorage): CoreResult<Feed, Failure> => {
    const found = feedFor(sql, id, finish.version, "active")
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    const open = runningSegment(found.feed)
    if (open === undefined) return completed(sql, stamp, calendar, found.feed)
    return finishRunning(sql, stamp, calendar, found.feed, open, finish)
  }

import {
  type ComponentDelete,
  type Feed,
  type FeedConflict,
  type FieldError,
  type InvalidInput,
  NotFound,
  type NursingSegment,
  type SegmentEdit,
  type VersionedPortion,

import { calendarOf } from "../calendar.ts"
import type { CoreResult, Stamp } from "../receipts.ts"
import {
  feedFor,
  invalidUnless,
  onlyComponent,
  overlapConflict,
  overlappedFeed,
  portionErrors,
  savedFeed,
  segmentErrors,
  whenEmptied,
} from "./rules.ts"
import { removePortion, removeSegment, saveFeed, updatePortion, updateSegment } from "./store.ts"

type Table = "nursing_segments" | "bottle_portions"

type Located<C> =
  | { readonly ok: true; readonly feed: Feed; readonly component: C }
  | { readonly ok: false; readonly error: NotFound | FeedConflict }

const locate = <C extends { readonly id: string }>(
  sql: SqlStorage,
  table: Table,
  id: string,
  version: number,
  componentsOf: (feed: Feed) => ReadonlyArray<C>,
): Located<C> => {
  const [row] = sql.exec<{ feed_id: string }>(`SELECT feed_id FROM ${table} WHERE id = ?`, id).toArray()
  if (row === undefined) return { ok: false, error: new NotFound() }
  const found = feedFor(sql, row.feed_id, version, "live")
  if (!found.ok) return found
  const component = componentsOf(found.feed).find((one) => one.id === id)
  return component === undefined ? { ok: false, error: new NotFound() } : { ok: true, feed: found.feed, component }
}

const segmentsOf = (feed: Feed) => feed.segments

const portionsOf = (feed: Feed) => feed.portions

const runningChanged = (current: NursingSegment, edit: SegmentEdit): FieldError[] =>
  (current.endedAt === null) === (edit.endedAt === null) ? [] : [{ path: "endedAt", issue: "invalid" }]

export const editSegment =
  (stamp: Stamp, id: string, edit: SegmentEdit) =>
  (sql: SqlStorage): CoreResult<Feed, InvalidInput | NotFound | FeedConflict> => {
    const found = locate(sql, "nursing_segments", id, edit.version, segmentsOf)
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    const errors = [...runningChanged(found.component, edit), ...segmentErrors(calendar, edit, stamp.now, "")]
    const invalid = invalidUnless(errors)
    if (invalid !== null) return { ok: false, error: invalid }
    const overlapped = overlappedFeed(sql, [edit], stamp.now, { feedId: null, segmentId: id })
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    updateSegment(sql, stamp, id, edit)
    return savedFeed(calendar, found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

export const editPortion =
  (stamp: Stamp, id: string, edit: VersionedPortion) =>
  (sql: SqlStorage): CoreResult<Feed, InvalidInput | NotFound | FeedConflict> => {
    const found = locate(sql, "bottle_portions", id, edit.version, portionsOf)
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    const invalid = invalidUnless(portionErrors(calendar, edit, stamp.now, ""))
    if (invalid !== null) return { ok: false, error: invalid }
    updatePortion(sql, stamp, id, edit)
    return savedFeed(calendar, found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

const deleteComponent =
  <C extends { readonly id: string }>(
    table: Table,
    componentsOf: (feed: Feed) => ReadonlyArray<C>,
    remove: (sql: SqlStorage, stamp: Stamp, id: string) => void,
  ) =>
  (stamp: Stamp, id: string, action: ComponentDelete) =>
  (sql: SqlStorage): CoreResult<Feed, NotFound | FeedConflict> => {
    const found = locate(sql, table, id, action.version, componentsOf)
    if (!found.ok) return found
    const calendar = calendarOf(sql)
    if (onlyComponent(found.feed)) return whenEmptied(sql, stamp, calendar, found.feed, action.deleteIfEmpty)
    remove(sql, stamp, id)
    return savedFeed(calendar, found.feed, saveFeed(sql, stamp, found.feed), stamp.now)
  }

export const deleteSegment = deleteComponent("nursing_segments", segmentsOf, removeSegment)

export const deletePortion = deleteComponent("bottle_portions", portionsOf, removePortion)

import {
  type Feed,
  FeedConflict,
  type FeedMove,
  type InvalidInput,
  type NotFound,
  queryKeys,
  type VersionedAction,
} from "@bt/contracts"
import { type Instant, validateNotInFuture } from "@bt/domain"
import { calendarOf, timeIssue } from "../calendar.ts"
import type { CoreResult, Stamp } from "../receipts.ts"
import {
  activeFeed,
  deletedAsItStands,
  errorAt,
  feedChanges,
  feedFor,
  invalidUnless,
  NO_EXCLUSION,
  overlapConflict,
  overlappedFeed,
  savedFeed,
} from "./rules.ts"
import { saveFeed, shiftFeed } from "./store.ts"

const latestOf = (feed: Feed): Instant =>
  Math.max(
    ...feed.segments.map((segment) => segment.endedAt ?? segment.startedAt),
    ...feed.portions.map((portion) => portion.occurredAt),
  )

const shiftedSegments = (feed: Feed, offset: number) =>
  feed.segments.map((segment) => ({
    startedAt: segment.startedAt + offset,
    endedAt: segment.endedAt === null ? null : segment.endedAt + offset,
  }))

export const moveFeed =
  (stamp: Stamp, id: string, move: FeedMove) =>
  (sql: SqlStorage): CoreResult<Feed, InvalidInput | NotFound | FeedConflict> => {
    const found = feedFor(sql, id, move.version, "live")
    if (!found.ok) return found
    const { feed } = found
    const offset = move.startedAt - feed.startedAt
    const calendar = calendarOf(sql)
    const latest = latestOf(feed) + offset
    const issue = timeIssue(calendar, move.startedAt, stamp.now) ?? validateNotInFuture(latest, stamp.now)
    const invalid = invalidUnless(errorAt("startedAt", issue))
    if (invalid !== null) return { ok: false, error: invalid }
    const moved = shiftedSegments(feed, offset)
    const overlapped = overlappedFeed(sql, moved, stamp.now, { feedId: feed.id, segmentId: null })
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    shiftFeed(sql, stamp, feed.id, offset)
    return savedFeed(calendar, feed, saveFeed(sql, stamp, feed), stamp.now)
  }

export const deleteFeed =
  (stamp: Stamp, id: string, action: VersionedAction) =>
  (sql: SqlStorage): CoreResult<Feed, NotFound | FeedConflict> => {
    const found = feedFor(sql, id, action.version, "live")
    if (!found.ok) return found
    return deletedAsItStands(sql, stamp, calendarOf(sql), found.feed)
  }

export const restoreFeed =
  (stamp: Stamp, id: string, action: VersionedAction) =>
  (sql: SqlStorage): CoreResult<Feed, NotFound | FeedConflict> => {
    const found = feedFor(sql, id, action.version, "deleted")
    if (!found.ok) return found
    const { feed } = found
    const active = feed.status === "active" ? activeFeed(sql) : undefined
    if (active !== undefined) {
      return { ok: false, error: new FeedConflict({ code: "FEED_ALREADY_ACTIVE", current: active }) }
    }
    const overlapped = overlappedFeed(sql, feed.segments, stamp.now, NO_EXCLUSION)
    if (overlapped !== undefined) return { ok: false, error: overlapConflict(overlapped) }
    const restored = saveFeed(sql, stamp, { ...feed, deletedAt: null })
    const changed = [...feedChanges(calendarOf(sql), null, restored, stamp.now), queryKeys.deleted]
    return { ok: true, response: restored, changed }
  }
