# M1.5 Household Durable Object Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 8 Oct 2026) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The household Durable Object starts doing its job. It migrates its SQLite schema when it starts, the admin seeds it once, it checks on every request that the caller is an active caregiver, it answers `GET /api/me`, and it keeps a receipt for every mutation so a retried save is applied once.

**Architecture:** Migrations are numbered `.sql` files that `migrate` applies in the constructor, under `blockConcurrencyWhile`. `packages/contracts` gains the http-api definition: one `me` group behind two middlewares. `Authorization` lets an active caregiver through and answers anyone else 401. `InvalidInputs` turns a request that fails decoding into 400 `InvalidInput`, naming every bad field. `docs/api.json` is generated from the definition, and a test fails when it's stale. In the Worker, `http.ts` implements both middlewares against the Durable Object's SQLite and serves the API with Effect's web handler. `core/` holds synchronous functions that take the SQL handle and `now`: the seed, the caller lookup, `/api/me`, and `withReceipt`, which runs a mutation and stores its receipt in one `transactionSync`. The Worker's admin branch decodes `POST /api/admin/household` and calls the Durable Object's `seedHousehold` RPC; `pnpm admin household:seed` is its client. Local runs seed a made-up household from `env.local` in `wrangler.jsonc`. An alarm prunes receipts every 6 h.

**Tech Stack:** TypeScript 5.9.3, `effect` 4.0.1 (Schema, `effect/http`, `effect/http-api`), `@bt/contracts`, `@bt/domain`, Workers and Durable Objects (`@cloudflare/workers-types` 5.20261006.1, wrangler 4.148.0, `@cloudflare/vite-plugin` 1.63.0), `@cloudflare/vitest-plugin` 1.3.7, Vitest 4.1.11, Playwright 1.64.0, oxlint 1.87.0 + oxfmt 0.72.0, Node 24.21.0 (`node:util` `parseArgs`, `--env-file-if-exists`).

**Spec:** `docs/implementation-plan.md`: the M1.5 row, D2, D5, D6, §1, §3.2, §3.3 (Migrations, Seed, Mutation pipeline, Clock, Receipts) and §6 (the DO core and Worker rows). `docs/spike-results.md`: S5 and S6, including the finding that `@effect/sql-sqlite-do`'s `withTransaction` must not be used for mutations. ## Decisions this plan makes (veto in review)

- **P1: Migration 0001 creates only the `household`, `caregivers`, `child` and `receipts` tables, plus the `_migrations` ledger.** Each later feature adds its own numbered migration with its tables, D4's `source` columns and their indexes (Andrew, 8 Oct 2026; the spec's §8 isn't in the repo). §3.3 changes to say so.
- **P2: Migrations are `.sql` files imported as text.** Wrangler's default rules make `*.sql` a Text module, `@cloudflare/vite-plugin` emits it next to the bundle, the test pool imports it, and `src/sql.d.ts` types it. `migrate` applies each missing migration and its ledger row in one `transactionSync`, in list order. A migration that fails rolls back and rejects the constructor's `blockConcurrencyWhile`, so the Durable Object never serves a half-migrated schema. An applied migration is never edited. A rollback runs older code against the newer schema, so migrations stay additive.
- **P3: Tables are `STRICT`, and SQLite enforces their foreign keys** (`PRAGMA foreign_keys` is 1 in Durable Objects; checked). `household` and `child` hold one row each (`CHECK (id = 1)`). A caregiver's email is `UNIQUE` and `CHECK (email = lower(email))`, which matches the lowercased `x-bt-email` the Worker forwards (M1.4's P3).
- **P4: No `Clock` interface.** Core functions take `now`, and the Durable Object reads `Date.now()` where a request or alarm comes in. Tests pin that with `vi.useFakeTimers({ toFake: ["Date"] })` and `vi.setSystemTime`, which reach the Durable Object because the test pool runs it in the test's isolate (checked). §3.3 changes to say so.
- **P5: The caller check is an http-api middleware, `Authorization`.** `contracts` declares it on the whole API, so the OpenAPI document shows the 401. The Durable Object implements it: it looks up `x-bt-email` among active caregivers on every request, and either hands the handler a `CurrentCaregiver` or answers 401. It is added after `InvalidInputs`, so it runs first, and a stranger learns nothing about their input. A path no endpoint matches gets the contract's 404 without the check: every caller has passed Access already, and a 404 reveals nothing. M1.9's socket upgrade, which doesn't go through http-api, reuses `activeCaregiver`.
- **P6: A request that fails decoding gets 400 `InvalidInput`, which names every bad field.** `HttpApiMiddleware.layerSchemaErrorTransform` replaces Effect's empty 400, and the API decodes with `errors: "all"`. `invalidInputFrom` in `contracts` turns the schema issue into `fieldErrors`. Each bad field appears once, with a dotted path such as `portions.0.date` and the issue `invalid`. A body that isn't JSON gets the empty path. The Worker's admin route uses the same function.
- **P7: `GET /api/me` answers `{ caregiver: { id, email, displayName }, household: { name, timeZone }, child: { name, birthDate } }`.** That's what M1.10's `useMe` and the Today screen need. The child's sex and gestational age stay in the Durable Object until growth (M4). Effect's struct decoding ignores extra keys, so adding fields later doesn't break an installed app running older code.
- **P8: The seed.** `pnpm admin household:seed` reads `BT_URL`, `CF_ACCESS_CLIENT_ID` and `CF_ACCESS_CLIENT_SECRET` from `.admin-token.env`, which is already gitignored. It posts to `/api/admin/household` with the service token and doesn't follow redirects, so an Access login page can't look like success. The Worker decodes the seed (`HouseholdSeed`) and calls the Durable Object's `seedHousehold` RPC.
  - **It seeds once.** A second seed changes nothing and answers 200 with what's stored; the first answers 201. Re-running it is safe, and it can't overwrite the production household.
  - **It stores the time zone's canonical name** (the M1.3 handoff). It allows every zone `TimeZone` accepts, `UTC` and `Etc/GMT±N` included.
  - **It needs the child's name**, which §3.3's list leaves out.
  - **Gestational age is 154–314 days** (22w0d to 44w6d), which also catches weeks typed as days.
  - **Emails must be lowercase.** The CLI lowercases them.
- **P9: The CLI lives in root `scripts/`, not `apps/worker/scripts/` as §1 says.** That's where the Node scripts, their `node` types and their test project already are. It imports the seed's type from the Worker, and the server does the validating. §1 changes.
- **P10: Local runs seed a made-up household.**
  - **How.** `wrangler.jsonc` gains `env.local`, whose `LOCAL_HOUSEHOLD` the Durable Object seeds when it starts, with the same decode and the same seed function. An invalid one stops it from starting. `pnpm dev` and the E2E build set `CLOUDFLARE_ENV=local`.
  - **Why it can't deploy.** Deploys use the top level, which has no `LOCAL_HOUSEHOLD`, and a test pins that. `wrangler deploy --env local` would create a separate Worker, `baby-tracker-local`, that refuses every JWT.
  - **Rejected: the admin path.** It can't work locally, because `access.dev` signs every request in as a caregiver.
  - **Rejected: a dev-only route.** It would put a back door in production code.
  - **Rejected: the Vite plugin's Local Explorer API.** It can write a local Durable Object's SQLite, but it's new and dev-only, and it skips the seed's validation.
- **P11: Receipts.**
  - **One transaction.** `withReceipt(storage, mutation, responseSchema, core)` runs everything in one `transactionSync`. It looks up the `actionId`.
    - **Same request hash:** the stored response and `changed` keys come back as `replayed`, and M1.9 rebroadcasts them.
    - **Different hash:** the saved record comes back as `replay-mismatch`, and the endpoint answers 409 `ACTION_REPLAY_MISMATCH` with its own `Conflict` class (M1.3).
    - **No receipt yet:** the core runs and its receipt is stored.
  - **A core that rejects** (a 409) rolls back whatever it wrote and stores no receipt, so a retry is checked again.
  - **`requestHash`.** `requestHash(route, payloadSchema, payload)` is the SHA-256 of the route and the payload re-encoded through its schema, so field order can't make a retry look edited.
  - **`ActionId` and `Version`.** `ActionId` is a UUID. `Version` waits for M1.6, its first user.
  - **Tests.** No endpoint uses `withReceipt` until M1.6, so its tests drive it with a probe core.
- **P12: Pruning.** An alarm every 6 h deletes receipts older than 24 h (`created_at < now − 24 h`). The Durable Object sets it when it starts if none is set, and each run sets the next.
- **P13: A household call that rejects becomes 503 `ServiceUnavailable`.** That covers a Durable Object reset during a deploy or a lost connection. Without it the app gets Cloudflare's HTML 500 (from the M1.4 review). Receipts make the app's retry safe.
- **P14: The admin gate stays a prefix check on `/api/admin/`** (rechecked, as the M1.4 review asked). Odd spellings such as `/api/admin` and `/api/%61dmin/…` reach the household as the caller, and its router has no admin paths. A contracts test pins that no endpoint is under `/api/admin`, and a Worker test sends the odd spellings through the real Durable Object.
- **P15: `docs/api.json` is generated** (`pnpm api:docs`), titled "Baby tracker", and a test fails when it's stale. oxfmt skips it, so the file is exactly what the generator writes. `LocalDate` shows `format: date`, and `IsoWeek` and `YearMonth` show a `pattern` (the M1.3 handoff). `TimeZone` stays a plain string, since JSON Schema has no format for zones.
- **P16: The Worker bundle grows from 87 to 238 KiB gzip**, for Effect's `http` and `http-api` modules. The spike measured 228 KiB. That's under the 400 KiB budget.

## Review Focus

1. **A disabled caregiver who keeps getting in** (AC 10). An instance that cached the caregiver list would serve a disabled parent until it restarts. Expect a 401 from the next request on, for that caregiver only. Tested in Task 4.
2. **A save applied twice, or a changed retry applied silently** (AC 14). A phone that lost the response to a save retries it, and the parent may have edited the form in between. Expect the retry with the same values to return the stored answer without applying it again, and the retry with edited values to come back as a mismatch with the saved record. If the receipt can't be stored, expect nothing to be kept. Tested in Task 6.
3. **The production household overwritten.** Re-running the seed, or a local seed that reached production, would replace the real household. Expect a second seed to change nothing, and the deployed configuration to have no `LOCAL_HOUSEHOLD`. Tested in Task 3.
4. **A parent locked out by a capital letter.** Google can return `Andrew@Gmail.com`, and the Worker forwards it lowercased. Expect every stored email to be lowercase: the table refuses anything else, the seed refuses it, and the CLI lowercases what it's given. Tested in Tasks 3 and 5.
5. **A deploy in the middle of a save.** A Durable Object reset rejects the call, and the app would get Cloudflare's HTML 500. Expect 503 `ServiceUnavailable`, which the app retries. Tested in Task 5.

Create `apps/worker/src/db/migrate.ts`:

```ts
export interface Migration {
  readonly name: string
  readonly sql: string
}

const LEDGER = `CREATE TABLE IF NOT EXISTS _migrations (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  applied_at INTEGER NOT NULL
) STRICT`

export const migrate = (storage: DurableObjectStorage, migrations: ReadonlyArray<Migration>, now: number): void => {
  storage.sql.exec(LEDGER)
  const { applied } = storage.sql.exec<{ applied: number }>("SELECT count(*) AS applied FROM _migrations").one()
  migrations.slice(applied).forEach(({ name, sql }, index) =>
    storage.transactionSync(() => {
      storage.sql.exec(sql)
      storage.sql.exec(
        "INSERT INTO _migrations (id, name, applied_at) VALUES (?, ?, ?)",
        applied + index + 1,
        name,
        now,
      )
    }),
  )
}
```

```ts
import { canonicalTimeZone, isIsoWeek, isLocalDate, isYearMonth } from "@bt/domain"
import { Schema } from "effect"

const FIRST_INSTANT = Date.UTC(2000, 0, 1)
const INSTANT_LIMIT = Date.UTC(2100, 0, 1)
const FIRST_CALENDAR_YEAR = 1999
const LAST_CALENDAR_YEAR = 2100

const inCalendarYears = (value: string) => {
  const year = Number(value.slice(0, 4))
  return year >= FIRST_CALENDAR_YEAR && year <= LAST_CALENDAR_YEAR
}

const calendarString = (
  isReal: (value: string) => boolean,
  example: string,
  jsonSchema: { readonly format: string } | { readonly pattern: string },
) =>
  Schema.String.check(
    Schema.makeFilter((value: string) => isReal(value) && inCalendarYears(value), {
      expected: `${example} from ${FIRST_CALENDAR_YEAR} to ${LAST_CALENDAR_YEAR}`,
      toJsonSchema: () => jsonSchema,
    }),
  )

export const Instant = Schema.Int.check(Schema.isGreaterThanOrEqualTo(FIRST_INSTANT), Schema.isLessThan(INSTANT_LIMIT))
export type Instant = typeof Instant.Type

export const LocalDate = calendarString(isLocalDate, "a date like 2026-10-06", { format: "date" })
export type LocalDate = typeof LocalDate.Type

export const IsoWeek = calendarString(isIsoWeek, "an ISO week like 2026-W41", { pattern: "^\\d{4}-W\\d{2}$" })
export type IsoWeek = typeof IsoWeek.Type

export const YearMonth = calendarString(isYearMonth, "a month like 2026-10", { pattern: "^\\d{4}-\\d{2}$" })
export type YearMonth = typeof YearMonth.Type

export const TimeZone = Schema.String.check(
  Schema.makeFilter((name: string) => canonicalTimeZone(name) !== null, {
    expected: "an IANA time zone like America/Vancouver",
  }),
```

Create `apps/worker/src/core/household.ts`. The time zone guard can't fire after `HouseholdSeed` has decoded the seed; it keeps the RPC honest about what it stores:

```ts
import { canonicalTimeZone } from "@bt/domain"
import type { HouseholdSeed, SeedResult } from "../seed.ts"

type HouseholdRow = { name: string; time_zone: string }
type CaregiverRow = { email: string; display_name: string }
type ChildRow = { name: string; birth_date: string; sex: "female" | "male"; gestational_age_days: number }

const storedHousehold = (sql: SqlStorage): HouseholdSeed | undefined => {
  const [household] = sql.exec<HouseholdRow>("SELECT name, time_zone FROM household").toArray()
  if (household === undefined) return undefined
  const caregivers = sql
    .exec<CaregiverRow>("SELECT email, display_name FROM caregivers ORDER BY rowid")
    .toArray()
    .map(({ email, display_name }) => ({ email, displayName: display_name }))
  const child = sql.exec<ChildRow>("SELECT name, birth_date, sex, gestational_age_days FROM child").one()
  return {
    name: household.name,
    timeZone: household.time_zone,
    caregivers,
    child: {
      name: child.name,
      birthDate: child.birth_date,
      sex: child.sex,
      gestationalAgeDays: child.gestational_age_days,
    },
  }
}

const insertHousehold = (sql: SqlStorage, seed: HouseholdSeed, now: number) => {
  sql.exec(
    "INSERT INTO household (id, name, time_zone, created_at, updated_at) VALUES (1, ?, ?, ?, ?)",
    seed.name,
    seed.timeZone,
    now,
    now,
  )
  for (const { email, displayName } of seed.caregivers) {
    sql.exec(
      "INSERT INTO caregivers (id, email, display_name, active, created_at, updated_at) VALUES (?, ?, ?, 1, ?, ?)",
      crypto.randomUUID(),
      email,
      displayName,
      now,
      now,
    )
  }
  const { name, birthDate, sex, gestationalAgeDays } = seed.child
  sql.exec(
    "INSERT INTO child (id, name, birth_date, sex, gestational_age_days, created_at, updated_at) VALUES (1, ?, ?, ?, ?, ?, ?)",
    name,
    birthDate,
    sex,
    gestationalAgeDays,
    now,
    now,
  )
}

export const seedHousehold = (storage: DurableObjectStorage, seed: HouseholdSeed, now: number): SeedResult =>
  storage.transactionSync(() => {
    const existing = storedHousehold(storage.sql)
    if (existing !== undefined) return { created: false, household: existing }
    const timeZone = canonicalTimeZone(seed.timeZone)
    if (timeZone === null) throw new RangeError(`Expected an IANA time zone, got "${seed.timeZone}"`)
    const household = { ...seed, timeZone }
    insertHousehold(storage.sql, household, now)
    return { created: true, household }
  })
```

```ts
import { NotFound } from "@bt/contracts"
import { DurableObject } from "cloudflare:workers"
import { Schema } from "effect"
import { seedHousehold } from "./core/household.ts"
import { migrate } from "./db/migrate.ts"
import { MIGRATIONS } from "./db/migrations.ts"
import { errorResponse } from "./error-response.ts"
import { HouseholdSeed, type SeedResult } from "./seed.ts"

interface HouseholdEnv {
  readonly LOCAL_HOUSEHOLD?: Schema.Json
}

export const startHousehold = async (
  storage: DurableObjectStorage,
  localHousehold: Schema.Json | undefined,
  now: number,
): Promise<void> => {
  migrate(storage, MIGRATIONS, now)
  if (localHousehold !== undefined) seedHousehold(storage, Schema.decodeUnknownSync(HouseholdSeed)(localHousehold), now)
}

export class HouseholdDO extends DurableObject<HouseholdEnv> {
  constructor(ctx: DurableObjectState, env: HouseholdEnv) {
    super(ctx, env)
    void ctx.blockConcurrencyWhile(() => startHousehold(ctx.storage, env.LOCAL_HOUSEHOLD, Date.now()))
  }

  override fetch(): Response {
    return errorResponse(new NotFound())
  }

  seedHousehold(seed: HouseholdSeed): SeedResult {
    return seedHousehold(this.ctx.storage, seed, Date.now())
```

```ts
import { canonicalTimeZone } from "@bt/domain"
import type { HouseholdSeed, SeedResult } from "../seed.ts"

type HouseholdRow = { name: string; time_zone: string }
type CaregiverRow = { email: string; display_name: string }
type ChildRow = { name: string; birth_date: string; sex: "female" | "male"; gestational_age_days: number }

const storedHousehold = (sql: SqlStorage): HouseholdSeed | undefined => {
  const [household] = sql.exec<HouseholdRow>("SELECT name, time_zone FROM household").toArray()
  if (household === undefined) return undefined
  const caregivers = sql
    .exec<CaregiverRow>("SELECT email, display_name FROM caregivers ORDER BY rowid")
    .toArray()
    .map(({ email, display_name }) => ({ email, displayName: display_name }))
  const child = sql.exec<ChildRow>("SELECT name, birth_date, sex, gestational_age_days FROM child").one()
  return {
    name: household.name,
    timeZone: household.time_zone,
    caregivers,
    child: {
      name: child.name,
      birthDate: child.birth_date,
      sex: child.sex,
      gestationalAgeDays: child.gestational_age_days,
    },
  }
}

const insertHousehold = (sql: SqlStorage, seed: HouseholdSeed, now: number) => {
  sql.exec(
    "INSERT INTO household (id, name, time_zone, created_at, updated_at) VALUES (1, ?, ?, ?, ?)",
    seed.name,
    seed.timeZone,
    now,
    now,
  )
  for (const { email, displayName } of seed.caregivers) {
    sql.exec(
      "INSERT INTO caregivers (id, email, display_name, active, created_at, updated_at) VALUES (?, ?, ?, 1, ?, ?)",
      crypto.randomUUID(),
      email,
      displayName,
      now,
      now,
    )
  }
  const { name, birthDate, sex, gestationalAgeDays } = seed.child
  sql.exec(
    "INSERT INTO child (id, name, birth_date, sex, gestational_age_days, created_at, updated_at) VALUES (1, ?, ?, ?, ?, ?, ?)",
    name,
    birthDate,
    sex,
    gestationalAgeDays,
    now,
    now,
  )
}
```

```ts
import { meOf } from "./core/household.ts"
import { errorResponse } from "./error-response.ts"

export const invalidInputs = HttpApiMiddleware.layerSchemaErrorTransform(InvalidInputs, (error) =>
  Effect.fail(invalidInputFrom(error.cause.issue)),
)

export const authorization = (sql: SqlStorage) =>
  Layer.succeed(Authorization, (handler) =>
    Effect.gen(function* () {
      const request = yield* HttpServerRequest.HttpServerRequest
      const caregiver = activeCaregiver(sql, request.headers["x-bt-email"])
      if (caregiver === undefined) return yield* new Unauthorized()
      return yield* Effect.provideService(handler, CurrentCaregiver, caregiver)
    }),
  )

const unknownRoute = HttpRouter.add("*", "/*", () =>
  Effect.sync(() => HttpServerResponse.fromWeb(errorResponse(new NotFound()))),
)

export const householdApi = (sql: SqlStorage) => {

    handlers.handle("me", () => Effect.map(Effect.service(CurrentCaregiver), (caregiver) => meOf(sql, caregiver))),
  )
  return HttpRouter.toWebHandler(
    Layer.mergeAll(
      HttpApiBuilder.layer(Api).pipe(Layer.provide(me.pipe(Layer.provide([authorization(sql), invalidInputs])))),
      unknownRoute,
    ).pipe(Layer.provide(HttpServer.layerServices)),
    { disableLogger: true },
```

```ts
import { ServiceUnavailable, Unauthorized } from "@bt/contracts"
import type { Caller } from "./access.ts"
import { type AdminHousehold, routeAdmin } from "./admin.ts"
import { errorResponse } from "./error-response.ts"

export interface Household extends AdminHousehold {
  fetch(request: Request): Promise<Response>
}

const INTERNAL_HEADER_PREFIX = "x-bt-"

const forHousehold = (request: Request, email: string): Request => {
  const headers = new Headers([...request.headers].filter(([name]) => !name.startsWith(INTERNAL_HEADER_PREFIX)))
  headers.set("x-bt-email", email)
  return new Request(request, { headers })
}

const sameOriginTarget = (url: URL): string => {
  const requested = url.searchParams.get("return") ?? "/"
  const target = requested.startsWith("/") ? URL.parse(requested, url.origin) : null
  return target?.origin === url.origin ? target.href : `${url.origin}/`
}

const loginRedirect = (url: URL): Response =>
  new Response(null, { status: 302, headers: { location: sameOriginTarget(url), "cache-control": "no-store" } })

const unavailable = () => errorResponse(new ServiceUnavailable())

const isAdmin = (caller: Caller, adminClientId: string | undefined): boolean =>
  caller.kind === "service" && adminClientId !== undefined && adminClientId !== "" && caller.clientId === adminClientId

export const routeApi = (
  request: Request,
  caller: Caller,
  household: Household,
  adminClientId: string | undefined,
): Response | Promise<Response> => {
  if (caller.kind === "keys-unavailable") return errorResponse(new ServiceUnavailable())
  if (caller.kind === "unauthenticated") return errorResponse(new Unauthorized())
  const url = new URL(request.url)
  if (url.pathname === "/api/login") return loginRedirect(url)
  if (url.pathname.startsWith("/api/admin/")) {
    return isAdmin(caller, adminClientId)
      ? routeAdmin(request, household).catch(unavailable)
      : errorResponse(new Unauthorized())
  }
  if (caller.kind === "service") return errorResponse(new Unauthorized())
  return household.fetch(forHousehold(request, caller.email)).catch(unavailable)
}
```

```ts
import type { HouseholdSeed } from "../apps/worker/src/seed.ts"

type SeedJson = (typeof HouseholdSeed)["Encoded"]

export interface AdminEnv {
  readonly BT_URL?: string | undefined
  readonly CF_ACCESS_CLIENT_ID?: string | undefined
  readonly CF_ACCESS_CLIENT_SECRET?: string | undefined
}

const SEXES = ["female", "male"] as const

const sexOf = (value: string): SeedJson["child"]["sex"] => {
  const sex = SEXES.find((known) => known === value)
  if (sex === undefined) throw new Error(`--sex must be female or male, not "${value}"`)
  return sex
}

const caregiverOf = (value: string) => {
  const separator = value.indexOf("=")
  if (separator < 1) throw new Error(`--caregiver takes email=Display Name, not "${value}"`)
  return { email: value.slice(0, separator).trim().toLowerCase(), displayName: value.slice(separator + 1).trim() }
}

const required = (name: string, value: string | undefined) => {
  if (value === undefined || value === "") throw new Error(`Missing --${name}`)
  return value
}

export const seedFromArgs = (args: ReadonlyArray<string>): SeedJson => {
  const { values } = parseArgs({
    args: [...args],
    options: {
      name: { type: "string" },
      "time-zone": { type: "string" },
      caregiver: { type: "string", multiple: true },
      "child-name": { type: "string" },
      "birth-date": { type: "string" },
      sex: { type: "string" },
      "gestational-age-days": { type: "string" },
    },
    strict: true,
  })
  return {
    name: required("name", values.name),
    timeZone: required("time-zone", values["time-zone"]),
    caregivers: (values.caregiver ?? []).map(caregiverOf),
    child: {
      name: required("child-name", values["child-name"]),
      birthDate: required("birth-date", values["birth-date"]),
      sex: sexOf(required("sex", values.sex)),
      gestationalAgeDays: Number(required("gestational-age-days", values["gestational-age-days"])),
    },
  }
}

  const value = env[name]
  if (value === undefined || value === "") throw new Error(`Set ${name} in .admin-token.env`)
  return value
}

      "cf-access-client-secret": fromEnv(env, "CF_ACCESS_CLIENT_SECRET"),
```

```ts
import { type ActionId, Changed } from "@bt/contracts"
import { Schema } from "effect"

const HOUR_MS = 60 * 60 * 1000
export const RECEIPT_TTL_MS = 24 * HOUR_MS
export const PRUNE_EVERY_MS = 6 * HOUR_MS

export interface Mutation {
  readonly actionId: ActionId
  readonly requestHash: string
  readonly caregiverId: string
  readonly now: number
}

export type CoreResult<A, E> =
  | { readonly ok: true; readonly response: A; readonly changed: Changed }
  | { readonly ok: false; readonly error: E }

export type Outcome<A, E> =
  | { readonly kind: "applied" | "replayed"; readonly response: A; readonly changed: Changed }
  | { readonly kind: "replay-mismatch"; readonly saved: A }
  | { readonly kind: "rejected"; readonly error: E }

type ReceiptRow = { request_hash: string; response: string; changed: string }

const changedJson = Schema.fromJsonString(Changed)

class Rollback extends Error {}

export const withReceipt = <A, E>(
  storage: DurableObjectStorage,
  mutation: Mutation,
  response: Schema.Codec<A, Schema.Json>,
  core: (sql: SqlStorage) => CoreResult<A, E>,
): Outcome<A, E> => {
  const responseJson = Schema.fromJsonString(response)
  let rejected: { readonly error: E } | undefined
  try {
    return storage.transactionSync((): Outcome<A, E> => {
      const { sql } = storage
      const [receipt] = sql
        .exec<ReceiptRow>("SELECT request_hash, response, changed FROM receipts WHERE action_id = ?", mutation.actionId)
        .toArray()
      if (receipt !== undefined) {
        const saved = Schema.decodeSync(responseJson)(receipt.response)
        if (receipt.request_hash !== mutation.requestHash) return { kind: "replay-mismatch", saved }
        return { kind: "replayed", response: saved, changed: Schema.decodeSync(changedJson)(receipt.changed) }
      }
      const result = core(sql)
      if (!result.ok) {
        rejected = { error: result.error }
        throw new Rollback()
      }
      sql.exec(
        "INSERT INTO receipts (action_id, caregiver_id, request_hash, response, changed, created_at) VALUES (?, ?, ?, ?, ?, ?)",
        mutation.actionId,
        mutation.caregiverId,
        mutation.requestHash,
        Schema.encodeSync(responseJson)(result.response),
        Schema.encodeSync(changedJson)(result.changed),
        mutation.now,
      )
      return { kind: "applied", response: result.response, changed: result.changed }
    })
  } catch (error) {
    if (error instanceof Rollback && rejected !== undefined) return { kind: "rejected", error: rejected.error }
    throw error
  }
}

export const requestHash = async <A>(
  route: string,
  payload: Schema.Codec<A, Schema.Json>,
  value: A,
): Promise<string> => {
  const body = JSON.stringify(Schema.encodeSync(payload)(value))
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(`${route}\n${body}`))
  return [...new Uint8Array(digest)].map((byte) => byte.toString(16).padStart(2, "0")).join("")
}

export const pruneReceipts = (sql: SqlStorage, now: number): number =>
  sql.exec("DELETE FROM receipts WHERE created_at < ?", now - RECEIPT_TTL_MS).rowsWritten
```

```ts
import { DurableObject } from "cloudflare:workers"
import { Schema } from "effect"
import { seedHousehold } from "./core/household.ts"
import { PRUNE_EVERY_MS, pruneReceipts } from "./core/receipts.ts"
import { migrate } from "./db/migrate.ts"
import { MIGRATIONS } from "./db/migrations.ts"
import { householdApi } from "./http.ts"
import { HouseholdSeed, type SeedResult } from "./seed.ts"

interface HouseholdEnv {
  readonly LOCAL_HOUSEHOLD?: Schema.Json
}

export const startHousehold = async (
  storage: DurableObjectStorage,
  localHousehold: Schema.Json | undefined,
  now: number,
): Promise<void> => {
  migrate(storage, MIGRATIONS, now)
  if (localHousehold !== undefined) seedHousehold(storage, Schema.decodeUnknownSync(HouseholdSeed)(localHousehold), now)
  if ((await storage.getAlarm()) === null) await storage.setAlarm(now + PRUNE_EVERY_MS)
}

export class HouseholdDO extends DurableObject<HouseholdEnv> {
  private readonly api: ReturnType<typeof householdApi>

  constructor(ctx: DurableObjectState, env: HouseholdEnv) {
    super(ctx, env)
    void ctx.blockConcurrencyWhile(() => startHousehold(ctx.storage, env.LOCAL_HOUSEHOLD, Date.now()))
    this.api = householdApi(ctx.storage.sql)
  }

  override async fetch(request: Request): Promise<Response> {
    const response = await this.api.handler(request)
    response.headers.set("cache-control", "no-store")
    return response
  }

  override async alarm(): Promise<void> {
    const now = Date.now()
    pruneReceipts(this.ctx.storage.sql, now)
    await this.ctx.storage.setAlarm(now + PRUNE_EVERY_MS)
  }

  seedHousehold(seed: HouseholdSeed): SeedResult {
    return seedHousehold(this.ctx.storage, seed, Date.now())
  }
}

export const householdOf = (namespace: DurableObjectNamespace<HouseholdDO>) => namespace.getByName("household")
```
