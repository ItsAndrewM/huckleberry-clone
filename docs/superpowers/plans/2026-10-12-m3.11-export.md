# M3.11 Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, as Andrew chose on 12 Oct 2026) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the household's records can leave the app, as a full backup and as a sheet a person can read:
- **JSON:** `GET /api/export.json` holds every table as stored: every row and column, deleted rows and audit columns included, with the migrations applied.
- **CSV:** `GET /api/export.csv` is one sheet with a row per live feed, diaper and measurement.
- **Phones:** Settings › Export hands either file to the share sheet, or downloads it where the browser can't share files.
- **Andrew's Mac:** `pnpm admin export <file>` saves the JSON, and each `pnpm release` saves one to `exports/` before it takes its bookmark.

**Architecture:**
- **`packages/contracts/src/export.ts` (new):** `HouseholdExport`, which is `{format, version, exportedAt, migrations, tables}`, and its decoder `householdExportFrom`. It also holds `ExportCsv`, a `text/csv` string, and `ExportGroup`'s two GET endpoints.
- **`apps/worker/src/core/export.ts` (new):** `householdExportOf(sql, now)` reads every table `sqlite_master` lists, row by row, in one synchronous pass, so no request can land in the middle of it. It leaves out the migration ledger (the `migrations` list stands for it), the receipts, and SQLite's and Cloudflare's own tables.
- **`apps/worker/src/core/export-csv.ts` (new):** `householdCsvOf(sql, now)` reuses the live loaders (`liveFeedsSince`, `liveDiapersSince`, `growthOf`) and domain's `feedSummary` and `localDateTimeOf`.
- **The routes:** `export-handlers.ts` (new) serves the group, and `http.ts` registers it. `POST /api/admin/export` reaches the household's new `exportHousehold()` RPC.
- **`scripts/admin-export.ts` (new):**
  - `saveExport` writes the answer exactly as it came, to a new file only, readable only by the Mac's user, and says only how much it holds
  - `releaseExportPath` names a release's export
  - `release.ts` calls `saveExport` after its build checks and before its bookmark, unless `--first` or `--skip-export`
- **Web:**
  - `api/export.ts`: fetches through the typed client
  - `features/settings/export-file.ts`: the rules, all pure: the file, its byte-order mark, what a refused share means, the words
  - `deliver-file.ts`: shares or downloads
  - `use-export.ts`: one mutation
  - `export-section.tsx`: the section, after "Signed in as"

## Decisions this plan makes (veto in review)

- **P1, what the JSON holds.**
  - **The envelope:** `{format: "baby-tracker-export", version: 1, exportedAt, migrations, tables}`.
  - **The tables:** every table in `sqlite_master`, by name, with every column under its SQL name, rows in insertion order. So a table a later migration adds joins the export by itself.
  - **Left out:** `_migrations`, since `migrations` lists its names in order, and `receipts`, which hold saved responses for a day and nothing a restore needs. SQLite's own `sqlite_*` and Cloudflare's own `_cf_*` tables are left out too. The DO lists `_cf_KV` and `_cf_METADATA` in `sqlite_master` (measured), and they aren't the household's.
- **P2, values as stored.** Instants are epoch milliseconds, booleans are 0 or 1, and amounts are in mL, g and cm. The caregivers' emails are in it, since it's the household's own backup. A BLOB column would throw, since none exists and no rule says how to write one.
- **P3, the CSV's details.**
  - **Columns:** `Kind, Start, End, Left (min), Right (min), Breast milk (mL), Formula (mL), Wet, Dirty, Weight (g), Length (cm), Head (cm), Logged by`
  - **Times:** `2026-10-12 03:05`, at the household's local time, without seconds.
  - **A running or paused feed:** its End is blank, since it can still resume, and its minutes count to the moment of the export. (The final review added "paused": a paused feed kept its pause time as End, and read as finished.)
  - **Minutes:** to a tenth. A feed shows both sides' minutes once it has any nursing, and both milks once it has any bottle. Otherwise those cells stay blank, so a bottle never reads "0 min".
  - **Wet and Dirty:** "yes" or blank.
  - **Format:** lines end in CRLF. A cell holding a comma, a quote or a line break is quoted, as RFC 4180 says. A cell starting `=`, `+`, `-`, `@`, a tab or a CR gets a leading `'`, so a spreadsheet can't read a name as a formula.
- **P4, the byte-order mark is the phone's.** The server sends plain CSV with `charset=utf-8`. The phone puts a BOM before it in the file it shares, so Excel reads names as UTF-8. A BOM from the server would never reach the file: `Response.text()` strips it (measured).
- **P5, sharing.**
  - **One tap:** a tap fetches the file and hands it to the share sheet.
  - **When iOS refuses:** iOS refuses a share that comes too long after its tap (`NotAllowedError`). Then "The CSV is ready." and "Share it" appear, for a fresh tap. If that's refused too, the file downloads instead.
  - **Closing the sheet:** a closed share sheet (`AbortError`) says nothing.
  - **Labels:** the buttons say "Download CSV" and "Download JSON" in a browser that can't share that kind of file, checked once at load.
- **P6, waiting.** While offline or signed out, both buttons wait, with the reason under the hint ("Exports need a connection." or "Sign in to export."), as the quick actions do. "Share it" still works offline, since the file is already on the phone.
- **P7, files.**
  - **On a phone:** `baby-tracker-<the household's local date>.csv` or `.json`.
  - **A release's export:** `exports/<UTC date>T<HHMMSS>Z-<commit>.json`, like `exports/2026-10-12T031450Z-20390a3.json`. The final review moved it from the minute to the second, so a rerun moments later doesn't meet "file exists" and get told to use `--skip-export`.
  - **Where `pnpm admin export` may write:** outside the checkout, or under its `exports/`. A leading `~` means the home folder even when quoted. Anywhere else in the checkout is refused, where git would see the file (the final review's Important finding). `.gitignore` ignores only the root's `/exports/`.
  - **Writes:** the scripts write a new file only (`wx`), mode 600, exactly as the household sent it.
  - **What prints:** only "N tables and M rows, as of <time>".
  - **When it fails:** a refusal prints its status and body, which hold no household data. A 200 that isn't an export is refused without echoing it.
- **P8, `pnpm release --skip-export`.** The release exports before it deploys, so it asks the Worker that's still live. For the first release that carries M3.11, that Worker has no export route and answers 404. So that one release runs with `--skip-export`, and the refusal says so. The flag also covers an emergency where the export itself is broken. Without it, a failed export stops the release before the bookmark (D3).
- **P9, the JSON on a phone is re-encoded.** The typed client decodes the export, and the phone writes `JSON.stringify` of it: the same rows, keys in the same order. The Mac's files are the server's own bytes.
- **P10, Settings' order.** Export follows "Signed in as", inside the branch that waits for the household, since the file's name needs its zone. Offline copy and Home Screen stay last.

## Review Focus

The five inputs most likely to bite that the spec implies but doesn't spell out, each with the test that pins it:

1. **A caregiver whose name holds a comma, a quote, a line break or a leading `=`:** the CSV must keep it one cell and never run it as a formula. Task 2, "quotes a name holding a comma, a quote or a line break, and makes one starting =, +, - or @ inert".
2. **A feed still running when the export is taken:** it must appear with no End and its minutes so far, not break the sheet or vanish. Task 2, "counts a running feed's minutes up to the export, to a tenth, and leaves its End blank".
3. **Deleted entries, and a feed with a deleted bottle:** the CSV leaves them out, and the JSON keeps every row. Task 2, "leaves out deleted entries, and the deleted parts of a feed", and Task 1, "keeps every column of every row, deleted rows and their audit included".
4. **iOS refusing a share that came too long after the tap** (the fetch took a while): the file must still reach the parent. Task 4, "asks for a second tap when the phone says the share came too long after the first", and `afterRefusal`'s tests.
5. **A release whose export fails:** a refused token, a 503, or a Worker without the route. It must stop before the bookmark, write no file, and name `--skip-export`. Task 3, "writes nothing when the household refuses", "never writes over a file that's already there", and `exportProblem`'s test.

The route, in a new `apps/worker/test/export.test.ts`. It pins the envelope, deleted rows with their audit, what's left out (the receipts, the ledger and Cloudflare's own tables), a table added later, and the caregiver check:

```ts
import { HouseholdExport, SavedDiaper } from "@bt/contracts"
import { runInDurableObject } from "cloudflare:test"
import { Schema } from "effect"
import { afterEach, beforeEach, describe, expect, it, vi } from "vitest"
import { MIGRATIONS } from "../src/db/migrations.ts"
import { ACTION_ID, ANDREW, HOUR_MS, NOW, seededHousehold } from "./fixtures.ts"
import { get, type Household, inStorage, sendJson } from "./requests.ts"

const decodeExport = Schema.decodeUnknownSync(Schema.toCodecJson(HouseholdExport))

const exported = async (household: Household) => {
  const response = await get(household, "/api/export.json", ANDREW.email)
  return { response, body: decodeExport(await response.json()) }
}

const decodeSaved = Schema.decodeUnknownSync(Schema.toCodecJson(SavedDiaper))

const diaperAt = async (household: Household, occurredAt: number) => {
  const payload = { actionId: crypto.randomUUID(), occurredAt, wet: true, dirty: false }
  return decodeSaved((await sendJson(household, "POST", "/api/diapers", payload)).body).diaper
}

beforeEach(() => {
  vi.useFakeTimers({ toFake: ["Date"] })
  vi.setSystemTime(NOW)
})

afterEach(() => {
  vi.useRealTimers()
})

describe("GET /api/export.json", () => {
  it("answers 200, no-store, with the format, the time, every migration applied and a table per name", async () => {
    const { response, body } = await exported(await seededHousehold())
    expect(response.status).toBe(200)
    expect(response.headers.get("cache-control")).toBe("no-store")
    expect(response.headers.get("content-type")).toBe("application/json")
    expect(body.format).toBe("baby-tracker-export")
    expect(body.version).toBe(1)
    expect(body.exportedAt).toBe(NOW)
    expect(body.migrations).toEqual(MIGRATIONS.map(({ name }) => name))
    expect(Object.keys(body.tables)).toEqual([
      "bottle_portions",
      "caregivers",
      "child",
      "diapers",
      "feeds",
      "growth_measurements",
      "household",
      "nursing_segments",
    ])
  })

  it("keeps every column of every row, deleted rows and their audit included", async () => {
    const household = await seededHousehold()
    const { id } = await diaperAt(household, NOW - HOUR_MS)
    await sendJson(household, "DELETE", `/api/diapers/${id}`, { actionId: crypto.randomUUID(), version: 1 })
    const andrew = await inStorage(
      household,
      (sql) => sql.exec<{ id: string }>("SELECT id FROM caregivers WHERE email = ?", ANDREW.email).one().id,
    )
    const { body } = await exported(household)
    expect(body.tables.diapers).toEqual([
      {
        id,
        occurred_at: NOW - HOUR_MS,
        wet: 1,
        dirty: 0,
        version: 2,
        source: "app",
        source_ref: null,
        created_by: andrew,
        created_at: NOW,
        updated_by: andrew,
        updated_at: NOW,
        deleted_at: NOW,
      },
    ])
    expect(body.tables.caregivers?.map(({ email }) => email)).toEqual(["andrew@example.test", "emily@example.test"])
  })

  it("leaves out the receipts and the migration ledger, which the migrations list stands for", async () => {
    const household = await seededHousehold()
    await diaperAt(household, NOW - HOUR_MS)
    const { body } = await exported(household)
    expect(Object.keys(body.tables)).not.toContain("receipts")
    expect(Object.keys(body.tables)).not.toContain("_migrations")
  })

  it("leaves out Cloudflare's own tables, which the storage API and alarms keep beside the household's", async () => {
    const household = await seededHousehold()
    const reserved = await runInDurableObject(household, async (_instance, state) => {
      await state.storage.put("a key", "a value")
      return state.storage.sql
        .exec<{ name: string }>(
          "SELECT name FROM sqlite_master WHERE type = 'table' AND name LIKE '\\_cf\\_%' ESCAPE '\\'",
        )
        .toArray()
        .map(({ name }) => name)
    })
    const { body } = await exported(household)
    expect(reserved).toContain("_cf_KV")
    expect(Object.keys(body.tables).filter((table) => table.startsWith("_cf_"))).toEqual([])
  })

  it("takes in a table a later migration adds, with no change to the export", async () => {
    const household = await seededHousehold()
    await inStorage(household, (sql) => {
      sql.exec("CREATE TABLE sleeps (id TEXT PRIMARY KEY, started_at INTEGER NOT NULL) STRICT")
      sql.exec("INSERT INTO sleeps (id, started_at) VALUES ('s1', ?)", NOW)
    })
    const { body } = await exported(household)
    expect(body.tables.sleeps).toEqual([{ id: "s1", started_at: NOW }])
  })

  it("is refused to someone who isn't a caregiver", async () => {
    const response = await get(await seededHousehold(), "/api/export.json", "stranger@example.test")
    expect(response.status).toBe(401)
  })
})

describe("an action id from a save", () => {
  it("never reaches the export, since receipts aren't exported", async () => {
    const household = await seededHousehold()
    await sendJson(household, "POST", "/api/diapers", {
      actionId: ACTION_ID,
```

```ts
  readonly names: ReadonlyMap<string, string>
  readonly now: Instant
}

const BEGINNING: Instant = 0
const FORMULA_START = /^[=+\-@\t\r]/
const NEEDS_QUOTES = /[",\r\n]/

const timeOf = (instant: Instant, zone: TimeZone) => localDateTimeOf(instant, zone).replace("T", " ")
const minutesOf = (seconds: number) => String(Math.round(seconds / 6) / 10)
const yesOrBlank = (flag: boolean) => (flag ? "yes" : "")
const numberOrBlank = (value: number | null) => (value === null ? "" : String(value))

const feedLine = (feed: Feed, { zone, names, now }: Context): Line => {
  const summary = feedSummary(feed, now)
  const nursed = feed.segments.length > 0
  const bottled = feed.portions.length > 0
  return {
    at: feed.startedAt,
    cells: {
      Kind: "Feed",
      Start: timeOf(feed.startedAt, zone),
      End: feed.endedAt === null ? "" : timeOf(feed.endedAt, zone),
      "Left (min)": nursed ? minutesOf(summary.leftSeconds) : "",
      "Right (min)": nursed ? minutesOf(summary.rightSeconds) : "",
      "Breast milk (mL)": bottled ? String(summary.breastMilkMl) : "",
      "Formula (mL)": bottled ? String(summary.formulaMl) : "",
      "Logged by": names.get(feed.createdBy) ?? "",
    },
  }
}

const diaperLine = (diaper: Diaper, { zone, names }: Context): Line => ({
  at: diaper.occurredAt,
  cells: {
    Kind: "Diaper",
    Start: timeOf(diaper.occurredAt, zone),
    Wet: yesOrBlank(diaper.wet),
    Dirty: yesOrBlank(diaper.dirty),
    "Logged by": names.get(diaper.createdBy) ?? "",
  },
})

const measurementLine = (measurement: Measurement, { zone, names }: Context): Line => ({
  at: measurement.measuredAt,
  cells: {
    Kind: "Growth",
    Start: timeOf(measurement.measuredAt, zone),
    "Weight (g)": numberOrBlank(measurement.weightG),
    "Length (cm)": numberOrBlank(measurement.lengthCm),
    "Head (cm)": numberOrBlank(measurement.headCm),
    "Logged by": names.get(measurement.createdBy) ?? "",
  },
})

const fieldOf = (text: string) => {
  const inert = FORMULA_START.test(text) ? `'${text}` : text
  return NEEDS_QUOTES.test(inert) ? `"${inert.replaceAll('"', '""')}"` : inert
}

const caregiverNames = (sql: SqlStorage) =>
  new Map(
    sql
      .exec<{ id: string; display_name: string }>("SELECT id, display_name FROM caregivers")
      .toArray()
      .map(({ id, display_name }) => [id, display_name]),
```

```ts
import type { ExportKind } from "../../api/export.ts"
import { type Attempt, afterRefusal, type Delivery, exportFileOf, ShareFailed } from "./export-file.ts"

const REVOKE_AFTER_MS = 60_000

const sharesFile = (file: File) => "canShare" in navigator && navigator.canShare({ files: [file] })

export const sharesKind = (kind: ExportKind) => sharesFile(exportFileOf(kind, "", "check"))

const download = (file: File): Delivery => {
  const url = URL.createObjectURL(file)
  Object.assign(document.createElement("a"), { href: url, download: file.name }).click()
  setTimeout(() => URL.revokeObjectURL(url), REVOKE_AFTER_MS)
  return "downloaded"
}

const share = async (file: File, attempt: Attempt): Promise<Delivery> => {
  try {
    await navigator.share({ files: [file] })
    return "shared"
  } catch (error) {
    const next = error instanceof DOMException ? afterRefusal(error.name, attempt) : null
    if (next === null) throw new ShareFailed("The share sheet refused the file", { cause: error })
    return next === "download" ? download(file) : next
  }
}

  sharesFile(file) ? share(file, attempt) : Promise.resolve(download(file))
```

```ts
import { localDateOf, type TimeZone } from "@bt/domain"
import { useMutation } from "@tanstack/react-query"
import { type ExportKind, fetchExport } from "../../api/export.ts"
import { useConnectivity } from "../../api/hooks.ts"
import { useApp } from "../../app-context.ts"
import { deliverFile } from "./deliver-file.ts"
import { type Delivery, exportFailure, exportFileOf, waitReason } from "./export-file.ts"

interface ExportRequest {
  readonly kind: ExportKind
  readonly file: File | null
}

export interface Exported {
  readonly kind: ExportKind
  readonly file: File
  readonly delivery: Delivery
}

export const useExport = (timeZone: TimeZone) => {
  const { api } = useApp()
  const reason = waitReason(useConnectivity())
  const exporting = useMutation({
    mutationFn: async ({ kind, file }: ExportRequest): Promise<Exported> => {
      if (file !== null) return { kind, file, delivery: await deliverFile(file, "again") }
      const fetched = exportFileOf(kind, await fetchExport(api, kind), localDateOf(Date.now(), timeZone))
      return { kind, file: fetched, delivery: await deliverFile(fetched, "first") }
    },
  })
  const { isPending, data, error, variables } = exporting
  return {
    reason,
    busy: isPending,
    preparing: isPending ? (variables?.kind ?? null) : null,
    waiting: !isPending && data?.delivery === "needs-a-tap" ? data : null,
    failure: isPending ? null : exportFailure(error),
    start: (kind: ExportKind) => exporting.mutate({ kind, file: null }),
    shareAgain: ({ kind, file }: Exported) => exporting.mutate({ kind, file }),
  }
}
```
