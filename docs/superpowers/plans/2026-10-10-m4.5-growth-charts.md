# M4.5 Growth Charts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 10 Oct 2026) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the child's measurements over WHO's 3rd to 97th percentile curves on the Growth tab, one metric at a time. The chart is labelled "WHO Child Growth Standards", makes no colour judgement, and has a numeric table beside it.

**Architecture:**
- **The curves:** `valueAtPercentile(metric, sex, ageDays, percentile)` in `packages/domain/src/growth/percentile-for.ts` is `percentileFor`'s inverse for the five curves WHO publishes. `test/growth/curve-gate.test.ts` checks it against WHO's printed P3 to P97 on every day from 0 to 730.
- **The table's age:** `ageInMonthsAndDays(measuredOn, birthDate)` in `growth/age.ts` counts calendar months, then days.
- **The model:** pure functions in `apps/web/src/features/growth/`, tested in Vitest:
  - `chart-model.ts`: the age window, the curves in the axis unit, and one row per measurement
  - `format.ts`: the wording of percentiles, ages, values and dates
  - `metrics.ts`: the three metrics
- **The chart:** `growth-chart.tsx` draws the model with TanStack Charts' React adapter: five neutral curves labelled at their ends, and her measurements as joined points with a tooltip.
- **The page:** `growth-page.tsx` replaces the Growth stub. It shows a Weight / Length / Head switch, the chart in a captioned figure, and "Show as a table".
- **E2E:** `e2e/growth.spec.ts` plays the household's answers, as `e2e/today.spec.ts` does.

**Tech Stack:** React 19.3, TanStack Charts 1.1.0 (new), TanStack Query 5.104.1 and Router 1.170.41, Tailwind 4.3.3, Base UI 1.8.0, Vitest 4.1.11 with fast-check, Playwright 1.64.0, TypeScript 5.9.3, oxlint 1.87.0 and oxfmt 0.72.0, Node 24.21.0.

## Decisions this plan makes (veto in review)

- **P1: TanStack Charts, pinned** (Andrew, 10 Oct 2026).
  - `@tanstack/charts` is pinned at 1.1.0 in the catalog. Its 1.0 compatibility contract began on 3 Oct 2026, and 1.1.0 is from 9 Oct. Upgrade only with a test run.
  - The React `Chart` comes from `@tanstack/charts/react/tooltip`, the entry that takes `renderTooltipBody`. `@tanstack/react-charts` is only a compatibility shim; don't use it.
  - Its framework peers (Vue, Svelte, Angular and others) are all optional, so pnpm installs none of them. It brings 43 packages, mostly d3 modules, and the bundle keeps only what the chart imports.
  - The chart's definition builds in Node: `createChartScene` and `renderChartSvg` let the `web` Vitest project check its marks, ticks and SVG with no DOM.
- **P2: The curves come from `valueAtPercentile`,** `percentileFor`'s inverse for the five curves WHO publishes.
  - The z-scores are Φ⁻¹ of 3, 15, 50, 85 and 97 %, to 17 digits, so `percentileFor` reads each curve back to within 1e-9 points.
  - They all lie inside ±3 SD, so M4.2's restricted application never applies.
  - It answers in the unit growth records store, as `percentileFor` takes it, so curves and measurements convert to the axis through one function.
  - It answers `"unavailable"` for a boy and for an age that isn't a whole day from 0 to 730, as `percentileFor` does.
  - **The gate:** `curve-gate.test.ts` holds every curve within 0.0005 of WHO's printed value on every day, WHO's own rounding to three decimals. A curve a day out of step misses by at least 0.0036.
- **P3: The age window** (Andrew, 10 Oct 2026).
  - It is the smallest of birth to 6 months (days 0 to 182), birth to 1 year (0 to 365) and birth to 2 years (0 to 730) that covers her age today, in the household's zone.
  - The x-axis is in months of 30.4375 days, WHO's own month. Day 182 is 5.98 months and day 730 is 23.98.
  - Ticks fall every month, every 2 months and every 3 months respectively.
  - Past day 730 the window stays at 2 years, and later measurements leave the chart for the table (P8).
- **P4: Units** (Andrew, 10 Oct 2026).
  - The weight axis is in kg for a kg or g household, and in lb for lb & oz. Length and head circumference are in cm or in.
  - The table and a point's details show the household's exact unit:
    - kg to 2 decimals: "4.30 kg"
    - grams whole: "4300 g"
    - pounds with ounces to 0.1: "9 lb 7.7 oz", from the domain's `poundsOuncesFromGrams`
    - cm or in to 1 decimal: "54.5 cm", "21.5 in"
  - Values are stored at full precision and rounded only here (§3.1). M4.4 can reuse `formatMeasurement`.
- **P5: Percentiles read as whole numbers from 1st to 99th,** and as "<1st" or ">99th" past them (Andrew, 10 Oct 2026, M4.2). `"unavailable"` reads "Percentile unavailable".
  - A value from 0.5 to 99.5 rounds to its whole number. Below 0.5 is "<1st", and 99.5 and above is ">99th", so no 0th or 100th ever shows.
  - Ordinals come from `Intl.PluralRules("en-US", { type: "ordinal" })`: 1st, 2nd, 3rd, 11th, 21st.
  - The curves are labelled the same way: 3rd, 15th, 50th, 85th, 97th.
- **P6: Ages read in calendar months, then days:** "Birth", "14 d", "1 mo", "1 mo 5 d", "23 mo 30 d".
  - `ageInMonthsAndDays` counts whole calendar months. A month from the 31st lands on the last day of a shorter month, so a 31 January birth is 1 month old on 28 February.
  - It answers `null` before the birth date, which reads "Before birth". M4.3 lets a measurement be restored from before the birth date (see M3.5's hand-off).
- **P7: Dates are the household's day,** written in the phone's locale with `Intl.DateTimeFormat`: "Oct 6, 2026" in en-US.
  - Both the date shown and the age come from the measurement's local date in the household's zone, as `percentileFor`'s age does (M4.2).
- **P8: What the chart plots.**
  - Only measurements with the chosen metric appear, for that metric.
  - One is plotted only on days 0 to 730. A measurement from before the birth date or after day 730 is still listed in the table, with "Percentile unavailable".
  - No measurement is after today, so the window always covers every plotted point.
  - Her points are plotted oldest first, so the line joining them and the keyboard follow her age, while the table runs newest first, as `GET /api/growth` answers.
  - A boy gets no chart (P11). His measurements are still listed, with "Percentile unavailable".
- **P9: Colours and marks, with no colour judgement.**
  - **The curves:** all five in `--muted-foreground`. The 50th is heavier (1.5 px at 0.9 opacity), and the others are 1 px at 0.55. No fills, and no red or green anywhere.
  - **Labels:** "3rd" to "97th" at each curve's right end, as an 11 px `text` mark. No legend.
  - **Her measurements:** `--primary` dots of radius 4, ringed in `--background`, joined by a 2 px `--primary` line.
  - **Theming:** colours are CSS variables in the SVG's attributes, so they follow light, dark and the `data-theme` override with no theme code. Axes, grid and ticks use `currentColor`.
  - **Spacing:** `nice: 10` on y and a 320 px height keep the labels apart. The prototype measured at least 13.5 px between label baselines for every metric, unit and window at 288 px wide.
  - **Focus:** only her points take focus or a tooltip. Every other mark is wrapped in `decorative()`, text marks included, since they take focus otherwise.
- **P10: The tooltip and the keyboard.**
  - **Tap:** TanStack picks the nearest of her points within 48 px. It pins a tooltip (`role="dialog"`) with the value and percentile over the date and age. Tapping elsewhere dismisses it.
  - **Keyboard:** Tab reaches the chart, and focus announces her oldest point (`role="status"`). The arrows, Home and End move between her points, Enter pins and Escape dismisses.
  - **The text:** the tooltip's accessible name reads "Oct 6, 2026 · 1 mo 5 d · 4.30 kg · 47th". The percentile reads "47th", as the curves are labelled.
  - **Focus outline:** after a tap, Chromium draws a focus outline even though `:focus-visible` is false. The chart's class removes it for focus that isn't from the keyboard.
- **P11: The page's states,** following Today's (M1.11).
  - **Loading:** "Loading…" while `me` or the measurements are on their way.
  - **Failed:** "Growth couldn't be loaded." when either fails.
  - **No measurements of the chosen metric yet:** the curves still show, with "No weight measurements yet" (or length, or head circumference) under the chart, and no table.
  - **A boy:** "WHO's curves here are for girls, so there are no curves or percentiles to show." in place of the chart. His measurements are still listed (P8).
  - The page title is "Growth", with the child's name under it, as Today has.
- **P12: The metric switch** is the Settings unit picker's `ToggleGroup`: Weight, Length and Head, in that order.
  - It lives in the page's state, and opens on Weight. Leaving the tab forgets it.
  - It is not in the URL. Nothing links to a metric yet, and M4.4 can move it there if its edit flow needs to come back to one.
- **P13: Data and refresh.**
  - `useGrowth()` reads `GET /api/growth` keyed `["growth"]`, which the socket already refreshes on every growth change.
  - The page reads `me` for the zone, the units, the birth date and the sex, so an edit in Settings redraws it at once (M4.2's hand-off).
  - "Today", for the window, comes from M1.11's clock store with a one-minute tick: `useMinute()`, beside `useNow()` in `timer/use-now.ts`. Render stays pure, and the window steps over within a minute of the household's midnight. `useNow()`'s one-second tick would redraw the chart every second.

  - §3.1's `growth/` bullet gains `valueAtPercentile` and `ageInMonthsAndDays`.

- [ ] **Step 1: Write the failing tests.** Create `packages/domain/test/growth/value-at-percentile.test.ts`. WHO's medians on day 0 are 3.2322 kg, 49.1477 cm and 33.8787 cm, as M4.2's tests pin:

```ts
import { describe, expect, it } from "vitest"
import {
  CURVE_PERCENTILES,
  type CurvePercentile,
  type GrowthMetric,
  percentileFor,
  valueAtPercentile,
} from "../../src/index.ts"

const METRICS = [
  "weightForAge",
  "lengthForAge",
  "headCircumferenceForAge",
] as const satisfies ReadonlyArray<GrowthMetric>

const READ_BACK_DAYS = [0, 1, 365, 730]

const drawn = (metric: GrowthMetric, ageDays: number, curve: CurvePercentile): number => {
  const value = valueAtPercentile(metric, "female", ageDays, curve)
  if (value === "unavailable") throw new Error(`No value at percentile ${curve} for ${metric} on day ${ageDays}`)
  return value
}

describe("valueAtPercentile", () => {
  it("draws the curves WHO publishes for its charts, the 3rd to the 97th", () => {
    expect(CURVE_PERCENTILES).toEqual([3, 15, 50, 85, 97])
  })

  it("puts the 50th percentile at WHO's median, in the unit growth records store", () => {
    expect(valueAtPercentile("weightForAge", "female", 0, 50)).toBeCloseTo(3232.2, 9)
    expect(valueAtPercentile("lengthForAge", "female", 0, 50)).toBeCloseTo(49.1477, 12)
    expect(valueAtPercentile("headCircumferenceForAge", "female", 0, 50)).toBeCloseTo(33.8787, 12)
  })

  it.each(METRICS.flatMap((metric) => CURVE_PERCENTILES.map((curve) => ({ metric, curve }))))(
    "draws $metric at percentile $curve where percentileFor reads it back, on days 0, 1, 365 and 730",
    ({ metric, curve }) => {
      for (const day of READ_BACK_DAYS) {
        expect(percentileFor(metric, "female", day, drawn(metric, day, curve))).toBeCloseTo(curve, 9)
      }
    },
  )

  it.each([
    { reason: "a boy, whose tables aren't bundled", sex: "male", ageDays: 0 },
```

```ts
import { type LocalDate, utcMidnightOf } from "../time/calendar.ts"
import { DAY_MS } from "../time/instant.ts"

export interface MonthsAndDays {
  readonly months: number
  readonly days: number
}

export const ageInDays = (measuredOn: LocalDate, birthDate: LocalDate): number =>
  (utcMidnightOf(measuredOn) - utcMidnightOf(birthDate)) / DAY_MS

const utcDay = (year: number, monthIndex: number, day: number): number =>
  new Date(0).setUTCFullYear(year, monthIndex, day)

const sameDateMonthsLater = (birth: Date, months: number): number => {
  const year = birth.getUTCFullYear()
  const monthIndex = birth.getUTCMonth() + months
  const daysInMonth = new Date(utcDay(year, monthIndex + 1, 0)).getUTCDate()
  return utcDay(year, monthIndex, Math.min(birth.getUTCDate(), daysInMonth))
}

export const ageInMonthsAndDays = (measuredOn: LocalDate, birthDate: LocalDate): MonthsAndDays | null => {
  const measured = utcMidnightOf(measuredOn)
  const birth = new Date(utcMidnightOf(birthDate))
  if (measured < birth.getTime()) return null
  const on = new Date(measured)
  const calendarMonths = (on.getUTCFullYear() - birth.getUTCFullYear()) * 12 + on.getUTCMonth() - birth.getUTCMonth()
  const months = sameDateMonthsLater(birth, calendarMonths) > measured ? calendarMonths - 1 : calendarMonths
  return { months, days: (measured - sameDateMonthsLater(birth, months)) / DAY_MS }
}
```

```ts
import type { Units } from "@bt/contracts"
import { type GrowthMetric, inchesFromCm, type MonthsAndDays, poundsOuncesFromGrams, roundTo } from "@bt/domain"

const ORDINALS = new Intl.PluralRules("en-US", { type: "ordinal" })

const ORDINAL_SUFFIX = {
  zero: "th",
  one: "st",
  two: "nd",
  few: "rd",
  many: "th",
  other: "th",
} satisfies { readonly [rule in Intl.LDMLPluralRule]: string }

const ordinal = (whole: number) => `${whole}${ORDINAL_SUFFIX[ORDINALS.select(whole)]}`

export const formatPercentile = (percentile: number | "unavailable") => {
  if (percentile === "unavailable") return "Percentile unavailable"
  const whole = Math.round(percentile)
  if (whole < 1) return "<1st"
  return whole > 99 ? ">99th" : ordinal(whole)
}

export const formatAge = (age: MonthsAndDays | null) => {
  if (age === null) return "Before birth"
  const { months, days } = age
  if (months === 0) return days === 0 ? "Birth" : `${days} d`
  return days === 0 ? `${months} mo` : `${months} mo ${days} d`
}

const oneDecimal = (value: number) => roundTo(value, 1).toFixed(1)

const formatWeight = (grams: number, weight: Units["weight"]) => {
  if (weight === "g") return `${Math.round(grams)} g`
  if (weight === "kg") return `${roundTo(grams / 1000, 2).toFixed(2)} kg`
  const { pounds, ounces } = poundsOuncesFromGrams(grams, 1)
  return `${pounds} lb ${ounces.toFixed(1)} oz`
}

export const formatMeasurement = (metric: GrowthMetric, value: number, units: Units) => {
  if (metric === "weightForAge") return formatWeight(value, units.weight)
  return units.length === "in" ? `${oneDecimal(inchesFromCm(value))} in` : `${oneDecimal(value)} cm`
}

export const formatMeasuredOn = (instant: number, timeZone: string, locale?: string) =>
  new Intl.DateTimeFormat(locale, { day: "numeric", month: "short", year: "numeric", timeZone }).format(instant)
```

```ts
import type { Measurement, Me, Sex, Units } from "@bt/contracts"
import {
  ageInDays,
  ageInMonthsAndDays,
  CM_PER_INCH,
  CURVE_PERCENTILES,
  type CurvePercentile,
  GRAMS_PER_POUND,
  type GrowthMetric,
  localDateOf,
  percentileFor,
  valueAtPercentile,
  WHO_LAST_DAY,
} from "@bt/domain"
import { formatAge, formatMeasuredOn, formatMeasurement, formatPercentile } from "./format.ts"
import type { GrowthMetricInfo } from "./metrics.ts"

export const DAYS_PER_MONTH = 30.4375

export interface AgeWindow {
  readonly months: number
  readonly lastDay: number
  readonly tickMonths: number
}

const AGE_WINDOWS = [
  { months: 6, lastDay: 182, tickMonths: 1 },
  { months: 12, lastDay: 365, tickMonths: 2 },
  { months: 24, lastDay: WHO_LAST_DAY, tickMonths: 3 },
] as const satisfies ReadonlyArray<AgeWindow>

export const ageWindowFor = (ageToday: number): AgeWindow =>
  AGE_WINDOWS.find(({ lastDay }) => ageToday <= lastDay) ?? AGE_WINDOWS[2]

export const monthTicks = ({ months, tickMonths }: AgeWindow): ReadonlyArray<number> =>
  Array.from({ length: months / tickMonths + 1 }, (_, index) => index * tickMonths)

export type AxisUnit = "kg" | "lb" | "cm" | "in"

export const axisLabel = (info: GrowthMetricInfo, unit: AxisUnit) => `${info.name} (${unit})`

export const axisUnitOf = (metric: GrowthMetric, units: Units): AxisUnit => {
  if (metric !== "weightForAge") return units.length
  return units.weight === "lb_oz" ? "lb" : "kg"
}

const RECORDED_PER_AXIS_UNIT = {
  kg: 1000,
  lb: GRAMS_PER_POUND,
  cm: 1,
  in: CM_PER_INCH,
} satisfies { readonly [unit in AxisUnit]: number }

export const inAxisUnit = (recorded: number, unit: AxisUnit): number => recorded / RECORDED_PER_AXIS_UNIT[unit]

export interface ChartPoint {
  readonly months: number
  readonly value: number
}

export interface Curve {
  readonly percentile: CurvePercentile
  readonly label: string
  readonly points: ReadonlyArray<ChartPoint>
}

export const curvesFor = (
  metric: GrowthMetric,
  sex: Sex,
  ageWindow: AgeWindow,
  unit: AxisUnit,
): ReadonlyArray<Curve> | "unavailable" => {
  if (valueAtPercentile(metric, sex, 0, 50) === "unavailable") return "unavailable"
  const days = Array.from({ length: ageWindow.lastDay + 1 }, (_, day) => day)
  return CURVE_PERCENTILES.map((percentile) => ({
    percentile,
    label: formatPercentile(percentile),
    points: days.flatMap((day) => {
      const value = valueAtPercentile(metric, sex, day, percentile)
      return value === "unavailable" ? [] : [{ months: day / DAYS_PER_MONTH, value: inAxisUnit(value, unit) }]
    }),
  }))
}

export interface CurveEnd extends ChartPoint {
  readonly label: string
}

export const curveEnds = (curves: ReadonlyArray<Curve>): ReadonlyArray<CurveEnd> =>
  curves.flatMap(({ label, points }) => {
    const end = points.at(-1)
    return end === undefined ? [] : [{ ...end, label }]
  })

export interface GrowthRow {
  readonly id: string
  readonly measuredOn: string
  readonly age: string
  readonly value: string
  readonly percentile: string
  readonly point: ChartPoint | null
}

export const growthRows = (
  measurements: ReadonlyArray<Measurement>,
  info: GrowthMetricInfo,
  { household, child }: Me,
  locale?: string,
): ReadonlyArray<GrowthRow> =>
  measurements.flatMap((measurement) => {
    const recorded = info.recorded(measurement)
    if (recorded === null) return []
    const measuredOn = localDateOf(measurement.measuredAt, household.timeZone)
    const ageDays = ageInDays(measuredOn, child.birthDate)
    const onTheChart = ageDays >= 0 && ageDays <= WHO_LAST_DAY
    return [
      {
        id: measurement.id,
        measuredOn: formatMeasuredOn(measurement.measuredAt, household.timeZone, locale),
        age: formatAge(ageInMonthsAndDays(measuredOn, child.birthDate)),
        value: formatMeasurement(info.metric, recorded, household.units),
        percentile: formatPercentile(percentileFor(info.metric, child.sex, ageDays, recorded)),
        point: onTheChart
          ? { months: ageDays / DAYS_PER_MONTH, value: inAxisUnit(recorded, axisUnitOf(info.metric, household.units)) }
          : null,
      },
    ]
  })
```

```ts
import { defineChart, dot, lineY, text } from "@tanstack/charts"
import { decorative } from "@tanstack/charts/mark/decorative"
import { scaleLinear } from "@tanstack/charts/scales/linear"
import { tooltip } from "@tanstack/charts/tooltip"
import { type AgeWindow, type Curve, curveEnds, type GrowthRow, monthTicks } from "./chart-model.ts"

const CURVE_PAINT = "var(--muted-foreground)"
const ACCENT = "var(--primary)"
const SURFACE = "var(--background)"

const tickNumber = new Intl.NumberFormat(undefined, { maximumFractionDigits: 1 })

export interface PlottedRow {
  readonly id: string
  readonly months: number
  readonly value: number
  readonly row: GrowthRow
}

export interface GrowthChartModel {
  readonly ageWindow: AgeWindow
  readonly axisLabel: string
  readonly curves: ReadonlyArray<Curve>
  readonly plotted: ReadonlyArray<PlottedRow>
}

export const plottedRows = (rows: ReadonlyArray<GrowthRow>): ReadonlyArray<PlottedRow> =>
  rows
    .flatMap((row) => (row.point === null ? [] : [{ id: row.id, ...row.point, row }]))
    .toSorted((a, b) => a.months - b.months)

export const pointSummary = ({ measuredOn, age, value, percentile }: GrowthRow) =>
  [measuredOn, age, value, percentile].join(" · ")

const curveMark = ({ percentile, points }: Curve) => {
  const median = percentile === 50
  return decorative(
    lineY(points, {
      id: `curve-${percentile}`,
      x: "months",
      y: "value",
      stroke: CURVE_PAINT,
      strokeWidth: median ? 1.5 : 1,
      strokeOpacity: median ? 0.9 : 0.55,
    }),
  )
}

export const growthChartDefinition = ({ ageWindow, axisLabel, curves, plotted }: GrowthChartModel) =>
  defineChart({
    marks: [
      ...curves.map(curveMark),
      decorative(
        text(curveEnds(curves), {
          id: "curve-labels",
          x: "months",
          y: "value",
          text: "label",
          anchor: "start",
          dx: 6,
          fill: CURVE_PAINT,
          fontSize: 11,
        }),
      ),
      decorative(lineY(plotted, { id: "her-line", x: "months", y: "value", stroke: ACCENT, strokeWidth: 2 })),
      dot(plotted, {
        id: "her-points",
        x: "months",
        y: "value",
        key: "id",
        r: 4,
        fill: ACCENT,
        stroke: SURFACE,
        strokeWidth: 2,
      }),
    ],
    scales: {
      x: {
        scale: scaleLinear().domain([0, ageWindow.months]),
        grid: true,
        axis: { label: "Age (months)", ticks: { values: [...monthTicks(ageWindow)], format: (month) => `${month}` } },
      },
      y: {
        scale: scaleLinear,
        nice: 10,
        grid: true,
        axis: { label: axisLabel, ticks: { format: (value) => tickNumber.format(value) } },
      },
    },
    focusRing: { radius: 7, fill: "none", stroke: ACCENT, strokeWidth: 2 },
    tooltip: {
      use: tooltip,
      format: (point) => pointSummary(point.datum.row),
      placement: ["top", "bottom"],
      offset: 12,
    },
  })
```

  Why the less obvious settings (P9, P10):
  - `decorative()` keeps the curves, her line and the labels from taking focus.
  - `focusRing.fill: "none"`: the default fill, `Canvas`, covers the focused dot.
  - `ticks.format` is needed because the compact scale writes "1.0" otherwise.
  - The x scale is configured with a fixed domain, so the 6, 12 and 24 ticks exist.
  - `nice: 10` keeps the y domain tight, so the curve labels sit apart.
  - Don't set `clip: true`: it would cut off the labels.

```ts
import { ageInDays, localDateOf } from "@bt/domain"
import { useMemo } from "react"
import { useMinute } from "../../timer/use-now.ts"
import { ageWindowFor, axisLabel, axisUnitOf, curvesFor, growthRows } from "./chart-model.ts"

export const useGrowthView = (me: Me, measurements: ReadonlyArray<Measurement>, info: GrowthMetricInfo) => {
  const now = useMinute()
  const ageWindow = ageWindowFor(ageInDays(localDateOf(now, me.household.timeZone), me.child.birthDate))

    const unit = axisUnitOf(info.metric, me.household.units)
    const rows = growthRows(measurements, info, me)

    const chart =

        ? null
        : { ageWindow, axisLabel: axisLabel(info, unit), curves, plotted: plottedRows(rows) }
```
