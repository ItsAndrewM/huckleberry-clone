# M1.12 Sheets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by Andrew on 10 Oct 2026) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From Today, a parent logs what just happened in two taps, even at 3 a.m. on one bar of signal:
- a diaper: Diaper, then Pee, Poo or Both
- a bottle: Bottle, then Save. It's prefilled with the last bottle, in the household's unit, and tops up a feed that's running.
- a nursing feed: Nursing, then Left or Right. The same sheet switches, pauses, resumes, adds a bottle and finishes, correcting the stop time when the feed ran on.
- a feed after the fact: its start, the first side and the minutes on each side
- any of them at an earlier time, read on the household's clock

Each one shows on Today at once and offers Undo for five seconds. It survives a dropped connection or an expired sign-in.

**Architecture:** `apps/web` gains three layers:
- **Saving** (`src/api/`):
  - Every save a sheet makes is an `Action`: data built from the contract's payload schemas. `send` turns one into its endpoint's call.
  - `pendingToday` writes a new entry into the `today` cache before the household answers, and moves today's totals with `@bt/domain`'s `totalsIn`. `savedToday` swaps in the answer.
- **The sheet frame** (`src/sheets/`):
  - One `SheetsProvider` in the shell holds which sheet is open, the failed send and the Undo toast. It runs every save through one TanStack mutation (`useSend`).
  - Pure modules run in Node tests: the state changes (`sheets-state.ts`), the time a parent picks (`when.ts`, D11), what a failure says (`failure.ts`) and the sign-in draft (`drafts.ts`).
  - The components only display: `Sheet` on shadcn's Drawer, `WhenField`, `FailureNote` and `UndoToast`.
- **The sheets** (`src/features/diaper/`, `src/features/feed/`): Diaper, Bottle, Nursing (start, running, paused, finish) and Past feed. Each is a form that builds an `Action` and hands it to the provider.

**Tech Stack:** React 19.3, TypeScript 5.9.3, TanStack Query 5.104.1, `effect` 4.0.1 (Schema), `@bt/contracts` and `@bt/domain`, shadcn 4.21.4 on Base UI 1.8.0 (its Drawer), Tailwind CSS 4.3.3, `lucide-react` 1.51.0, Vitest 4.1.11, Playwright 1.64.0, oxlint 1.87.0 and oxfmt 0.72.0, Node 24.21.0. ## Decisions this plan makes (veto in review)

- **P1: A bottle tops up the feed that's running or paused** (Andrew, 10 Oct 2026).
  - With a feed active, the Bottle sheet says "Adds to the feed that started at 2:10 AM." It saves with `POST /api/feeds/:id/bottle` and the feed's version.
  - With none, it saves with `POST /api/feeds`, one portion and no segments.
  - A top-up stays one feed, counted once in "Feeds started".
- **P2: A past feed is its start, the first side, and the minutes on each side, plus an optional bottle** (Andrew).
  - The sides run end to end from the start, and the bottle comes at the end. A gap between sides can't be entered; the live timer covers that.
  - It opens from the Nursing sheet's "Log a past feed".
- **P3: "Saved · Undo" for five seconds after each new entry** (Andrew).
  - The new entries: a diaper, a bottle, a started feed, a past feed, and a bottle added to a feed.
  - Undo deletes the entry with the version the household answered: `DELETE /api/diapers/:id`, `/api/feeds/:id`, or `/api/portions/:id` with `deleteIfEmpty: false`. A failed Undo says so in the toast.
  - A running feed's controls get no Undo: Switch, Pause and Resume each have an obvious reverse, and Finish has its stop-time step.
- **P4: The last side is tagged, not suggested** (Andrew).
  - The Nursing sheet's Left and Right look alike. `prefill.lastSide` adds "Last" under one; a screen reader hears "Right Last".
  - Resuming a paused feed tags the side that feed ended on.
- **P5: Plain conflict messages here, recovery in M1.13** (Andrew).
  - `failure.ts` gives each refusal one sentence: who started the running feed, and when; which feed a past feed overlaps; who changed the feed or diaper a moment ago; "This was already saved."; a time in the future, before the birth, before the side started, or a side over 4 hours.
  - The sheet stays open on the household's current copy, because Today refetches after every failure.
  - Finishing at the running side's start, with nothing else in the feed, asks "Delete this feed?". Delete resends with `deleteIfEmpty: true` and a new actionId.
  - M1.13 adds Reload, Reapply, and applying replayed values as an edit.
- **P6: The sheets live in the shell.**
  - `SheetsProvider`, `LogSheets` and `UndoToast` sit in `Shell`, so a save that fails after the parent changed tabs still reopens its sheet, and a sign-in draft comes back on any route.
  - The provider holds `{ open, failed, toast }` and one `useMutation` (`useSend`); `busy` is the send in flight.
  - The toast expires by a sweep the provider schedules when it shows one, timed from the same moment as the toast's `until`. `UndoToast` therefore doesn't subscribe to M1.11's clock, which stops once nothing shows a timer (M1.11's P3).
- **P7: Optimistic creates; waited-for controls** (§3.4).
  - A diaper, a bottle, a past feed, a started feed and a bottle added to a feed go into the `today` cache at once, with a `pending:<actionId>` id.
  - Today's totals move by the difference `totalsIn` finds over the local day. The recent list shows "Saving…" in place of who logged the entry.
  - On failure the cache rolls back and Today refetches. On success the household's answer replaces the pending entry, and the answer's `changed` keys are invalidated.
  - Switch, Pause, Resume and Finish aren't optimistic. Their buttons wait (`busy`), and the answer goes straight into the cache with its new version, so the next tap sends that version (the M1.7 handoff).
- **P8: A sheet closes when its save leaves, but only online.**
  - Creates and Finish close the sheet at once while the connectivity store says online.
  - Offline or signed out, the sheet stays open and the failure shows in place: AC 11's "keep the form".
  - A failure reopens the sheet with the values sent, since each sheet rebuilds its form from the failed action, and with the reason.
- **P9: An action is data.**
  - `Action` is an Effect Schema union over the contract's payload schemas (`NewDiaper`, `NewFeed`, `FeedStart`, `TimedAction` and the rest). A failed send, a retry and a sign-in draft all carry the same value.
  - Try again resends it unchanged, with the same actionId.
  - Editing a failed entry and saving again keeps the sheet's actionId. §3.3 explains why: rotating it would duplicate a save whose answer was lost.
  - Each Switch, Pause, Resume, Finish and Undo makes its own actionId.
- **P10: The sign-in draft.**
  - The banner's Sign in sits under an open sheet. So a failed save's note offers its own Sign in link, and its click saves `{route, sending, createdAt}` to `sessionStorage` before the navigation. The storage is guarded as `theme.ts` guards `localStorage`, through the shared `storage.ts`.
  - `main.tsx` takes the draft once, for the route the app opens on.
  - Within 12 hours (`DRAFT_RETRY_MS`, half the receipts' retention), the provider resends it once. The resend runs from an effect guarded by a module-level flag, the react-use-effect-guard skill's app-initialization pattern; StrictMode's second run finds the flag set.
  - An older draft reopens its sheet: "This wasn't saved before you signed in, Thu 8:30 PM. Save it now?". Save now sends it under a new actionId (§3.3).
- **P11: The time a parent picks.**
  - Each sheet shows "Now · Change". Change opens a `datetime-local` input (step 60), set to the household's wall clock with `localDateTimeOf`, new in `@bt/domain`.
  - The input is read in the household's zone with `resolveLocal` (D11). A time the clocks skipped is refused: "That time didn't happen: the clocks went forward." A time that happened twice asks "1:30 AM (first)" or "(second)". A time more than 5 minutes ahead is refused.
  - Finishing a feed can't stop before the running side started. A stop picked in the start's own minute means the start itself, which drops that side (M1.7).
- **P12: `tapTime()`.**
  - A tap's time is `Date.now()`, read in the handler through `src/sheets/tap-time.ts`.
  - oxlint's `react/purity` flags `Date.now()` in any closure made during render, though a handler may be impure. The named helper says what the read is for.
- **P13: The page-lifecycle guard is a test over the whole web app.**
  - `scripts/page-lifecycle.test.ts` fails on any `pagehide`, `beforeunload` or `visibilitychange` handler in `apps/web/src`: the "grep check in CI" §3.5 allows.
  - It's stricter than "mutation modules". Nothing in the app needs those events, and TanStack's focus refetch lives in its own package.
- **P14: shadcn's Drawer, as §3.4 says, at 27.5 KB gzip.**
  - The web bundle grows from 194.3 KB (M1.11) to 231.1 KB gzip. About 27.5 KB of that is Base UI's Drawer: swipe to close, the grab handle and stacked sheets. About 9 KB is M1.12's own code.
  - Base UI's Dialog styled as a bottom sheet would cost about 16 KB, without the swipe. The Drawer is kept for the iPhone sheet feel; M5.5 can split it out.
  - It needs no new package. The generated file imports only `@base-ui/react`, and its `data-starting-style` and `data-ending-style` variants stand in for `tw-animate-css`.
  - M1.10's P10 lint edits apply to it: no comments, React's imports by name, `use()`, and the React 19 context element.
- **P15: The running card doesn't open the sheet.** The Nursing quick action, just below the card, opens the running feed's controls. A tap target over the card can wait for M5.2's accessibility pass; M1.11's handoff suggested one.
- **P16: The Bottle sheet's amounts.**
  - Breast milk and formula each have −, a typed amount and +, in the household's unit: ±10 mL, or ±0.5 fl oz from the amount shown.
  - They start from `prefill.lastBottle` (D13), or from 0. Save waits for some milk.
  - A stored amount goes back unchanged unless the parent edits it: 59.1 mL shows as 2.0 fl oz and saves as 59.1 (the M1.2 handoff).
- **P17: E2E plays the household.**
  - The sheet specs answer `/api/today`, `/api/last24h` and each save with `page.route` (`e2e/played-household.ts`). Parallel browsers then never share a running feed, and every request body is checked.
  - Two specs use the real local household: one diaper round trip, and AC 11. WebKit's `page.route` doesn't see a page's requests while its service worker runs (the M1.14 handoff).
  - A Chromium-only spec checks that Try again reuses the actionId.
- **P18: The tap budgets (AC 2).**
  - A diaper: Diaper, then Pee, Poo or Both.
  - A bottle: Bottle, then Save.
  - A feed: Nursing, then Left or Right.
  - The diaper spec counts its taps.
- **P19: The quick actions wait for Today** (M1.11's handoff).
  - `QuickActions` takes `ready` from the Today page. Until both Today and `me` have loaded, and while either has failed, its buttons are disabled.
  - Every sheet needs the household's zone and units, and the Nursing and Bottle sheets need Today's running feed and prefill. A Bottle opened without Today could log a separate feed while one is running.
  - A spec pins this. Another pins M1.11's `pb-16`: the last row of a long recent list clears the bar.

## Review Focus

The five ways this is most likely to fail a parent, each with the test that pins it:

1. **Both phones touch the running feed at once (AC 13).**
   - A Switch that meets the other phone's Pause must neither resend nor guess. It says who changed the feed, and shows the feed as it is now.
   - Pinned by `nursing.spec.ts` ("says who changed the running feed a moment ago", Task 8) and `failure.test.ts` (Task 5).
2. **A save whose answer is lost, then retried (AC 14).**
   - Try again must reuse the actionId, so the household's receipt answers it. An edited resave keeps it too.
   - Pinned by `sheets-offline.spec.ts`'s Chromium test (Task 6) and `sheets-state.test.ts` (Task 4).
3. **A phone in another zone, around a clock change.**
   - A picked time is read on the household's clock, and 1:30 on the night the clocks go back asks which one.
   - Pinned by `when.test.ts` (Task 3) and the time-picking specs run in Europe/London (Tasks 6, 8, 9).
4. **An fl oz household saving its last bottle again, untouched.**
   - 59.1 mL must stay 59.1, not round-trip through 2.0 oz.
   - Pinned by `bottle.spec.ts`'s fl oz test and `amounts.test.ts` (Task 7).
5. **A sign-in that expires mid-entry.**
   - The entry must survive Access's round trip and save exactly once. After 12 hours, it asks first.
   - Pinned by `sign-in-draft.spec.ts` and `drafts.test.ts` (Task 10).

```ts
import type { SavedDiaper, SavedFeed } from "@bt/contracts"
import { type Action, type DiaperAction, type FeedAction, isDiaperAction } from "./actions.ts"
import type { HouseholdApi } from "./client.ts"

export type Saved = SavedDiaper | SavedFeed

type OnFeed = Extract<FeedAction, { readonly id: string }>
type NewFeed = Exclude<FeedAction, OnFeed>

const sendDiaper = (api: HouseholdApi, action: DiaperAction): Promise<SavedDiaper> =>
  action.kind === "logDiaper"
    ? api.request((client) => client.diapers.logDiaper({ payload: action.payload }))
    : api.request((client) => client.diapers.deleteDiaper({ params: { id: action.id }, payload: action.payload }))

const sendNewFeed = (api: HouseholdApi, action: NewFeed): Promise<SavedFeed> =>
  action.kind === "logFeed"
    ? api.request((client) => client.feeds.logFeed({ payload: action.payload }))
    : api.request((client) => client.feeds.startFeed({ payload: action.payload }))

const sendOnFeed = (api: HouseholdApi, action: OnFeed): Promise<SavedFeed> => {
  const params = { id: action.id }
  switch (action.kind) {
    case "switchSide":
      return api.request((client) => client.feeds.switchSide({ params, payload: action.payload }))
    case "pauseFeed":
      return api.request((client) => client.feeds.pauseFeed({ params, payload: action.payload }))
    case "resumeFeed":
      return api.request((client) => client.feeds.resumeFeed({ params, payload: action.payload }))
    case "addBottle":
      return api.request((client) => client.feeds.addBottle({ params, payload: action.payload }))
    case "finishFeed":
      return api.request((client) => client.feeds.finishFeed({ params, payload: action.payload }))
    case "deleteFeed":
      return api.request((client) => client.feeds.deleteFeed({ params, payload: action.payload }))
    case "deletePortion":
      return api.request((client) => client.portions.deletePortion({ params, payload: action.payload }))
  }
}

export const send = (api: HouseholdApi, action: Action): Promise<Saved> => {
  if (isDiaperAction(action)) return sendDiaper(api, action)
  return "id" in action ? sendOnFeed(api, action) : sendNewFeed(api, action)
}
```

```ts
  readonly now: Instant
```

```ts
import { type DiaperChange, roundTo, type StartedFeed, totalsIn, zonedDayBounds } from "@bt/domain"
import type { Action } from "./actions.ts"
import { type Author, isPending, pendingDiaper, pendingFeed, pendingId, startedFeed, withBottle } from "./pending.ts"
import type { Saved } from "./send.ts"

export interface Pending extends Author {
  readonly zone: string
}

const idOf = (entry: RecentEntry) => (entry.kind === "feed" ? entry.feed.id : entry.diaper.id)

const timeOf = (entry: RecentEntry) => (entry.kind === "feed" ? entry.feed.startedAt : entry.diaper.occurredAt)

const without = (recent: ReadonlyArray<RecentEntry>, id: string) => recent.filter((entry) => idOf(entry) !== id)

const withEntry = (recent: ReadonlyArray<RecentEntry>, entry: RecentEntry) =>
  [...without(recent, idOf(entry)), entry].toSorted((a, b) => timeOf(b) - timeOf(a))

const later = (current: Feed | null, feed: Feed) =>
  current === null || current.id === feed.id || feed.startedAt >= current.startedAt ? feed : current

const shifted = (today: Today, pending: Pending, before: Change, after: Change): Totals => {
  const day = zonedDayBounds(today.date, pending.zone)
  const added = totalsIn(day, after.feeds, after.diapers, pending.now)
  const removed = totalsIn(day, before.feeds, before.diapers, pending.now)
  const sum = (key: keyof Totals) => roundTo(today.totals[key] + added[key] - removed[key], 1)
  return {
    feedsStarted: sum("feedsStarted"),
    leftSeconds: sum("leftSeconds"),
    rightSeconds: sum("rightSeconds"),
    nursingSeconds: sum("nursingSeconds"),
    breastMilkMl: sum("breastMilkMl"),
    formulaMl: sum("formulaMl"),
    bottleMl: sum("bottleMl"),
    diapers: sum("diapers"),
    wetDiapers: sum("wetDiapers"),
    dirtyDiapers: sum("dirtyDiapers"),
  }
}

interface Change {
  readonly feeds: ReadonlyArray<StartedFeed>
  readonly diapers: ReadonlyArray<DiaperChange>
}

const NOTHING: Change = { feeds: [], diapers: [] }

const withFeed = (today: Today, pending: Pending, feed: Feed, before: Feed | null): Today => ({
  ...today,
  totals: shifted(today, pending, before === null ? NOTHING : { feeds: [before], diapers: [] }, {
    feeds: [feed],
    diapers: [],
  }),
  activeFeed: feed.status === "active" ? feed : today.activeFeed,
  lastFeed: later(today.lastFeed, feed),
  recent: withEntry(today.recent, { kind: "feed", feed }),
})

export const pendingToday = (today: Today, action: Action, pending: Pending): Today => {
  switch (action.kind) {
    case "logDiaper": {
      const diaper = pendingDiaper(action.payload, pending)
      const recent = withEntry(today.recent, { kind: "diaper", diaper })
      return { ...today, totals: shifted(today, pending, NOTHING, { feeds: [], diapers: [diaper] }), recent }
    }
    case "logFeed":
      return withFeed(today, pending, pendingFeed(action.payload, pending), null)
    case "startFeed":
      return withFeed(today, pending, startedFeed(action.payload, pending), null)
    case "addBottle": {
      const active = today.activeFeed
      if (active?.id !== action.id) return today
      return withFeed(today, pending, withBottle(active, action.payload), active)
    }
    default:
      return today
  }
}

const activeAfter = (active: Feed | null, feed: Feed): Feed | null => {
  if (feed.deletedAt === null && feed.status === "active") return feed
  return active !== null && (active.id === feed.id || isPending(active.id)) ? null : active
}

const savedFeed = (today: Today, feed: Feed, recent: ReadonlyArray<RecentEntry>): Today => {
  const live = feed.deletedAt === null
  return {
    ...today,
    activeFeed: activeAfter(today.activeFeed, feed),
    lastFeed: live ? later(today.lastFeed, feed) : today.lastFeed,
    recent: live ? withEntry(recent, { kind: "feed", feed }) : without(recent, feed.id),
  }
}

export const savedToday = (today: Today, saved: Saved, action: Action): Today => {
  const recent = without(today.recent, pendingId(action.payload.actionId))
  if ("feed" in saved) return savedFeed(today, saved.feed, recent)
  const { diaper } = saved
  const live = diaper.deletedAt === null
  return { ...today, recent: live ? withEntry(recent, { kind: "diaper", diaper }) : without(recent, diaper.id) }
}
```

```ts
import {
  FUTURE_TOLERANCE_MS,
  type Instant,
  type LocalDateTime,
  type LocalResolution,
  localDateTimeOf,
  resolveLocal,
} from "@bt/domain"
import { attempt } from "../storage.ts"

export type Pick = "earlier" | "later" | null

export type When =
  | { readonly kind: "now" }
  | { readonly kind: "at"; readonly local: LocalDateTime; readonly pick: Pick }

type At = Extract<When, { readonly kind: "at" }>

export type WhenIssue = "unreadable" | "nonexistent" | "ambiguous" | "in_future" | "too_early"

export type Resolved =
  | { readonly ok: true; readonly instant: Instant }
  | { readonly ok: false; readonly issue: WhenIssue }

export const NOW: When = { kind: "now" }

const resolutionOf = (local: LocalDateTime, zone: string): LocalResolution | null =>
  attempt(() => resolveLocal(local, zone), null)

export const whenAt = (instant: Instant, zone: string): When => {
  const local = localDateTimeOf(instant, zone)
  const resolution = resolutionOf(local, zone)
  if (resolution?.kind !== "ambiguous") return { kind: "at", local, pick: null }
  return { kind: "at", local, pick: instant < resolution.later ? "earlier" : "later" }
}

const issue = (found: WhenIssue): Resolved => ({ ok: false, issue: found })

const atInstant = ({ local, pick }: At, zone: string): Resolved => {
  const resolution = resolutionOf(local, zone)
  if (resolution === null) return issue("unreadable")
  if (resolution.kind === "nonexistent") return issue("nonexistent")
  if (resolution.kind === "ok") return { ok: true, instant: resolution.instant }
  if (pick === null) return issue("ambiguous")
  return { ok: true, instant: pick === "earlier" ? resolution.earlier : resolution.later }
}

const MINUTE_MS = 60_000

const sameMinute = (a: Instant, b: Instant) => Math.floor(a / MINUTE_MS) === Math.floor(b / MINUTE_MS)

const notBefore = (instant: Instant, earliest: Instant): Resolved => {
  if (instant >= earliest) return { ok: true, instant }
  return sameMinute(instant, earliest) ? { ok: true, instant: earliest } : issue("too_early")
}

export const resolveWhen = (when: When, zone: string, now: Instant, earliest = 0): Resolved => {
  const resolved = when.kind === "now" ? { ok: true as const, instant: now } : atInstant(when, zone)
  if (!resolved.ok) return resolved
  if (resolved.instant > now + FUTURE_TOLERANCE_MS) return issue("in_future")
  return notBefore(resolved.instant, earliest)
}

export const ambiguity = (when: When, zone: string): LocalResolution | null => {
  if (when.kind === "now") return null
  const resolution = resolutionOf(when.local, zone)
  return resolution?.kind === "ambiguous" ? resolution : null
}
```

```ts
import type { Sending } from "./sending.ts"

export interface Toast {
  readonly message: string
  readonly undo: Sending | null
  readonly until: number
}

export const TOAST_MS = 5_000

const addedPortion = (feed: Feed, sent: VersionedPortion) =>
  feed.portions.findLast(
    (portion) =>
      portion.occurredAt === sent.occurredAt &&
      portion.breastMilkMl === sent.breastMilkMl &&
      portion.formulaMl === sent.formulaMl,
  )

const undoFeed = (action: Action, feed: Feed, actionId: string): Action | null => {
  if (action.kind === "logFeed" || action.kind === "startFeed") {
    return { kind: "deleteFeed", id: feed.id, payload: { actionId, version: feed.version } }
  }
  if (action.kind !== "addBottle") return null
  const portion = addedPortion(feed, action.payload)
  if (portion === undefined) return null
  return { kind: "deletePortion", id: portion.id, payload: { actionId, version: feed.version, deleteIfEmpty: false } }
}

export const undoOf = ({ action }: Sending, saved: Saved, actionId: string): Action | null => {
  if ("feed" in saved) return undoFeed(action, saved.feed, actionId)
  if (action.kind !== "logDiaper") return null
  return { kind: "deleteDiaper", id: saved.diaper.id, payload: { actionId, version: saved.diaper.version } }
}

const messageOf = ({ sheet, action }: Sending): string | null => {
  switch (action.kind) {
    case "logDiaper":
      return "Diaper saved"
    case "logFeed":
      return sheet === "pastFeed" ? "Feed saved" : "Bottle saved"
    case "startFeed":
      return "Feed started"
    case "addBottle":
      return "Bottle added to the feed"
    default:
      return null
  }
}

export const toastFor = (sending: Sending, saved: Saved, now: number): Toast | null => {
  const message = messageOf(sending)
  if (message === null) return null
  const undo = undoOf(sending, saved, crypto.randomUUID())
  return { message, undo: undo === null ? null : { sheet: sending.sheet, action: undo }, until: now + TOAST_MS }
}
```

```ts
import { closesOnSend, type Failed, type Sending, type SheetKind } from "./sending.ts"
import { TOAST_MS, type Toast, toastFor } from "./undo.ts"

export interface SheetsState {
  readonly open: SheetKind | null
  readonly failed: Failed | null
  readonly toast: Toast | null
}

export const CLOSED: SheetsState = { open: null, failed: null, toast: null }

const UNDOES = new Set<Action["kind"]>(["deleteDiaper", "deleteFeed", "deletePortion"])

export const sendingState = (state: SheetsState, sending: Sending, online: boolean): SheetsState => ({
  ...state,
  open: online && closesOnSend(sending) ? null : state.open,
  failed: null,
  toast: UNDOES.has(sending.action.kind) ? null : state.toast,
})

const undoFailure = (error: Error, now: number): Toast => ({
  message: error instanceof Offline ? "No connection, so that wasn't undone." : "That wasn't undone.",
  undo: null,
  until: now + TOAST_MS,
})

export const failedState = (state: SheetsState, failed: Failed, now: number): SheetsState => {
  if (UNDOES.has(failed.sending.action.kind)) return { ...state, toast: undoFailure(failed.error, now) }
  return { ...state, open: failed.sending.sheet, failed }
}

export const savedState = (state: SheetsState, sending: Sending, saved: Saved, now: number): SheetsState => ({
  ...state,
  toast: toastFor(sending, saved, now) ?? state.toast,
})

export const expiredState = (state: SheetsState, now: number): SheetsState =>
  state.toast !== null && now >= state.toast.until ? { ...state, toast: null } : state
```

```ts
import {
  type CaregiverName,
  DiaperConflict,
  type Feed,
  FeedConflict,
  type FieldIssue,
  InvalidInput,
  NotFound,
  Unauthorized,
} from "@bt/contracts"
import { AuthRequired, Offline } from "../api/errors.ts"

export interface Note {
  readonly message: string
  readonly retry: string | null
  readonly signIn: boolean
}

export interface Household {
  readonly caregivers: ReadonlyArray<CaregiverName>
  readonly timeZone: string
  readonly childName: string
  readonly locale?: string
}

const TRY_AGAIN = "Try again"

const note = (message: string, retry: string | null = null): Note => ({ message, retry, signIn: false })

const nameOf = ({ caregivers }: Household, id: string) =>
  caregivers.find((caregiver) => caregiver.id === id)?.displayName ?? "The other phone"

const timeOf = ({ locale, timeZone }: Household, instant: number) =>
  new Intl.DateTimeFormat(locale, { hour: "numeric", minute: "2-digit", timeZone }).format(instant)

const spanOf = (household: Household, feed: Feed) =>
  `${timeOf(household, feed.startedAt)}–${feed.endedAt === null ? "now" : timeOf(household, feed.endedAt)}`

const fieldMessage = (issue: FieldIssue, household: Household): string | null => {
  switch (issue) {
    case "in_future":
      return "That time is in the future."
    case "before_birth":
      return `That's before ${household.childName} was born.`
    case "end_not_after_start":
      return "Pick a time after this side started."
    case "out_of_range":
      return "A side can run for 4 hours at most."
    default:
      return null
  }
}

const fieldNote = (error: InvalidInput, household: Household): Note => {
  const messages = error.fieldErrors.map(({ issue }) => fieldMessage(issue, household))
  return note(messages.find((message) => message !== null) ?? "Check the times and amounts, then try again.")
}

const feedNote = (error: FeedConflict, household: Household): Note => {
  const { current } = error
  switch (error.code) {
    case "FEED_ALREADY_ACTIVE":
      return note(`${nameOf(household, current.createdBy)} started a feed at ${timeOf(household, current.startedAt)}.`)
    case "SEGMENT_OVERLAP":
      return note(`This overlaps the feed at ${spanOf(household, current)}.`)
    case "STALE_VERSION":
      return note(`${nameOf(household, current.updatedBy)} changed this feed a moment ago.`)
    case "FEED_EMPTY":
      return note("Nothing would be left in this feed.")
    case "ACTION_REPLAY_MISMATCH":
      return note("This was already saved.")
  }
}

const diaperNote = (error: DiaperConflict, household: Household): Note =>
  error.code === "STALE_VERSION"
    ? note(`${nameOf(household, error.current.updatedBy)} changed this diaper a moment ago.`)
    : note("This was already saved.")

const conflictNote = (error: Error, household: Household): Note | null => {
  if (error instanceof FeedConflict) return feedNote(error, household)
  if (error instanceof DiaperConflict) return diaperNote(error, household)
  return null
}

export const failureNote = (error: Error, household: Household): Note => {
  if (error instanceof Offline)
    return note("No connection. This is kept here: try again once you're back online.", TRY_AGAIN)
  if (error instanceof AuthRequired || error instanceof Unauthorized) {
    return { message: "Your sign-in has expired. Sign in, and this will be saved.", retry: null, signIn: true }
  }
  if (error instanceof InvalidInput) return fieldNote(error, household)
  if (error instanceof NotFound) return note("This has changed since it opened. Today is up to date now.")
  return conflictNote(error, household) ?? note("Not saved.", TRY_AGAIN)
}
```

```ts
      const before = queryClient.getQueryData<Today>(queryKeys.today)
      const me = queryClient.getQueryData<Me>(queryKeys.me)
      if (before !== undefined && me !== undefined) {
        const pending = { by: me.caregiver.id, now: Date.now(), zone: me.household.timeZone }
        queryClient.setQueryData(queryKeys.today, pendingToday(before, action, pending))
      }
      return { before }
    },
    onError: (error, sending, context) => {
      if (context?.before !== undefined) queryClient.setQueryData(queryKeys.today, context.before)
      void queryClient.invalidateQueries({ queryKey: queryKeys.today })
      onFailed({ sending, error })
    },
    onSuccess: (saved, sending) => {
      queryClient.setQueryData<Today>(queryKeys.today, (today) =>
        today === undefined ? today : savedToday(today, saved, sending.action),
      )
      for (const queryKey of saved.changed) void queryClient.invalidateQueries({ queryKey })
      onSaved(sending, saved)
    },
  })
}
```

```tsx
import { type ReactNode, useState } from "react"
import { useConnectivity } from "../api/hooks.ts"
import type { Sending } from "./sending.ts"
import { type Sheets, SheetsContext } from "./sheets-context.ts"
import { CLOSED, expiredState, failedState, savedState, sendingState } from "./sheets-state.ts"
import { TOAST_MS } from "./undo.ts"
import { useSend } from "./use-send.ts"

export const SheetsProvider = ({ children }: { readonly children: ReactNode }) => {
  const [state, setState] = useState(CLOSED)
  const online = useConnectivity() === "online"
  const sweepAfter = (shownAt: number) =>
    setTimeout(() => setState((current) => expiredState(current, shownAt + TOAST_MS)), TOAST_MS)
  const mutation = useSend({
    onFailed: (failed) => {
      const now = Date.now()
      setState((current) => failedState(current, failed, now))
      sweepAfter(now)
    },
    onSaved: (sending, saved) => {
      const now = Date.now()
      setState((current) => savedState(current, sending, saved, now))
      sweepAfter(now)
    },
  })
  const send = (sending: Sending) => {
    setState((current) => sendingState(current, sending, online))
    mutation.mutate(sending)
  }
  const sheets: Sheets = {
    ...state,
    busy: mutation.isPending ? (mutation.variables ?? null) : null,
    show: (sheet) => setState((current) => ({ ...current, open: sheet, failed: null })),
    close: () => setState((current) => ({ ...current, open: null, failed: null })),
    send,
  }
  return <SheetsContext value={sheets}>{children}</SheetsContext>
}
```

```ts
import { MAX_BOTTLE_ML, type VolumeUnit } from "@bt/contracts"
import { flOzFromMl, mlFromFlOz, roundTo } from "@bt/domain"

export const STEP_ML = 10
export const STEP_FL_OZ = 0.5

export const UNIT_LABELS = { ml: "mL", fl_oz: "fl oz" } as const satisfies Record<VolumeUnit, string>

const clamped = (ml: number) => Math.min(MAX_BOTTLE_ML, Math.max(0, roundTo(ml, 1)))

export const amountText = (ml: number, unit: VolumeUnit) =>
  unit === "ml" ? String(roundTo(ml, 1)) : roundTo(flOzFromMl(ml), 1).toFixed(1)

export const stepped = (ml: number, unit: VolumeUnit, steps: number) => {
  if (unit === "ml") return clamped(ml + steps * STEP_ML)
  return clamped(mlFromFlOz(roundTo(flOzFromMl(ml), 1) + steps * STEP_FL_OZ))
}

export const parsedAmount = (text: string, unit: VolumeUnit): number | null => {
  const value = text.trim() === "" ? 0 : Number(text)
  if (!Number.isFinite(value) || value < 0) return null
  const ml = unit === "ml" ? roundTo(value, 1) : mlFromFlOz(value)
  return ml <= MAX_BOTTLE_ML ? ml : null
}
```

```ts
import type { Feed, Prefill } from "@bt/contracts"
import type { FeedAction } from "../../api/actions.ts"
import type { Failed } from "../../sheets/sending.ts"
import { NOW, type When, whenAt } from "../../sheets/when.ts"

export interface Amounts {
  readonly breastMilkMl: number | null
  readonly formulaMl: number | null
}

export interface BottleSession extends Amounts {
  readonly actionId: string
  readonly when: When
}

const sentBottle = (failed: Failed | null) => {
  const action = failed?.sending.action
  if (action?.kind === "addBottle") return action.payload
  if (action?.kind !== "logFeed") return undefined
  const [portion] = action.payload.portions
  return portion === undefined ? undefined : { ...portion, actionId: action.payload.actionId }
}

export const bottleSession = (failed: Failed | null, prefill: Prefill | undefined, zone: string): BottleSession => {
  const sent = sentBottle(failed)
  if (sent !== undefined) {
    const { actionId, breastMilkMl, formulaMl, occurredAt } = sent
    return { actionId, breastMilkMl, formulaMl, when: whenAt(occurredAt, zone) }
  }
  const last = prefill?.lastBottle
  return {
    actionId: crypto.randomUUID(),
    breastMilkMl: last?.breastMilkMl ?? 0,
    formulaMl: last?.formulaMl ?? 0,
    when: NOW,
  }
}

export const hasMilk = ({ breastMilkMl, formulaMl }: Amounts) =>
  breastMilkMl !== null && formulaMl !== null && breastMilkMl + formulaMl > 0

export const bottleAction = (
  actionId: string,
  { breastMilkMl, formulaMl }: Amounts,
  occurredAt: number,
  active: Feed | null,
): FeedAction => {
  const portion = { occurredAt, breastMilkMl: breastMilkMl ?? 0, formulaMl: formulaMl ?? 0 }
  if (active === null) return { kind: "logFeed", payload: { actionId, segments: [], portions: [portion] } }
  return { kind: "addBottle", id: active.id, payload: { actionId, version: active.version, ...portion } }
}
```

```ts
import type { Feed, NursingSegment, Side } from "@bt/contracts"
import type { FeedAction } from "../../api/actions.ts"
import { isPending } from "../../api/pending.ts"

export type NursingState =
  | { readonly kind: "idle" }
  | { readonly kind: "starting" }
  | { readonly kind: "running"; readonly feed: Feed; readonly segment: NursingSegment }
  | { readonly kind: "paused"; readonly feed: Feed; readonly lastSide: Side | null }

export const OTHER_SIDE = { left: "right", right: "left" } as const satisfies Record<Side, Side>

export const SIDE_NAMES = { left: "Left", right: "Right" } as const satisfies Record<Side, string>

const lastSideOf = (feed: Feed): Side | null =>
  feed.segments.toSorted((a, b) => a.startedAt - b.startedAt).at(-1)?.side ?? null

export const nursingState = (active: Feed | null): NursingState => {
  if (active === null) return { kind: "idle" }
  if (isPending(active.id)) return { kind: "starting" }
  const segment = active.segments.find((candidate) => candidate.endedAt === null)
  return segment === undefined
    ? { kind: "paused", feed: active, lastSide: lastSideOf(active) }
    : { kind: "running", feed: active, segment }
}

export const timedAction = (kind: "switchSide" | "pauseFeed", feed: Feed, occurredAt: number): FeedAction => ({
  kind,
  id: feed.id,
  payload: { actionId: crypto.randomUUID(), version: feed.version, occurredAt },
})

export const resumeAction = (feed: Feed, side: Side, occurredAt: number): FeedAction => ({
  kind: "resumeFeed",
  id: feed.id,
  payload: { actionId: crypto.randomUUID(), version: feed.version, side, occurredAt },
})

export const finishAction = (feed: Feed, occurredAt: number, deleteIfEmpty: boolean): FeedAction => ({
  kind: "finishFeed",
  id: feed.id,
  payload: { actionId: crypto.randomUUID(), version: feed.version, occurredAt, deleteIfEmpty },
})
```

```tsx
import { type Feed, FeedConflict, type NursingSegment } from "@bt/contracts"
import { useState } from "react"
import { Button } from "../../components/ui/button.tsx"
import { FailureNote } from "../../sheets/failure-note.tsx"
import type { Failed } from "../../sheets/sending.ts"
import { failedFor, useSheets } from "../../sheets/sheets-context.ts"
import { tapTime } from "../../sheets/tap-time.ts"
import { WhenField } from "../../sheets/when-field.tsx"
import { NOW, resolveWhen, type When, whenAt } from "../../sheets/when.ts"
import { useNow } from "../../timer/use-now.ts"
import { finishAction } from "./nursing-state.ts"

interface FinishViewProps {
  readonly feed: Feed
  readonly segment: NursingSegment
  readonly zone: string
  readonly onBack: () => void
}

const sentStop = (failed: Failed | null, zone: string): When => {
  const action = failed?.sending.action
  return action?.kind === "finishFeed" ? whenAt(action.payload.occurredAt, zone) : NOW
}

const emptiedBy = (failed: Failed | null) => {
  const action = failed?.sending.action
  if (!(failed?.error instanceof FeedConflict) || failed.error.code !== "FEED_EMPTY") return null
  return action?.kind === "finishFeed" ? { current: failed.error.current, stoppedAt: action.payload.occurredAt } : null
}

export const FinishView = ({ feed, segment, zone, onBack }: FinishViewProps) => {
  const sheets = useSheets()
  const failed = failedFor(sheets, "nursing")
  const [when, setWhen] = useState(() => sentStop(failed, zone))
  const now = useNow()
  const emptied = emptiedBy(failed)
  if (emptied !== null) {
    return (
      <div role="alert" className="flex flex-col gap-3">
        <p className="text-base">Stopping at the start leaves nothing in this feed. Delete it?</p>
        <Button
          variant="destructive"
          size="lg"
          onClick={() =>
            sheets.send({ sheet: "nursing", action: finishAction(emptied.current, emptied.stoppedAt, true) })
          }
        >
          Delete feed
        </Button>
        <Button variant="ghost" size="lg" onClick={onBack}>
          Keep it
        </Button>
      </div>
    )
  }
  const finish = () => {
    const resolved = resolveWhen(when, zone, tapTime(), segment.startedAt)
    if (resolved.ok) sheets.send({ sheet: "nursing", action: finishAction(feed, resolved.instant, false) })
  }
  return (
    <>
      <WhenField label="Stopped" when={when} onChange={setWhen} zone={zone} now={now} earliest={segment.startedAt} />
      <Button
        size="lg"
        className="h-14 text-lg"
        disabled={!resolveWhen(when, zone, now, segment.startedAt).ok}
        onClick={finish}
      >
        Finish feed
      </Button>
      <Button variant="ghost" size="lg" onClick={onBack}>
        Back
      </Button>
      <FailureNote sheet="nursing" />
    </>
  )
}
```

```ts
import { MAX_SEGMENT_MS, type NewFeed, type Side } from "@bt/contracts"
import type { Failed } from "../../sheets/sending.ts"
import { type When, whenAt } from "../../sheets/when.ts"
import type { Amounts } from "./bottle-entry.ts"
import { OTHER_SIDE } from "./nursing-state.ts"

export const MINUTE_MS = 60_000
export const MAX_SIDE_MINUTES = MAX_SEGMENT_MS / MINUTE_MS
const EARLIER_MS = 30 * MINUTE_MS

export interface PastFeed extends Amounts {
  readonly first: Side
  readonly minutes: { readonly left: number | null; readonly right: number | null }
}

export interface PastFeedSession extends PastFeed {
  readonly actionId: string
  readonly when: When
}

const isMinutes = (minutes: number | null): minutes is number =>
  minutes !== null && Number.isInteger(minutes) && minutes >= 0 && minutes <= MAX_SIDE_MINUTES

export const isComplete = ({ minutes, breastMilkMl, formulaMl }: PastFeed) =>
  isMinutes(minutes.left) &&
  isMinutes(minutes.right) &&
  breastMilkMl !== null &&
  formulaMl !== null &&
  minutes.left + minutes.right + breastMilkMl + formulaMl > 0

export const pastFeedEntry = (actionId: string, startedAt: number, feed: PastFeed): NewFeed => {
  const order = [feed.first, OTHER_SIDE[feed.first]]
  const segments = order.reduce<NewFeed["segments"]>((laid, side) => {
    const minutes = feed.minutes[side] ?? 0
    if (minutes === 0) return laid
    const start = laid.at(-1)?.endedAt ?? startedAt
    return [...laid, { side, startedAt: start, endedAt: start + minutes * MINUTE_MS }]
  }, [])
  const end = segments.at(-1)?.endedAt ?? startedAt
  const milk = { breastMilkMl: feed.breastMilkMl ?? 0, formulaMl: feed.formulaMl ?? 0 }
  const portions = milk.breastMilkMl + milk.formulaMl > 0 ? [{ occurredAt: end, ...milk }] : []
  return { actionId, segments, portions }
}

const minutesOn = (entry: NewFeed, side: Side) =>
  entry.segments
    .filter((segment) => segment.side === side)
    .reduce((total, segment) => total + (segment.endedAt - segment.startedAt) / MINUTE_MS, 0)

const freshSession = (now: number, zone: string): PastFeedSession => ({
  actionId: crypto.randomUUID(),
  when: whenAt(now - EARLIER_MS, zone),
  first: "left",
  minutes: { left: 0, right: 0 },
  breastMilkMl: 0,
  formulaMl: 0,
})

const sentSession = (entry: NewFeed, zone: string): PastFeedSession => {
  const [segment] = entry.segments
  const [portion] = entry.portions
  const milk = portion ?? { occurredAt: 0, breastMilkMl: 0, formulaMl: 0 }
  return {
    actionId: entry.actionId,
    when: whenAt(segment === undefined ? milk.occurredAt : segment.startedAt, zone),
    first: segment?.side ?? "left",
    minutes: { left: minutesOn(entry, "left"), right: minutesOn(entry, "right") },
    breastMilkMl: milk.breastMilkMl,
    formulaMl: milk.formulaMl,
  }
}

export const pastFeedSession = (failed: Failed | null, now: number, zone: string): PastFeedSession => {
  const action = failed?.sending.action
  return action?.kind === "logFeed" ? sentSession(action.payload, zone) : freshSession(now, zone)
}
```

```ts
export const DRAFT_KEY = "bt.draft"
export const DRAFT_RETRY_MS = 12 * 60 * 60 * 1000

export const Draft = Schema.Struct({ route: Schema.String, sending: Sending, createdAt: Schema.Int })
export type Draft = typeof Draft.Type

const decodeDraft = Schema.decodeUnknownOption(Schema.fromJsonString(Draft))

  attempt(() => openStorage().setItem(DRAFT_KEY, JSON.stringify(draft)), undefined)

export const takeDraft = (openStorage: () => BrowserStorage, route: string): Draft | null => {
  const stored = attempt(() => openStorage().getItem(DRAFT_KEY), null)
  attempt(() => openStorage().removeItem(DRAFT_KEY), undefined)
  if (stored === null) return null
  return Option.getOrNull(Option.filter(decodeDraft(stored), (draft) => draft.route === route))
}

export const isFresh = (draft: Draft, now: number) => now - draft.createdAt < DRAFT_RETRY_MS
```

```ts
  readonly open: SheetKind | null
  readonly failed: Failed | null
  readonly toast: Toast | null
}

export const CLOSED: SheetsState = { open: null, failed: null, toast: null }

const UNDOES = new Set<Action["kind"]>(["deleteDiaper", "deleteFeed", "deletePortion"])

const withActionId = <Sent extends Action>(action: Sent, actionId: string): Sent => ({
  ...action,
  payload: { ...action.payload, actionId },
})

const renewed = ({ sheet, action }: Sending, actionId: string): Sending => ({
  sheet,
  action: withActionId(action, actionId),
})

export const restoredState = (draft: Draft | null, now: number, actionId: string): SheetsState => {
  if (draft === null || isFresh(draft, now)) return CLOSED
  const failed = { sending: renewed(draft.sending, actionId), error: new StaleDraft({ createdAt: draft.createdAt }) }
  return { open: draft.sending.sheet, failed, toast: null }
}

export const sendingState = (state: SheetsState, sending: Sending, online: boolean): SheetsState => ({
  ...state,
  open: online && closesOnSend(sending) ? null : state.open,
  failed: null,
  toast: UNDOES.has(sending.action.kind) ? null : state.toast,
})

const undoFailure = (error: Error, now: number): Toast => ({
  message: error instanceof Offline ? "No connection, so that wasn't undone." : "That wasn't undone.",
  undo: null,
  until: now + TOAST_MS,
})

export const failedState = (state: SheetsState, failed: Failed, now: number): SheetsState => {
  if (UNDOES.has(failed.sending.action.kind)) return { ...state, toast: undoFailure(failed.error, now) }
  return { ...state, open: failed.sending.sheet, failed }
}

  ...state,
  toast: toastFor(sending, saved, now) ?? state.toast,
})

export const expiredState = (state: SheetsState, now: number): SheetsState =>
  state.toast !== null && now >= state.toast.until ? { ...state, toast: null } : state
```
