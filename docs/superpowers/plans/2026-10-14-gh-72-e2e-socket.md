# GH-72 Every E2E Page Hears a Played Household Socket Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, chosen by Andrew on 14 Oct 2026) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** another spec's write to the shared local household can't change what a spec sees mid-test (issue #72).
- Every E2E page hears a played live socket by default. A test that needs the real household's socket opts in.
- Going offline closes the played socket in both engines, the way a phone's network would.

**Architecture:**
- **`e2e/test.ts`** extends Playwright's `test`:
  - The `context` fixture routes `/api/ws` to a played socket for every page. It answers `ping` with `pong`.
  - The fixture wraps that context's `setOffline`. Going offline closes every played socket with 1011 "offline", and a new one is refused until the test is back online.
  - The `socket` fixture's `changed(...keys)` sends the household's `changed` message to the newest open socket.
  - The option `household: "played" | "real"` decides it. `"real"` leaves the socket to the local household.
- **Every spec** imports `{ expect, test }` from `./test.ts`. An oxlint override for `e2e/**/*.spec.ts` refuses `test` from `@playwright/test`.
- **The real socket:**
  - Two tests keep it: today.spec's "shows a diaper the other phone just logged, without a reload" and live.spec's "opens a socket to the household … answers its heartbeat".
  - M3.3's AC 6 test needs no opt-in. Its watching phone comes from `browser.newContext()`, which the fixture never touches, and its logging page updates from its own save.
- **Gone:**
  - `muteLiveUpdates`: its export and 33 calls in 11 specs, plus `bottle.spec.ts`'s own copy.
  - The four local `playSocket` helpers, in edit-feed, edit-diaper, settings and settings-supplements.
  - The three `goOfflineLikeAPhone` copies, in offline, sheets-offline and deleted, and connectivity.spec's close routes.
  - connectivity.spec's WebKit-only skip on its midnight test.

**Tech Stack:** Playwright 1.64.0 (`routeWebSocket` on the context, `WebSocketRoute` `onMessage`, `onClose` and `close`, option fixtures), oxlint 1.87.0, oxfmt 0.72.0, TypeScript 5.9.3 and Node 24.21.0. It adds no package and changes no app code.

## Decisions this plan makes (veto in review)

- **P1: The default lives on the context.** `context.routeWebSocket`, so a spec's own `page.routeWebSocket` still wins, as live.spec's and new-version.spec's do. Playwright tries a page's routes first, newest first, and the context's only when none matches (`_onWebSocketRoute` in playwright-core 1.64).
- **P2: The played socket answers the heartbeat.** A test that runs the clock past two beats (60 s) keeps its socket, as with a real household. `muteLiveUpdates` never answered.
- **P3: Offline closes and refuses.**
  - The wrapped `setOffline(true)` closes every played socket with 1011 "offline", the code the specs' own close routes used.
  - While offline, a new one closes inside the route handler. Playwright's mock fires `open` only after the handler returns, and never on a closed socket, so a refused reconnect never reads as heard.
  - A probe on 14 Oct 2026 showed why it's needed: without it, in Chromium and in WebKit, a played socket stays open after `setOffline(true)`, and a new one opens while offline.
- **P4: `socket.changed(...keys)`** waits until a played socket is open, then sends to the newest. A socket the page closes leaves the set. With `household: "real"` it throws.
- **P5: Two opt-ins only.** Every other spec passed on the played socket (Task 1's full run).
- **P6: The lint rule restricts `test` only.** The sweep moves `expect` too, and the rule doesn't need to.

## The noisy household (Finish's proof; not committed)

`noisy-household.mjs <port> <every-ms>` logs and deletes a real diaper every 250 ms while a full run uses the same port. Each write broadcasts `changed` with `["today"]` to every socket that reaches the household:

```js
const [port = "4226", every = "250"] = process.argv.slice(2)
const origin = `http://localhost:${port}`
const counts = { logged: 0, deleted: 0, refused: 0, unreachable: 0 }

const send = (method, path, body) =>
  fetch(`${origin}${path}`, { method, headers: { "content-type": "application/json" }, body: JSON.stringify(body) })

const churn = async () => {
  try {
    const logged = await send("POST", "/api/diapers", {
      actionId: crypto.randomUUID(),
      occurredAt: Date.now() - 60_000,
      wet: true,
      dirty: false,
    })
    if (!logged.ok) {
      counts.refused += 1
      return
    }
    counts.logged += 1
    const { diaper } = await logged.json()
    const deleted = await send("DELETE", `/api/diapers/${diaper.id}`, { actionId: crypto.randomUUID(), version: diaper.version })
    if (deleted.ok) counts.deleted += 1
    else counts.refused += 1
  } catch {
    counts.unreachable += 1
  }
}

setInterval(churn, Number(every))
setInterval(() => console.log(new Date().toISOString(), JSON.stringify(counts)), 15_000)
```

```ts
import { type BrowserContext, test as base, expect, type WebSocketRoute } from "@playwright/test"

export { expect }

type Household = "played" | "real"
type QueryKey = ReadonlyArray<string | number>

export interface PlayedSocket {
  readonly changed: (...keys: ReadonlyArray<QueryKey>) => Promise<void>
}

const HOUSEHOLD_SOCKET = /\/api\/ws$/u
const OFFLINE = { code: 1011, reason: "offline" }
const openSocketsOf = new WeakMap<BrowserContext, Set<WebSocketRoute>>()

const answerTheHeartbeat = (socket: WebSocketRoute) =>
  socket.onMessage((message) => {
    if (message === "ping") socket.send("pong")
  })

const playTheHousehold = async (context: BrowserContext) => {
  const open = new Set<WebSocketRoute>()
  let offline = false
  openSocketsOf.set(context, open)
  await context.routeWebSocket(HOUSEHOLD_SOCKET, async (socket) => {
    if (offline) return socket.close(OFFLINE)
    open.add(socket)
    answerTheHeartbeat(socket)
    socket.onClose(() => open.delete(socket))
  })
  const setOffline = context.setOffline.bind(context)
  context.setOffline = async (goingOffline) => {
    offline = goingOffline
    if (goingOffline) await Promise.all([...open].map((socket) => socket.close(OFFLINE)))
    await setOffline(goingOffline)
  }
}

const sendChanged = async (context: BrowserContext, keys: ReadonlyArray<QueryKey>) => {
  const open = openSocketsOf.get(context)
  if (open === undefined)
    throw new Error('socket.changed plays the household, which test.use({ household: "real" }) turns off')
  await expect.poll(() => open.size).toBeGreaterThan(0)
  const newest = [...open].at(-1)
  newest?.send(JSON.stringify({ changed: keys }))
}

export const test = base.extend<{ household: Household; socket: PlayedSocket }>({
  household: ["played", { option: true }],
  context: async ({ context, household }, use) => {
    if (household === "played") await playTheHousehold(context)
    await use(context)
  },
  socket: async ({ context }, use) => {
    await use({ changed: (...keys) => sendChanged(context, keys) })
  },
})
```

The override in `oxlint.config.ts` keeps `datesThroughDomain` and adds `paths: [{ name: "@playwright/test", importNames: ["test"], message: … }]`.
